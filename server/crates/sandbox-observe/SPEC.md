# sandbox-observe

## 功能意图

sandbox-observe 是预留的观测面，定义沙箱侧观测记录的数据模型与只读采集接口：agent 会话记录、主机侧命令执行记录、流量监测记录。数据源位于 channel 与 agent-runtime 的执行路径（二者接口预留观测上报口），本模块只承接记录模型与采集，不产生数据、不反向依赖 server。流量监测仅保留数据模型，不实现采集。

## 关键功能与验收

### 观测记录模型

三类记录的数据模型：agent 会话记录（会话 ID、轮次、prompt 与响应摘要）、主机侧命令执行记录（命令、退出码、时间、来源通道）、流量监测记录（通道、方向、规模摘要）。模型可序列化，供存储与查询。

#### 验收

- 三类记录模型字段完整、可序列化往返。
- 记录模型不含凭据明文字段。

### 采集接口

定义只读采集接口：按沙箱、运行与时间范围查询记录。采集实现由后续观测源接入方提供。

#### 验收

- 接口签名覆盖三类记录的过滤查询，实现可替换。
- 无数据源接入时接口返回空集而非错误。
