# sandbox-observe

## 功能意图

为 Flow 提供沙箱观测记录、事件映射和采集接口。Flow 装配方将 Channel 命令与连接、agent 会话和进程退出事件映射为关联记录，供内存或空采集器消费。沙箱 Runtime 通过公共协议报告会话状态，不链接此业务库。

## 关键功能与验收

### 事件接入

记录来源、沙箱、运行、会话或命令关联标识、时间、结果和必要摘要。主机侧执行命令时由实际执行方上报，不能以沙箱 SSH 命令记录冒充主机审计。

#### 验收

- 同一执行链的会话、命令和进程事件可按关联标识查询。
- 原始凭据和敏感环境变量不出现在记录中。
- 未配置采集实现时生产方可继续工作，不报告虚假的采集成功。

### 传输观测预留

流量观测先记录连接状态、方向与字节计数。完整抓包、协议内容分析和独立流量监控系统不在此阶段实现。

#### 验收

- 传输摘要可关联到通道和沙箱，不要求解析业务载荷。
- 接入新的观测消费者不改变沙箱生命周期和 agent 会话协议。
