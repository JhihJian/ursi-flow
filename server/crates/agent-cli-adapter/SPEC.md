# Agent CLI Adapter

## 功能意图

适配具体 Agent CLI 的启动参数、配置文件、输入输出和取消方式。真实适配器由沙箱内 session-service 装配，使用本地进程与文件接口操作该会话工作区。源码目录归属 workspace，不代表运行位置在 server 进程内。

## 关键功能与验收

### CLI 执行与取消

按统一输入启动 CLI，解析输出与工具事件并返回统一结果。会话服务决定何时执行和取消，Adapter 实现对应 CLI 的进程控制。

#### 验收

- 一个真实 CLI 在沙箱内完成任务并输出结果与产物。
- 取消后 CLI 及所属子进程退出，失败结果不会被适配器自动重试。
- 新增适配器不改变 Gateway 和 Channel 的协议。

### 能力渲染

将模型、提示词、Skills、MCP 服务配置渲染到会话工作区和 CLI 参数中，凭据按所需权限临时注入。

#### 验收

- 给定模型、Skills 与 MCP 配置，CLI 实际使用的配置包含对应值。
- 临时凭据不进入产物与日志，释放会话时清理相关临时文件。

### 测试替身

提供确定性的 mock 用于会话服务和流程测试，支持成功、失败与取消场景。

#### 验收

- mock 在相同输入下产生确定性结果，失败与取消可被上层识别。
- mock 经过相同事件和结果契约，不绕过会话控制验收。
