# Agent Runtime

## 功能意图

定义 agent 可控接口和会话语义，向 server 提供创建会话、执行、取消、关闭及事件回流能力。服务端通过 Channel 传输 ACP 请求到沙箱 session-service，具体 CLI 由会话服务装配的 Adapter 控制。共享输入、结果和事件契约可供客户端与适配器实现使用。

## 关键功能与验收

### 会话控制

关联运行、节点、会话与执行请求，提交 prompt 和角色能力配置，返回统一结果和终态。工作流重试策略由 server engine 决定。

#### 验收

- 一次执行的请求、事件和结果保持同一关联标识。
- 取消或关闭请求能到达对应会话，并返回可判断的执行状态。
- 连接中断可与任务失败区分，不自动重复提交未知结果的任务。

### 能力配置契约

约定提示词、模型、Skills 和 MCP 服务等配置输入。CLI 特有的参数和文件渲染由 Adapter 在沙箱内执行。

#### 验收

- 跨 ACP 传递后配置字段保持完整，未知或不支持能力返回明确错误。
- 变更具体 CLI 不要求 server 拼接 CLI 命令或写入特定格式配置。

### 事件回流

将 session-service 返回的状态、输出与工具事件映射为统一事件，供 server 展示和观测采集。

#### 验收

- 执行期间持续收到属于当前会话的事件，终态与最终结果一致。
- 观测消费者缺失不会阻止控制请求和结果返回。
