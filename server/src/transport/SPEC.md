# transport

## 功能意图

向页面、外部调用方和 agent 提供 HTTP、SSE/WebSocket 与 MCP 接入。负责协议解析、路由、身份上下文、错误映射和静态资源，各业务操作调用所属域的公开服务。业务状态转换与 SQL 查询由业务域拥有。

## 关键功能与验收

### 业务接口与错误映射

按流程、角色、运行、产物、沙箱、连接配置组织 API，解析请求后调用对应服务。统一返回参数错误、资源不存在、状态冲突和基础设施故障。

#### 验收

- 给定有效请求，业务替身收到完整且正确的参数，响应保留服务返回的标识与结果。
- 格式错误请求返回 4xx，业务服务不被调用。
- 资源不存在映射为 404，引用或状态冲突映射为 409，内部故障返回脱敏错误。
- 角色配置与模型连接响应只返回允许展示的配置及凭据引用，认证信息不进入响应或请求日志。

### 事件流与重放

按运行订阅事件，以稳定事件标识和游标合并历史与实时通知。先建立订阅再补读历史，在订阅交界、接收滞后和重连时从持久化事件源补读并去重。

#### 验收

- 指定运行的订阅只输出该运行的事件，客户端收到可继续读取的游标。
- 在历史读取与实时订阅交界插入事件，客户端按顺序收到一次该事件。
- 慢消费者触发通知滞后后可从持久事件补读，不静默丢失。
- 携带有效游标重连时继续读取后续事件；无效游标返回明确错误或显式重同步指令。
- 客户端断开后订阅资源释放，运行继续执行。

### MCP 与连接协议接入

装配现有 mcp-server 提供的工具域，工具操作通过注入的业务接口执行。运行与节点身份来自可信调用上下文。终端等长连接转交 sandboxes/Channel 接入。

#### 验收

- MCP 调用与等价 HTTP 调用遵循相同业务校验和错误规则。
- agent 无法用工具参数覆盖可信上下文中的运行和节点归属。
- 未授权的运行资源访问被拒绝，连接关闭后本地请求资源释放。
- 平台 MCP 工具注册与角色配置的外部 MCP 连接互不覆盖。

### 静态页面资源

提供 web 构建产物的内嵌或目录读取，使用 feature 隔离构建产物依赖。

#### 验收

- 开启内嵌构建后可返回页面与静态资源，无需外部文件目录。
- 无构建产物时接口仍可启动，静态资源缺失返回明确响应且不 panic。
- 静态路径不能越过配置的资源根目录。

## 交付与验收边界

独立交付使用进程内路由测试、业务服务与事件源替身，验证请求解析、响应、错误映射、身份传播和流协议。网络测试需要监听时使用 0.0.0.0 与动态端口。

联合验收连接真实业务服务和 SQLite，验证 CRUD 与审批 API、事件重放和游标去重。MCP 与 agent 联调验证工具发现、上下文归属和调用结果，长连接与 Channel 联调验证实际传输。协议替身测试不覆盖真实业务持久化。
