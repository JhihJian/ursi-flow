# mcp

## 功能意图

mcp 是面向 agent 的 MCP 工具面：同一 MCP server 骨架下的三个工具注册域。运维域暴露沙箱与网关操作，控制域暴露流程与运行操作，内部工具域暴露运行上下文内的产物与状态工具（注入 run/node 身份）。transport 负责协议入口，本模块注册工具并定义后端接口；app 将接口绑定到实际业务服务。

## 关键功能与验收

### 工具域注册

三个域各自注册工具：名称、描述、输入 schema 与处理函数。域可独立启停，server 装配时选择暴露的域。工具操作通过 flow-core 的业务接口执行。

#### 验收

- 给定装配了某域的 server，agent 经 MCP 可发现并调用该域工具。
- 未装配的域对 agent 不可见。

### 运行上下文注入

内部工具域的工具调用自动携带运行上下文（run ID、node ID、会话身份），工具实现从上下文取身份而非参数明文传入，防止越权引用其他运行。

#### 验收

- 工具调用只能操作上下文所属运行的资源，跨运行引用被拒绝。
- 上下文缺失时调用返回明确错误。
