# 工作项办理

## 功能意图

记录每次派工采用的包版本、输入和来源，在同一张工作项上完成办理、交付和验收。

## 关键功能与验收

### 发起与查找

#### 验收

- 从已发布且可派工的包版本创建工作项，保存解析后的快照，初始状态为 `pending`，尝试和交付历史为空。
- 相同 `requestId` 和派工参数再次提交时返回原工作项；复用标识但更改来源、输入、包或修订时返回冲突。
- 经办人开始办理后可按 `working` 查找该单，从详情读到当次材料及经办人。

### 交付与验收

#### 验收

- 办理中提交文本文件，校验成功后在一笔更新中收存内容、分配交付版本并转入 `review`。活动尝试阻止交付。
- 只有当前待验收版本可通过或退回。通过后记录所通过的版本，退回必须写明原因，工作项回到 `working`。
- 重提交付产生新版本。按旧版本读取仍可取得原文和意见，迟到的旧版验收请求返回冲突。以同一数据目录重启后两张单的材料、文件和状态保持独立。
