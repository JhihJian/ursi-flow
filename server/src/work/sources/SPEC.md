# 固定动作文件来源

## 功能意图

让管理员把本地导出的资源接入工作清单。操作者从资源详情选择预设动作，生成可追溯的工作项。

## 关键功能与验收

### 可选来源与刷新

#### 验收

- 未配置时来源接口返回 404，内置工作项路由可独立使用。
- 来源索引仅公布来源标识、类型及动作名。资源列表和详情使用当前导出文件，文件替换后下次查询能读到更新。
- 配置和导出检查文件类型、权限及字节上限。损坏的导出返回来源不可用，响应中不含本地路径或解析失败的材料。

### 固定动作派工

#### 验收

- 只接受动作名及请求标识。派工时重新读取所选资源，按来源配置固定工作包修订并记录来源四元组。客户端提交的包、执行器或材料字段被拒绝。
- 并发重试同一请求只创建一个待办理工作项。相同请求标识对应不同派工参数时返回冲突。
- 派工本身不产生执行尝试；开始办理后，该工作项只能发起所选动作。
