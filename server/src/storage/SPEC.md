# storage

## 功能意图

向 server 各业务域提供 SQLite 连接、迁移、事务与文件内容存储基础能力，使本域数据操作和跨域一致性操作共用可替换的存储边界。各域拥有业务 repository、表结构和查询语义，storage 负责组织迁移及事务执行。

## 关键功能与验收

### 数据库打开与迁移

按配置打开数据库，按顺序应用各域登记的迁移。迁移版本与执行结果持久化，初始化完成后才交出可用连接。

#### 验收

- 使用空临时目录打开数据库，完成建表后可供 repository 读写；重复打开不重复执行已完成迁移。
- 关闭连接后重新打开，已提交数据和迁移记录保留。
- 注入迁移失败，返回明确错误且服务不进入就绪状态；失败迁移不被记录为成功。

### 事务上下文

提供可供多个域 repository 共用的事务上下文。调用方控制一次用例的开始、提交与回滚，所有参与者使用同一个一致性视图。

#### 验收

- 在同一事务内写两个测试表，中途失败后均不可见，成功提交后均可见。
- 事务内多次查询配置时，并发更新不能产生新旧数据混合的读取视图。
- 使用两个真实 SQLite 连接执行冲突写入，返回可处理的冲突或等待结果，不静默丢失更新。
- 事务作用域退出且未提交时回滚，连接可继续用于后续操作。

### 稳定内容存储

提供内容写入、读取与清理基础能力，以稳定标识关联数据库元数据。各域管理内容归属，storage 保证路径边界和完整写入。

#### 验收

- 写入内容并重开存储后，按标识读取的字节一致。
- 写入中断不会将半份内容发布为可用对象。
- 路径穿越、绝对路径或符号链接逃逸请求被拒绝，存储目录外文件保持不变。
- 元数据提交失败遗留的未引用内容可清理，已引用内容保持可读。

## 交付与验收边界

独立交付使用真实临时 SQLite 和临时内容目录，验证迁移、重开、故障回滚与双连接并发，无需 HTTP、Gateway 或 Agent CLI。

联合验收由 server 组织：roles/workflows 的引用登记与删除、runs 的快照创建和状态事件提交使用真实 repository 验证。storage 事务测试证明基础能力，业务约束由拥有该规则的模块验证。
