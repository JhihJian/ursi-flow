# session-service

## 功能意图

沙箱内的 agent 会话服务，接收 ACP 会话请求，装配 Agent CLI Adapter，管理会话状态、执行进程、事件流与取消。sshd、code-server、Chromium、noVNC 及应用进程分别提供自身原生服务。

## 关键功能与验收

### Agent 会话控制

鉴权后创建绑定沙箱工作区的会话，接收 prompt 和能力配置，启动适配器并返回事件与最终结果。会话进程由本服务拥有，工作流重试决策留给 server engine。

#### 验收

- 合法会话完成一次 prompt 往返，输出、工具事件与终态具有相同会话标识。
- 无效身份或跨会话操作被拒绝，CLI 错误转换为明确执行结果。
- 执行失败不在服务内部自动重复提交 prompt。

### 取消与资源回收

显式取消、关闭、会话到期或沙箱停止时回收所属子进程。连接断开单独报告，不自动等同于取消或新建任务。

#### 验收

- 取消可终止所属 CLI 进程组，终态返回后不遗留该会话子进程。
- 连接中断不会静默重放任务，重新连接不能启动第二份同一请求。
- 服务重启后旧执行状态以可识别的中断结果报告，不自动重跑。

### 会话观测

按会话关联标识产生开始、执行、取消、结束与错误事件，供 server 收集并接入预留观测面。

#### 验收

- 会话事件能关联沙箱、运行和请求，记录内容经过敏感信息过滤。
- 可选观测订阅方缺失不影响会话控制与结果返回。
