# process-supervisor

## 功能意图

通过成熟进程监督器管理沙箱内常驻服务，维护配置、启动依赖、就绪检查、重启限额与停止规则。监督器程序由 image 提供，本目录交付配置与必要的薄适配。具体产品在实现时根据监督能力验证选定。

## 关键功能与验收

### 服务启动与恢复

启动 sshd、session-service 等已启用常驻服务，执行对应就绪检查。服务崩溃按退避和重启限额恢复，达到限额则报告故障。Agent CLI 属于会话任务，由 session-service 管理。

#### 验收

- 服务进程存在但检查未通过时不汇报就绪。
- 常驻服务异常退出按配置重启，持续失败最终报告不可用。
- agent 任务失败不会触发监督器自动重跑，session-service 重启也不重放旧任务。

### 信号与进程回收

监督启动链处理容器停止信号，按依赖关系停止服务，在宽限期后终止残留进程，回收退出的子进程。

#### 验收

- 发送停止信号后，常驻服务与会话进程退出，容器正常结束。
- 无响应服务超过宽限期被终止，不无限阻塞沙箱停止。
- 子进程退出事件可查询，持续运行不会积累僵尸进程。
