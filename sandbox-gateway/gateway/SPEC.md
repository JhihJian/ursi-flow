# Sandbox Gateway

## 功能意图

Gateway 是独立沙箱资源管理服务。统一负责创建、启动、停止、删除、重建、状态查询、元数据保存、启动时资源对账、端口地址返回及公开/内部端口隔离。可选 tunnel 为客户端提供受鉴权保护的字节中继。

一个 crate 内划分 gateway-api、lifecycle、driver、tunnel。lifecycle 是唯一沙箱业务状态管理方，driver 将统一规格翻译为基础设施操作。server 通过网络契约调用 Gateway，agent 会话在沙箱内处理。

## 关键功能与验收

### 资源生命周期

提供完整生命周期操作，保存创建规格与操作意图，区分停止保留、删除释放与保数据重建。

#### 验收

- 创建后可查询就绪状态和端点，停止后可再次启动。
- 保数据重建后工作区文件仍存在；显式销毁数据的重建按授权范围执行。
- 删除遇到驱动故障时保留删除意图，恢复后继续完成清理。

### 持久化与对账

元数据存储和资源对账由 lifecycle 统一处理。对账同时保留期望操作和观察到的实际状态。

#### 验收

- Gateway 重启后能读回创建规格、操作意图与资源标识并继续对账。
- 查询超时不触发资源或记录删除，确认资源不存在后按期望操作收敛。

### 端点与可选隧道

返回服务端点及公开/内部属性。内部端口保持在受控网络中，tunnel 只中继已授权端点的 TCP 字节。

#### 验收

- 内部端口不会被发布为宿主公网监听或公共负载均衡入口。
- 关闭 tunnel 时直连方式可用；启用后 SSH、ACP 等上层协议无需改变。
- 非法凭据、未知端点和任意目标地址转发请求被拒绝。
