# tunnel

## 功能意图

提供可选的 TCP over WebSocket 字节中继。通过 lifecycle 解析沙箱已声明端点，转发获准的字节流，使 Channel 在直连和隧道间切换时保持上层协议一致。

## 关键功能与验收

### 目标校验

接收已鉴权的调用上下文、沙箱标识与端点标识，校验访问范围并解析当前可达地址。入口认证由 gateway-api 完成，目标策略仍在升级前检查。

#### 验收

- 任意 host/URL、未知端点与越权沙箱请求被拒绝。
- 未启用 tunnel 或未配置有效鉴权时，不建立字节中继。
- 目标不可达时在升级前返回错误。

### 双向中继

有序转发 TCP 字节，支持半关闭、背压与取消。连接断开、沙箱释放或服务关闭时回收相关连接。

#### 验收

- 使用真实 TCP 测试服务验证二进制数据双向完整，输入 EOF 后仍能读取剩余输出。
- 慢消费者不会导致无界缓冲，取消后两侧连接均关闭。
- SSH、ACP 或 HTTP 内容不被解析、修改或重放。
