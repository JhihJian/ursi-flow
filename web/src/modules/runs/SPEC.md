# 运行记录前端模块

## 功能意图

为运行操作者提供进度、冻结配置、节点事件、产物与人工审批入口。
运行快照、调度、执行轮次和审批状态以 server/runs 的服务结果为准。
模块入口与业务用例分别验收，业务结果以服务端返回为准。

## 关键功能与验收

### 初始化入口

通过 `/runs` 提供运行记录页面，介绍进度与快照、事件与产物、人工审批三项能力。

#### 验收

- 路由名为 `runs`，懒加载页面，标题为“运行记录”，描述说明用户用途。
- 页面复用共享占位组件，展示三项能力及“功能准备中”，无模拟业务记录、成功状态或未接通的操作按钮。

### 状态、快照与事件（业务接入要求）

展示运行列表、节点状态、创建时快照、当前执行轮次、工具轨迹、日志和产物关联。
通过共享事件能力按游标接续持久事件，运行结果与资源清理结果分别展示。

#### 验收

- 更新流程或角色后，旧运行详情仍读取冻结配置，历史尝试与当前执行状态可区分。
- SSE 断线后补读事件，按运行标识与单调序号去重并保持顺序，迟到事件保持轮次隔离。
- 产物关联可定位到当前或历史执行，资源释放失败保留真实运行结果及清理错误。

### 审批、返工与取消（业务接入要求）

等待审批时提供放行或打回传递祖先节点的操作，取消结果依据服务确认展示。

#### 验收

- 仅等待审批节点显示审批入口，合法放行后更新状态，打回后展示目标及下游的新执行轮次。
- 非法目标、状态冲突和达到返工限制展示服务错误，刷新后与服务状态一致。
- 历史产物保持可查，当前输出跟随服务选择；取消待确认时保持待确认状态。

## 模块职责与验收边界

- 本域路由、页面、API 适配、类型与状态归本目录，按功能需要添加文件。
- 前端代码仅依赖 shared 公共能力，跨域导航由 app 装配。
- server/runs 规格约束服务契约，浏览器经共享 HTTP 与 SSE 层访问服务。
- 独立验收覆盖路由、用途说明、三项能力与准备中状态，仅证明初始化入口可用。
- 业务独立验收可用接口替身检查事件排序去重、审批请求和冲突展示。
- 联合验收连接真实 runs、配置域、artifacts、sandboxes、transport 与存储，验证快照、审批和事件补读。
- 初始化验收与业务验收分别记录，真实执行及资源释放另需 Gateway 与执行链路证据。
