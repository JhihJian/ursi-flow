# 外部来源

## 功能意图

展示服务端配置的外部来源及其当前导出条目，让操作者通过固定动作派工并回到统一工作清单。

## 关键功能与验收

### 来源浏览

#### 验收

- `/sources`、`/sources/:provider/items` 和 `/sources/:provider/items/:id` 分别读取来源索引、实时条目列表和实时条目详情。
- 来源未配置的 404、空列表和 503/网络故障分别显示未启用、空态和可重试故障；工作清单不受来源探测失败影响。
- 条目材料只读展示，导出刷新后重新读取，不缓存旧条目，也不回显服务端路径或原始错误材料。

### 固定动作派工

#### 验收

- 派工请求只提交 `requestId` 和服务端公布的 `action`，包、修订、输入和执行器不由客户端控制。
- 同一条目动作重试沿用原 `requestId`，防止响应丢失或重复点击创建多张工作项；切换动作后生成新的请求标识。
- 成功后进入 `/items/:id`，失败保留选择和错误，可继续用同一请求标识重试。
