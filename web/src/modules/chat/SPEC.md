# 本地演示对话

## 功能意图

提供独立于 Flow 服务的会话管理、流式交互与 Markdown 消息阅读。界面标明演示回复来源。

## 关键功能与验收

### 会话与本地持久化

#### 验收

- 会话支持新建、搜索、深链、删除及刷新恢复。空态显示新建入口，删除需要确认。
- 本地模板使用固定示例，消息不请求网络服务，也不携带真实令牌。

### 消息流

#### 验收

- 输入消息后按 NDJSON 分段呈现回复，最终以完整消息替换占位内容，推理与工具信息可折叠查看。
- 可停止、重新生成和重试；中止已离开页面的读取，旧请求收尾不覆盖新请求的状态。
- 回复使用净化后的 Markdown，桌面和移动布局均能访问列表、消息和输入框。
