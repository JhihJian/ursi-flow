# 沙箱管理前端模块

## 功能意图

为运行操作者提供模拟沙箱的资源状态、运行关联、生命周期日志和释放操作。当前页面只管理模拟状态与记录，没有真实连接或终端。真实资源生命周期由 Gateway 管理，平台关联与访问接入由 server/sandboxes 和 Channel 提供。

## 关键功能与验收

### 资源目录、搜索与运行关联

`/sandboxes` 查询模拟 API，展示全部环境、使用中和已释放数量。资源卡片提供标识、镜像、CPU、内存、工作目录、创建时间与所属运行。

#### 验收

- 初始页面显示种子沙箱及统计，按名称或标识搜索、按 running、released、failed 状态筛选可得到匹配结果。
- 点击“查看关联运行”进入正确的 `/runs/:id`，从运行页携带 `?id=` 首次进入沙箱页面可打开对应详情，页面内选中资源同样以 `id` 查询参数表示。
- 创建模拟运行后刷新资源目录，可查询新增沙箱与正确运行关联。
- 加载、查询失败和无匹配结果有独立提示，刷新与重试重新查询接口。
- 独立验收检查模拟目录、搜索与路由，真实 Gateway 状态、资源规格及关联一致性需与 sandboxes、runs 联合验收。

### 资源详情与生命周期日志

通过资源名称或“详情与日志”打开弹窗，显示标识、状态和模拟生命周期记录。

#### 验收

- 详情标识与所选卡片一致，日志呈现模拟准备、快照加载或释放记录。
- 关闭后可打开另一资源，窄屏可阅读长标识和日志，键盘可关闭弹窗并返回触发入口。
- 页面明确标示本地演示日志和模拟资源范围，展示中没有可连接的终端、IDE 或远程端点。
- 独立验收检查日志与资源匹配，真实日志来源、访问授权、文件及原生连接协议需完成对应接入并联合验收。

### 确认释放与状态反馈

释放通过 API 请求确认结果，活动模拟运行拒绝手动释放。模拟运行成功或取消时自动释放关联沙箱，已释放资源保留查询与日志。

#### 验收

- 点击未释放资源的“释放”弹出确认，取消保持状态，确认后显示请求等待状态。
- queued、running 或 waiting 运行的释放请求返回冲突，页面以 `role="alert"` 就地展示后端错误文案并保留原状态与可点击的释放按钮，可继续查看关联运行。
- 在关联运行中取消任务，或通过审批等待运行完成后，刷新沙箱显示 released，详情保留释放记录，卡片隐藏释放按钮。
- 对已结束运行的释放请求可返回已释放结果，重复请求保持幂等，已生成的模拟产物继续可查。
- 释放请求故障时显示操作失败，释放 API 成功后重新查询列表并显示操作通知，查询失败单独显示错误。独立验收覆盖模拟规则与反馈，真实释放失败、超时、结果未知和查询核实需与 Gateway 联合验收。

### 前端实现与验收方式

页面为 React 组件 `SandboxesView.tsx`，目录、详情与释放交互共用同一份 `useResource` 数据，选中资源、搜索词与状态筛选为组件局部状态。组件测试 `SandboxesView.test.tsx` 覆盖统计与筛选、`?id=` 详情、确认与取消、释放成功后刷新以及冲突错误就地提示。

## 模块职责与验收边界

本域拥有路由、目录筛选、详情选择、日志展示与释放交互。DTO、API、请求生命周期、确认及通知由 shared 提供，模拟资源状态和生命周期日志归 mocks。页面通过路由与运行域关联。

前端独立验收使用模拟 API 和浏览器操作，覆盖资源目录、日志、活动运行拒绝释放、取消后的终态及历史产物保留。镜像、CPU、内存和目录为演示数据。

真实联合验收连接 server/sandboxes、runs、Gateway 与 Channel，核对准备就绪、运行关联、资源查询、释放核实和本地连接清理。文件往返、终端、IDE、预览与远程连接需完成实际接口接入并验证授权、身份错误和连接中断行为。真实 API 路由与 DTO 尚需联调，live 模式只切换请求传输。
