# 沙箱管理前端模块

## 功能意图

为运行操作者提供沙箱资源状态、运行关联、获准访问和清理结果入口。
运行关联以 server/sandboxes 为准，资源实际生命周期由 Gateway 管理。
模块入口与业务用例分别验收，业务结果以服务端返回为准。

## 关键功能与验收

### 初始化入口

通过 `/sandboxes` 提供沙箱管理页面，介绍资源关联、文件与连接、释放结果三项能力。

#### 验收

- 路由名为 `sandboxes`，懒加载页面，标题为“沙箱管理”，描述说明用户用途。
- 页面复用共享占位组件，展示三项能力及“功能准备中”，无模拟业务记录、成功状态或未接通的操作按钮。

### 资源关联与释放结果（业务接入要求）

查看运行对应的沙箱标识、就绪状态及释放结果，区分操作失败与结果待确认。
资源查询失败时保留上次已知结果并标明查询故障，最终状态取自服务核实结果。

#### 验收

- 运行、沙箱标识与 Gateway 查询结果一致，准备中与已就绪状态可区分。
- 释放失败或超时显示失败或待确认，后续查询确认完成后才显示已释放。
- 查询故障与资源终态分别展示，运行执行结果与资源清理结果分别保留。

### 文件与连接接入（业务接入要求）

为已就绪且获准访问的沙箱提供文件、终端、IDE 或预览入口，遵循端点授权与原生协议。

#### 验收

- 未就绪或不存在的资源保持访问入口不可用，拒绝访问时展示服务返回的原因。
- 获准访问可连接正确资源，文件往返内容一致，错误身份与不可达端点可区分。
- 连接中断显示连接故障，远端任务状态继续依据运行服务确认。

## 模块职责与验收边界

- 本域路由、页面、API 适配、类型与状态归本目录，按功能需要添加文件。
- 前端代码仅依赖 shared 公共能力，跨域导航由 app 装配。
- server/sandboxes 规格约束服务契约，浏览器经共享 HTTP 层取得获准访问入口。
- 独立验收覆盖路由、用途说明、三项能力与准备中状态，仅证明初始化入口可用。
- 业务独立验收可用接口替身检查状态区分、授权错误和访问入口可用条件。
- 联合验收连接真实 sandboxes、runs、Gateway 与 Channel，验证资源关联、文件接入和释放核实。
- 初始化验收与业务验收分别记录，业务完成需取得真实资源与连接链路证据。
