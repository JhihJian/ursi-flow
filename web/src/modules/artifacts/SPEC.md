# 产物管理前端模块

## 功能意图

为交付物查阅者提供产物搜索、执行轮次筛选、内容预览、源文件、下载与运行追溯。默认内容来自模拟 API，覆盖前端独立验收。真实产物回收、完整归属与内容存储由 server/artifacts 提供，当前有效输出由运行域确定。

## 关键功能与验收

### 产物目录与归属筛选

`/artifacts` 读取产物和运行目录，按文件名或路径搜索，按运行及执行轮次筛选。条目具有稳定产物标识，展示运行、节点、轮次、大小与创建时间。

#### 验收

- 打开页面可查看模拟 API 的产物，搜索匹配文件名称或路径，选择运行及轮次后仅展示匹配条目。
- `/artifacts?runId=...` 初始化运行筛选，首次进入时的 `id` 参数可定位对应条目；运行筛选同步为 `runId` 查询参数，轮次筛选同步为 `attempt` 查询参数，切换运行时清除轮次参数。
- 点击文件切换内容，所属运行链接进入 `/runs/:id`，运行名称缺失时可使用运行标识展示归属。
- 桌面双栏面板填满内容区剩余高度，左侧文件列表与右侧预览各自滚动，窄屏面板高度随内容。
- 加载、请求失败、无匹配结果分别展示，刷新和重试重新读取产物，失败状态展示请求错误文案且不显示可操作的旧内容面板。
- 独立验收使用种子与多轮次模拟产物检查筛选、定位和路由，真实范围查询及完整归属需与 artifacts、runs 联合验收。

### 净化预览、源文件与 Blob 下载

模拟 API 返回文本内容、内容类型和文件名。Markdown 经 shared 净化组件呈现，源文件和其他内容类型以文本显示，下载由当前产物内容构造 Blob。

#### 验收

- 选择 `text/markdown` 产物时，“内容预览”显示标题、列表、表格等结构，危险 HTML、事件属性及危险链接经净化。
- 切换“源文件”显示原始文本，包含的 HTML 作为文本展示；切回预览后仍对应同一产物。
- 点击“下载文件”生成所选文件名，UTF-8 下载内容与 API 返回文本及源文件内容一致，下载后回收临时对象 URL。
- 独立组件与浏览器验收检查 Markdown 净化、源文件及实际下载内容。真实文件授权、二进制传输、损坏检测和内容校验由真实接口联调验收。

### 返工历史与资源释放后的读取

页面展示 API 返回的历史产物。模拟运行返工增加运行级 attempt，保留旧文件及事件，模拟沙箱释放保持产物可查。

#### 验收

- 同一模拟运行审批打回并重新执行后，旧、新产物具有各自标识和轮次，按轮次筛选可分别读取。
- 返回旧轮次时文件内容保持原值，运行页中的产物入口可导航到对应运行及条目。
- 模拟运行完成或取消并释放沙箱后，已生成产物仍能预览和下载。
- 独立验收覆盖运行级轮次历史展示。真实服务的 generation、节点累计 attempt、迟到产物隔离和当前有效输出选择需与 artifacts、runs、sandboxes 及存储联合验收。

## 模块职责与验收边界

本域拥有路由、搜索筛选、选择状态、预览切换及下载交互。DTO、API、请求生命周期和 Markdown 净化由 shared 提供，模拟产物生成与持久化归 mocks，跨域通过路由地址和资源标识关联。

页面为 React 组件 `ArtifactsView.tsx`，运行与轮次筛选以地址栏为唯一来源，搜索词与选中产物为组件局部状态。组件测试 `ArtifactsView.test.tsx` 覆盖筛选与地址同步、轮次收敛、空态与错误态、Markdown 与源文件切换、下载文件名与内容、关联运行链接回退。

独立验收使用模拟 API、固定归属夹具与浏览器下载检查，验证页面行为及模拟内容一致性。真实产物验收连接 artifacts、runs、sandboxes 和存储，核对内容回收、授权、校验信息、释放后读取、完整归属及旧尝试迟到写入隔离。当前模拟 DTO 使用 `runId`、`nodeId` 和运行级 `attempt`，真实 server 协议尚需联调。
