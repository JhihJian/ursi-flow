# 工作清单

## 功能意图

为经办人和验收人提供可筛选的工作项入口，并从已发布的工作包版本发起待办理工作项。

## 关键功能与验收

### 清单与深链

#### 验收

- `/items` 按全部、待办理、办理中、待验收和已交付查询服务端工作项，详情链接保留 `status` 查询串。
- 成功的空数组显示空态，加载失败显示故障和重试，不把故障误报为空态。桌面和移动布局均能换行显示长标识。
- `/items/new?package=...&revision=...` 读取指定工作包版本，展示 SOP、验收标准、交付物和类型化输入。

### 发起与防重

#### 验收

- 表单只提交 `requestId`、包、修订和输入，服务端返回的工作项打开后为 `pending`。
- 同一组参数在响应丢失或可重试失败后沿用同一个 `requestId`，提交按钮防止并发重复发送；修改包、修订或输入后生成新的标识。
- 服务端冲突和其他故障保留表单内容并显示错误，不跳转到未知工作项。
