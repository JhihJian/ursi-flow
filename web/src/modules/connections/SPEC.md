# 模型连接前端模块

## 功能意图

为模型服务维护者提供连接配置、凭据引用、能力查询和引用约束入口。
连接校验与能力描述以 server/connections 为准，凭据解析由服务端受控执行入口负责。
模块入口与业务用例分别验收，业务结果以服务端返回为准。

## 关键功能与验收

### 初始化入口

通过 `/connections` 提供模型连接页面，介绍服务配置、凭据引用、能力与引用三项能力。

#### 验收

- 路由名为 `connections`，懒加载页面，标题为“模型连接”，描述说明用户用途。
- 页面复用共享占位组件，展示三项能力及“功能准备中”，无模拟业务记录、成功状态或未接通的操作按钮。

### 配置与凭据引用（业务接入要求）

创建、编辑和删除连接，维护名称、服务类型、endpoint 与凭据引用。
页面使用非敏感配置 DTO，凭据明文与含敏感信息的上游响应保持在服务端受控边界内。

#### 验收

- 保存合法连接后重新打开详情，配置与服务结果一致，非法地址显示可定位错误。
- 含内嵌认证信息的 endpoint 被拒绝，页面错误采用脱敏内容。
- 使用带识别标记的测试密钥检查页面、状态、日志与浏览器持久存储，均无明文标记。

### 能力判断与引用约束（业务接入要求）

展示执行器对连接参数和认证方式的能力判断，并呈现角色引用造成的删除冲突。

#### 验收

- 能力支持、不支持及查询失败分别展示，描述接口结果仅表示适配能力。
- 被角色引用的连接删除失败时展示冲突原因，成功删除后列表与详情一致。
- 连接更新后旧运行读取冻结配置，新运行使用新值，真实认证结果取自执行链路。

## 模块职责与验收边界

- 本域路由、页面、API 适配、类型与状态归本目录，按功能需要添加文件。
- 前端代码仅依赖 shared 公共能力，跨域导航由 app 装配。
- server/connections 规格约束服务契约，浏览器经共享 HTTP 层访问非敏感配置。
- 独立验收覆盖路由、用途说明、三项能力与准备中状态，仅证明初始化入口可用。
- 业务独立验收可用接口替身检查字段校验、脱敏呈现与能力状态区分。
- 联合验收连接真实 connections、roles、runs、存储及凭据来源，验证引用约束、快照隔离和认证。
- 初始化验收与业务验收分别记录，能力描述验收和真实模型认证分别提供证据。
