# Web Mocks

## 功能意图

提供独立的本地模拟 API，支持页面演示和前端独立验收。本模块非真实后端，模型调用、脚本执行、工具操作和沙箱资源均为模拟。真实服务、SSE、凭据解析及执行链路由服务端联合验收。

浏览器入口通过 shared 的 HTTP transport 注入模拟请求实现，默认使用 localStorage 保存演示配置、运行快照、进度、事件和产物。凭据字段仅保存演示用 credentialRef 引用。

## 关键功能与验收

### 独立请求与演示控制

提供 /api 下角色、连接、流程、运行、产物和沙箱的 JSON 请求响应，以及演示设置和重置入口。默认请求延迟为 180 毫秒，支持设置 0 至 30000 毫秒延迟及一次性服务错误。

#### 验收

- 浏览器入口注入应用 transport，全局 fetch 保持原行为。直接创建模拟后端时可注入内存存储与延迟。
- 成功请求直接返回 DTO，删除成功返回 204，校验、缺失资源、状态冲突和服务故障返回结构化错误及对应 HTTP 状态码。
- failNext 只使下一次普通请求返回 503，设置与重置接口可继续访问。
- AbortSignal 取消保留 AbortError，延迟期间取消的请求不修改数据或消费错误开关。

### 配置、引用与快照

角色、连接和流程支持创建、查询、修改及删除，角色和流程支持独立复制。配置遵循必填字段、存在的引用和无环依赖图规则。运行创建时深拷贝流程、所用角色与连接。

#### 验收

- 空节点、重复节点或连线、缺失端点、循环依赖及不存在的角色引用均被拒绝。
- 删除被流程引用的角色或被角色引用的连接返回 409，复制后的修改与原记录独立。
- 配置修改或删除后，旧运行快照保持创建时内容，新运行使用当前配置。
- 连接和 MCP 地址使用 HTTP(S)，内嵌凭据及敏感查询参数被拒绝。请求中明确的 token、apiKey、password 等明文凭据字段被拒绝，连接测试返回明确的模拟结果。

### 顺序调度与审批

运行按 DAG 依赖逐个调度就绪节点，同一运行最多执行一个节点。节点数组顺序仅用于多个就绪节点的选择，依赖关系由边确定。agent 和 script 节点的模拟处理耗时均为两秒。GET 运行列表或详情时按模拟时钟推进状态，以轮询替代 SSE。

#### 验收

- 创建运行后仅一个依赖就绪节点执行，提前排列的下游保持 pending，汇合节点等待全部前驱成功后启动。
- 重复轮询当前执行节点不会启动独立分支。长间隔轮询可以顺序补推进多个已到完成时间的节点。
- 审批节点就绪后运行进入 waiting，全部其他待执行节点保持 pending，持续轮询不越过审批。放行后恢复单节点调度。
- 打回只接受当前审批的传递祖先，重置目标及其下游，增加执行轮次，保留独立已完成分支与历史产物。自身、下游、独立分支及未知目标被拒绝，状态保持不变。
- 列表、详情和操作响应中的运行状态与节点状态一致。全部节点成功后运行 succeeded 并释放模拟沙箱，取消后冻结节点并释放沙箱。
- 非等待审批运行拒绝放行和打回，终态拒绝继续操作，活动运行拒绝手动释放沙箱。事件标识唯一且有序，事件时间不倒退，产物可按运行和执行轮次查询。

### 演示状态保存与重置

浏览器默认使用 localStorage 的 ursi-flow-demo-v1 键保存完整演示状态。存储访问受限时浏览器入口可使用会话内存，存储内容无法恢复时使用新种子。状态变更在完整校验后一次提交，保存失败返回 503 并保留原状态。

#### 验收

- 首次创建即保存种子，重新实例化保留标识、时间、配置、快照、进度和模拟时钟。
- 成功修改提交一次，校验失败不修改数据、不消耗编号，存储写入失败回滚整个修改。
- 错误开关和延迟设置可恢复，重置生成独立种子并恢复初始设置，历史修改不会污染种子。

## 交付与验收边界

使用 Vitest 假时钟、内存存储和浏览器环境测试独立验证请求、顺序调度、审批返工、引用、快照、持久化与 transport 注入。验收命令为在 web 目录运行 `npm run test -- src/mocks` 和 `npm run typecheck`。模拟测试证明前端演示行为，真实服务状态、持久化事务、SSE 重放和执行结果由真实后端联合验收。
