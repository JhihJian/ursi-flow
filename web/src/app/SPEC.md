# Web App

## 功能意图

装配 Vue 应用、Router 和 Pinia，提供响应式导航、页面布局、标题及路由错误处理。各业务模块通过公开路由加入应用，业务功能由所属模块提供。

## 关键功能与验收

### 应用启动与路由装配

注册六个业务模块的懒加载路由，首页进入工作流，导航和标题跟随当前路由。

#### 验收

- 直接进入六个模块路径均显示对应标题与页面，页面刷新后仍保持当前模块。
- 导航高亮与 aria-current 对应当前地址，浏览器标题包含模块名。
- 根地址进入工作流，未知地址显示未找到页面并可返回工作流。

### 应用壳与键盘访问

桌面显示侧边导航，小屏显示顶部导航，内容区可在窄屏完整阅读。提供跳到主要内容的键盘入口和可见焦点。

#### 验收

- 桌面与移动浏览器均可点击六个模块入口，页面没有非预期的横向溢出。
- 键盘首次 Tab 可聚焦跳转入口，激活后焦点进入主要内容区。
- 导航、错误重试和返回入口均可通过键盘访问。

### 路由加载失败

捕获懒加载错误并保留失败目标地址，提供重新打开目标页面的入口，保留已加载的应用壳。

#### 验收

- 阻断模块资源请求后显示页面加载失败提示，恢复网络后点击重试可打开原目标模块。
- 正常导航恢复后清除错误提示。

## 交付与验收边界

独立验收通过内存 Router 和组件挂载验证模块装配，通过 Playwright 在桌面及移动 Chromium 验证构建产物的导航、刷新、404、键盘与加载失败。

生产 history 回退与真实 API 路由隔离由 server transport 联合验收。业务占位入口可访问不等于业务功能已交付。
