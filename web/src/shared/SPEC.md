# Web Shared

## 功能意图

提供无业务归属的 UI 与 HTTP 请求基础能力，供业务模块复用。共享实现不导入 app 或业务模块，业务 DTO、状态和校验提示归各域。

## 关键功能与验收

### 同源 JSON 请求

请求统一使用 /api 前缀，保留调用方请求参数、响应结构与取消信号。共享入口仅处理传输结果，业务语义由调用方解释。

#### 验收

- JSON 成功响应按原结构返回，204 响应返回空值。
- 请求携带原取消信号，取消失败保持 AbortError 身份。
- 绝对 URL 被拒绝，不发出外部请求。
- 非 JSON 成功响应或损坏 JSON 返回可识别的固定错误。

### 错误与敏感信息边界

HTTP 失败保留状态码，页面错误不携带原始上游响应正文。

#### 验收

- 模拟包含标记密钥的错误正文，暴露给调用方的错误信息不包含标记。
- 业务模块可依据 HTTP 状态区分不存在、冲突与服务故障。
- 公共入口不缓存凭据或写入浏览器持久存储。

### 初始化页面组件

接收模块标题、用途和规划能力，统一呈现尚未开放的功能入口。

#### 验收

- 页面显示传入的标题与能力，并明确标注功能准备中。
- 初始化组件不发出业务请求，不展示伪造记录或成功反馈。
- 标题与正文在窄屏可读，结构使用语义化标题和列表。

## 交付与验收边界

HTTP 使用 fetch 替身独立验证请求、取消、204、错误和响应解析。共享页面通过各模块的挂载与浏览器测试验证。真实接口状态码、认证和响应类型由 server transport 联合验收。
