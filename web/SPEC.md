# web

## 功能意图

web 是渲染展示页面。它通过 api 提供的 HTTP 与 SSE 契约，向用户展示流程列表与流程结构、单次运行的节点状态、工具轨迹、日志与产物，并提供人工审批的放行与打回操作入口。首版以只读展示与审批操作为主，不实现拖拽式流程画布。

## 关键功能与验收

### 流程列表与详情

展示流程列表，进入流程详情后展示节点与边的结构关系（只读 DAG 视图）。

#### 验收

- 流程列表展示已存流程的名称与基本信息。
- 流程详情页展示节点集合与节点间依赖边，节点类型可区分（agent、script、approval）。

### 运行详情

展示单次运行的节点状态、工具轨迹、日志与产物，支持查看各节点的输出与交付物。

#### 验收

- 运行详情页展示每个节点的当前状态。
- 可查看某节点的工具轨迹与日志。
- 可查看运行产生的产物列表与内容。

### 审批操作

在运行详情中对处于等待审批的节点提供放行与打回操作；打回需选择目标环节。

#### 验收

- 等待审批的节点展示放行与打回操作入口。
- 放行后页面反映节点继续执行；打回后反映目标环节重新执行。
- 非等待审批节点不展示审批操作入口。
