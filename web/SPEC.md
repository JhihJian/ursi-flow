# web

## 功能意图

web 通过 server transport 提供的 HTTP 与 SSE 契约，提供角色和模型连接配置、流程定义管理、运行查询及人工审批。界面按流程、角色、运行、产物、沙箱和连接设置组织，业务规则与状态归相应 server 模块。流程编辑使用表单或定义文本，首版流程图用于只读展示。

后端各模块可先经服务接口完成独立验收，页面验收连接真实业务服务与持久化存储。

## 模块地图

采用 Vue 3、TypeScript、Vite、Vue Router、Pinia 与 Tailwind CSS。业务目录与 server 业务域对应，共享基础和应用装配分别组织。

| 模块 | 职责 |
|---|---|
| [app](src/app/SPEC.md) | 应用壳、导航、路由、全局样式和加载失败处理 |
| [shared](src/shared/SPEC.md) | 公共 UI 与同源 HTTP 请求 |
| [workflows](src/modules/workflows/SPEC.md) | 流程定义、图展示、角色选择和启动入口 |
| [roles](src/modules/roles/SPEC.md) | 提示词、Skills、MCP 与模型选择 |
| [runs](src/modules/runs/SPEC.md) | 运行状态、审批、事件及配置快照 |
| [artifacts](src/modules/artifacts/SPEC.md) | 产物预览、下载和执行归属 |
| [sandboxes](src/modules/sandboxes/SPEC.md) | 沙箱关联、状态及获准连接入口 |
| [connections](src/modules/connections/SPEC.md) | 模型连接与凭据引用 |

## 关键功能与验收

### 工程初始化与模块入口

提供可重复安装、类型检查、测试和构建入口。六域路由可独立进入，尚未开放的业务能力使用明确的准备中页面，业务记录来自真实服务接口。

#### 验收

- Node.js 24 下使用锁文件完成干净安装，lint、类型检查、单元测试和构建成功。
- 六个模块路由在桌面和移动浏览器可导航与刷新，未知地址显示返回入口。
- 懒加载失败显示可恢复提示，初始化页面不产生业务写入或展示伪造业务记录。
- 构建输出到 dist，生产页面回退与 API、静态资源路由隔离由 server transport 联合验收。

### 流程列表与详情

展示流程列表，进入详情后展示节点与边的结构关系（只读 DAG 视图）。提供定义创建、编辑和节点角色选择，并可从合法定义发起运行。

#### 验收

- 流程列表展示已存流程的名称与基本信息。
- 流程详情页展示节点集合与节点间依赖边，节点类型可区分（agent、script、approval）。
- 提交定义可保存并读回，非法图或不存在的角色引用显示服务端校验错误。
- 从流程发起运行后进入运行详情，运行列表可查询对应记录。

### 角色与模型连接

角色页面提供创建、编辑、复制、删除及提示词、模型、Skills 文件和 MCP 配置。模型连接设置管理服务端点及凭据引用。

#### 验收

- 保存角色配置后重新打开页面，提示词、技能文件和 MCP 条目保持一致。
- 角色选择可用模型连接，删除被引用配置时显示服务端冲突原因。
- 凭据字段使用受控输入或引用，列表、详情与错误提示不回显密钥明文。
- 编辑角色后旧运行显示原快照，新建运行使用更新配置。

### 沙箱与连接状态

展示运行关联的沙箱标识、资源状态和清理结果，并提供获准的文件或连接入口。

#### 验收

- 运行关联与 Gateway 查询结果一致，查询失败和释放失败有明确展示。
- 未就绪的沙箱不提供可用连接，端点访问遵循服务端授权。

### 运行详情

展示单次运行的节点状态、工具轨迹、日志与产物，支持查看各节点的输出与交付物。

#### 验收

- 运行详情页展示每个节点的当前状态。
- 可查看某节点的工具轨迹与日志。
- 可查看运行产生的产物列表与内容。

### 审批操作

在运行详情中对处于等待审批的节点提供放行与打回操作；打回需选择目标环节。

#### 验收

- 等待审批的节点展示放行与打回操作入口。
- 放行后页面反映节点继续执行；打回后反映目标环节重新执行。
- 非等待审批节点不展示审批操作入口。
