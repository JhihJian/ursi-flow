# web

## 功能意图

为流程维护者和运行操作者提供工作流、角色、运行、产物、沙箱、模型连接与对话七域工作台。默认模拟 API 支持浏览器独立验收，覆盖配置管理、运行快照、审批返工、历史产物、模拟资源释放与对话流。live 模式使用同源 `/api`，真实 server API 协议及真实执行链路分别通过联合验收确认。

## 模块地图

工程采用 React 19、TypeScript、Vite、React Router 7、Zustand 和 Tailwind CSS，组件基于 shadcn/ui（Radix UI）以源码形式维护。基础 UI、图标与明暗、主色调样式复用并适配 Grasp，来源与许可证见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 关键功能与验收

### 工程与七域入口

提供可重复安装、检查、构建及桌面和移动导航，明暗与黑白主色调、通用反馈保持一致。

#### 验收

- Node.js 24 下运行 `npm ci`、`npm run check`，完成安装、lint、单元测试、类型检查和默认构建。
- 七域均显示业务页面，根地址进入工作流，运行深链可刷新，未知地址显示 404 与返回入口。
- 桌面侧边栏和移动抽屉均可导航，明暗与黑白主色调切换后刷新各自保持，键盘可跳到主要内容。
- 懒加载失败保留目标地址，恢复后可重新打开。独立浏览器验收执行 `npm run test:e2e`。
- 生产 history 回退、API 和静态资源错误隔离由真实托管环境联合验收。

### 演示数据与模式切换

默认演示模式通过应用 transport 注入模拟 API，以 localStorage 保存演示状态。凭据字段仅使用演示引用，live 模式使用网络 API。

#### 验收

- 未启动 server 时可查询与修改七域演示数据，刷新读回已保存配置、运行快照、事件、产物与对话会话。
- 模拟接口注入不替换全局 fetch，存储访问受限时使用会话内存。
- 演示设置可调整 0 至 30000ms 延迟、使下一次业务请求返回 503，重试恢复；重置确认后恢复种子及初始设置。
- 连接与 MCP 仅填写 `credentialRef`，明确的密钥字段和带内嵌凭据的地址被模拟 API 拒绝。
- `VITE_API_MODE` 支持 mock/live，默认构建包含演示功能，`build:live` 排除模拟 API。live 隐藏演示控制，网络失败显示错误且不回退 mock。
- 模式独立验收确认传输选择，真实路由、DTO、认证及持久化仍需与 server 联合验收。

### 流程定义与发起运行

提供工作流搜索、创建、编辑、复制、删除，使用节点与连线 JSON 维护定义，以只读 DAG 查看 agent、approval、script 类型和依赖。

#### 验收

- 修改并保存合法定义，刷新后名称、描述、节点与边一致；副本修改保持原记录内容。
- 损坏 JSON、重复节点或边、循环依赖、非法端点及无效角色引用显示校验错误，保留输入。
- 从角色列表选择 agent 节点配置，启动时任务输入必填，创建成功后进入返回标识对应的运行详情。
- 独立验收覆盖模拟定义管理与创建跳转，真实引用事务、并发编辑和运行实例化由 workflows、roles、runs 联合验收。

### 角色与模型连接配置

角色工作室维护提示词、模型、执行器、文本 Skills 与 MCP。连接页维护服务商、地址、模型和凭据引用，并显示模拟验证结果。

#### 验收

- 创建、保存和刷新后配置读回一致，复制角色后修改副本不影响原角色。
- 未保存时离开触发确认，取消保留草稿；请求失败保留输入并显示可读错误。
- 删除被流程引用的角色或被角色引用的连接时显示冲突，记录保留。
- 模拟连接验证有等待与结果反馈，修改连接后清除旧结果。真实网络连通性、认证与凭据解析另行联合验收。
- 修改配置后旧运行快照保持原值，新运行使用新值；真实存储事务、完整 Skill 文件包及执行器配置生效由真实服务和执行链路联合验收。

### 运行观测、审批与返工

详情使用串行 GET 轮询，每轮完成后等待 1500ms。模拟后端在运行查询时按约两秒每节点推进依赖就绪节点，审批暂停整个运行。页面依据 API 响应显示节点、事件、快照和操作结果。

#### 验收

- 模拟运行依拓扑顺序逐个执行，慢请求不重叠，终态停止自动轮询，切换运行或卸载页面取消旧读取与定时器。
- 查看任务输入、节点输出、工具与日志事件及冻结配置，重复读取的事件按标识去重，查询失败保留上次成功数据。
- 等待审批时可放行或选择上游祖先打回，返工增加轮次并重置目标及其下游；非等待状态隐藏审批入口。
- 返工保留原快照、历史事件和旧产物。取消需确认，成功后显示终态，关联模拟沙箱释放。
- 独立验收覆盖轮询、模拟审批和历史展示；真实审批并发、generation 与节点级 attempt、持久事件游标、SSE 及迟到执行隔离由真实 runs、transport 和存储联合验收。

### 产物查阅与下载

产物由模拟 API 提供内容与归属，支持名称或路径搜索、运行与轮次筛选、净化 Markdown 预览、源文件和 Blob 下载。

#### 验收

- 筛选后条目与运行、轮次匹配，详情显示节点、路径、时间和执行轮次，关联运行可跳转。
- Markdown 预览显示标题、列表与表格，危险 HTML 经净化；源文件保留文本，下载文件名与内容和所选产物一致。
- 审批返工后可分别读取新旧轮次，模拟沙箱释放后产物仍可读取；空结果和请求错误有明确反馈。
- 独立验收检查模拟内容呈现与下载，真实内容授权、校验、回收、完整归属与当前输出选择由 artifacts、runs 和存储联合验收。

### 沙箱状态、日志与释放

沙箱页展示模拟资源标识、规格、运行关联、状态与生命周期日志，提供确认释放。当前功能范围为模拟状态和操作记录，没有真实连接或终端。

#### 验收

- 可按名称或标识搜索、按状态筛选，详情显示准备与释放日志，可进入关联运行。
- 活动运行释放失败时显示冲突且保持原状态，取消或完成运行后查看已释放状态与记录。
- 查询或释放故障显示可重试反馈，已释放资源隐藏释放操作，已回收模拟产物仍保留。
- 独立验收检查状态展示和模拟释放规则，真实 Gateway 查询、释放结果核实、授权及终端和文件接入需连接 sandboxes 与 Channel 联合验收。

### 对话与流式回复

对话页维护会话列表与消息记录，通过注入的 transport 读取 `application/x-ndjson` 流，逐段渲染助手回复，支持停止与重新生成。演示回复由本地模板生成，不调用模型。

#### 验收

- 新建、切换、搜索和删除会话后刷新，会话标题与消息记录一致；地址栏会话标识是选中状态的唯一来源。
- 发送消息后进入流式状态，助手回复分段出现并渲染 Markdown；推理与工具信息可折叠查看，工具块显示调用状态。
- 流式过程中可停止，停止后保留已接收内容；停止后立即重发不会覆盖新请求的状态。
- 请求失败显示可读错误与重试入口，离开页面中止在途读取；会话列表加载失败显示可重试错误态。
- 独立验收检查演示对话流与交互，真实模型调用、流协议、会话归属与鉴权由 chat 与 server 联合验收。
