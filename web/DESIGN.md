# Web 模块设计与交付边界

## 目标与交付形态

Web 为流程维护者和运行操作者提供六域工作台。默认演示模式通过本地模拟 API 完成配置、启动运行、审批返工、产物查阅和沙箱状态管理，支持前端独立验收。live 模式请求真实网络接口，真实 server API 协议与执行链路分别通过联合验收确认。

工程采用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 Tailwind CSS，以独立 npm 包和锁文件管理依赖。Node.js 24 用于安装与构建，产物输出到 `web/dist`。Pinia 在入口注册，页面状态主要由本域 composable 和组件管理。

基础 UI、图标、明暗主题 tokens 复用并适配 Grasp。应用壳、业务布局与页面围绕 ursi-flow 六域组织，来源与许可证见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 目录与职责

| 模块 | 职责 |
| --- | --- |
| `src/app` 与 `src/main.ts` | 选择 API 模式，装配 Router 和 Pinia，提供应用壳、导航、主题、全局反馈与演示设置入口 |
| `src/shared` | 六域共用 DTO、API 传输、通用组件、请求生命周期、编辑保护和反馈能力 |
| `src/mocks` | 种子数据、模拟 API、配置引用检查、运行调度与审批、快照、事件、产物和模拟沙箱状态，持久化演示数据 |
| `src/modules/workflows` | 工作流目录、JSON 定义编辑、只读 DAG 与发起运行 |
| `src/modules/roles` | 角色工作室、提示词、模型、文本 Skills 和 MCP 编辑 |
| `src/modules/runs` | 运行目录与详情、串行轮询、日志筛选、快照、审批返工和取消 |
| `src/modules/artifacts` | 产物搜索与运行、轮次筛选，Markdown 预览、源文件和下载 |
| `src/modules/sandboxes` | 模拟资源状态、运行关联、生命周期日志和释放操作 |
| `src/modules/connections` | 模型连接配置、凭据引用、模拟验证与引用冲突反馈 |
| `e2e` | 构建产物的浏览器独立验收 |

app 导入各业务域公开的 `routes.ts`，按需加载页面。业务域依赖 shared，shared 保持独立。mocks 使用 shared DTO 并由入口注入 transport。跨域通过共享 API 查询所需数据，通过资源标识与路由地址跳转，业务模块不导入其他域内部组件或状态。ESLint 检查静态导入的依赖方向。

共享 DTO 位于 `src/shared/api/types.ts`，描述前端与演示 API 当前使用的传输结构。真实服务的路由、字段、错误码和认证需要联调对齐，server 规格中的存储模型、generation 和节点级 attempt 等语义另由真实服务契约约束。

## API 模式与数据归属

### 默认演示模式

入口在挂载应用前调用 `startMockApi()`，通过 `setApiTransport()` 注入模拟请求实现。业务页面统一使用 shared API。注入只影响应用请求入口，全局 `fetch` 保持浏览器原行为。

演示后端默认以 localStorage 的 `ursi-flow-demo-v1` 键保存配置、运行快照、进度、事件、产物、沙箱和控制设置。首次加载生成独立种子，刷新读回保存状态。存储访问被禁止时入口使用会话内存，保存失败返回服务错误。localStorage 是演示数据存储，连接及 MCP 凭据字段仅使用演示引用，真实密钥由服务端凭据来源管理。

模拟控制包含默认 180ms 请求延迟、0 至 30000ms 可调延迟、下一次业务请求返回 503 和重置种子。控制请求自身不消费一次性故障。配置及运行状态由 mocks 完整校验后提交，页面根据 API 响应显示结果。

### live 模式

`.env` 中的 `VITE_API_MODE` 支持 `mock` 与 `live`。默认开发和构建包含演示功能，`dev:live` 和 `build:live` 使用 Vite live 模式，live 构建排除模拟 API。页面在 live 模式中隐藏演示设置，传输使用同源网络请求，网络失败不回退模拟数据。

共享 HTTP 入口添加 `/api` 前缀与同源凭据设置，接受相对路径、传递取消信号、保留 JSON 响应结构，204 返回空值。HTTP 错误只公开状态码和白名单提示，原始上游正文留在传输边界。类型声明描述静态契约，运行时协议一致性通过真实 API 联调验证。

Vite 开发代理将 `/api` 转发到 `URSI_API_PROXY`，默认 `http://127.0.0.1:8080`。生产由同源服务处理 `/api`，preview 只用于静态预览。`VITE_*` 属于浏览器构建配置，`URSI_API_PROXY` 属于开发服务配置。

## 核心业务流程

### 配置与启动快照

模型连接供角色选择，角色供工作流 agent 节点引用。角色管理文本 Skills 与结构化 MCP，工作流编辑名称、描述及节点、连线 JSON，依赖图用于只读检查。保存时页面给出格式与必填项反馈，模拟 API 校验引用、重复节点与连线、依赖环等约束。

创建运行时提交工作流标识、任务输入和可选名称。模拟 API 深拷贝流程、实际引用的角色与连接，创建运行及关联沙箱后返回运行标识。旧运行始终展示冻结快照，新运行读取最新配置。删除被流程引用的角色或被角色引用的连接返回冲突。

### 顺序推进与串行读取

模拟后端按 DAG 依赖逐个调度，每个运行同时最多一个节点执行。agent 和 script 节点使用约两秒的模拟耗时，脚本内容和模型配置仅用于演示定义。GET 运行列表或详情时根据时钟推进到相应状态，长间隔查询可顺序补推进多个节点。

运行详情通过 GET 读取完整状态，每轮读取完成后等待 1500ms 再开始下一轮。产物按运行查询，并依据运行更新时间或重试条件刷新。慢请求串行执行，终态停止自动轮询。切换运行或卸载页面清理定时器并取消在途读取，过期响应不能覆盖新页面。读取失败保留上次成功状态并提供重试。

事件按 API 事件 ID 合并去重，前端序号用于阅读定位。当前机制为完整响应轮询，服务端持久游标、SSE 重放与断线补读另属真实服务接入验收。

### 审批返工与历史

依赖就绪的审批节点暂停整个模拟运行。放行后继续调度；打回只接受当前审批的上游祖先，重置目标及其下游，增加运行级 `attempt`，保留其他已完成分支。配置快照、旧事件和历史产物持续保留。

页面审批或取消操作等待在途读取完成，提交期间暂停轮询，最终依据 API 响应更新状态。全部节点成功或确认取消后，模拟后端将关联沙箱设为已释放。活动运行的手动释放请求返回冲突。

演示 `attempt` 是运行级轮次，产物 DTO 包含 `runId`、`nodeId` 和 `attempt`。真实服务的 generation、节点累计 attempt、迟到结果隔离与当前有效输出选择需在联合验收中对齐。

### 产物与沙箱

产物内容由模拟 API 返回。页面按名称或路径搜索、按运行和执行轮次筛选，Markdown 经 marked 解析及 DOMPurify 净化后显示，源文件以文本呈现，下载从所选内容创建 Blob 并释放对象 URL。内容预览与下载验证同一份模拟内容。

沙箱页面显示模拟标识、镜像、规格、目录、运行关联、状态和生命周期日志，提供确认释放与失败反馈。当前页面没有真实终端、IDE、文件通道或远程连接。真实资源准备、连接授权、文件往返和释放核实由 sandboxes、Gateway 与 Channel 联合验收。

## 应用壳与通用交互

六个一级地址为 `/workflows`、`/roles`、`/runs`、`/artifacts`、`/sandboxes`、`/connections`。运行详情位于 `/runs/:id`。根地址进入工作流，未知地址显示 404，懒加载失败保留目标地址并提供重新打开入口。

桌面使用侧边导航，小屏使用顶部按钮打开抽屉。主题在挂载前应用，偏好存于独立 localStorage 键。通用组件统一加载、空态、错误、确认、通知与未保存编辑保护。模态框提供焦点约束与恢复，标签页支持键盘切换，页面提供跳到主要内容入口。

## 验收边界

| 层次 | 环境 | 可观察结果与范围 |
| --- | --- | --- |
| 前端独立验收 | Vitest 接口替身、模拟 API、内存或浏览器存储 | 六域表单与状态、请求错误、引用冲突反馈、快照展示、审批返工、轮询清理、产物内容和模拟沙箱释放 |
| 浏览器独立验收 | 默认构建与 Playwright、桌面和移动 Chromium | 导航、深链、主题、键盘、故障恢复，以及两种尺寸下的配置和运行闭环、历史产物与下载 |
| 真实 API 联合验收 | live 前端、真实 transport、业务域和持久化存储 | 路由与 DTO、认证、事务引用、快照一致性、审批冲突、实际产物归属、持久事件和生产路由处理 |
| 真实执行联合验收 | Gateway、Channel、Agent Runtime、session-service 和 CLI | 真实凭据解析、模型与脚本执行、配置渲染、资源连接、产物回收、迟到结果隔离与释放核实 |

前端独立验收操作与命令见 [README](README.md)。真实 API 与执行链路需要各自的联合验收证据，live 模式本身只确定请求目标。

## 静态托管

生产资源部署于站点根路径 `/`，页面深链由静态服务回退 `index.html`。`/api`、`/api/*` 和 `/assets/*` 等资源由各自处理器响应，缺失 API、脚本或样式返回对应错误。server transport 或独立静态服务的路由隔离需联合验收，Vite preview 用于本地构建产物检查。
