# PlanWeave 独立前端演示

## 功能意图

在浏览器里独立体验 PlanWeave 的 TODO 和 Canvas Map。界面沿用上游组件和主题，两页共享同一个样例项目。部署只需要静态文件服务器。

## 关键功能与验收

### 工作区结构

#### 验收

- 视口宽度达到原版桌面窗口下限 1100 px 时，左右区域并排。两页共用宽 280 px 的左侧项目导航和高 44 px 的工作区标题栏。Canvas Map 的右侧检查器宽 320 px，TODO 的右侧组件栏宽 300 px，中间工作区填满剩余宽度。
- 点击左侧项目名回到 Canvas Map。点击画布名或任务名时，在整张项目任务图上定位对应的一组节点或单个节点。定位只改变视口和高亮，保留所有画布的节点、坐标与连线。平移后再次点击同一项可重新定位。
- 任务图显示样例任务节点、依赖线和任务块。点击任务块打开详情，关闭后保留当前节点和视口。TODO 及任务图的右侧组件栏展示节点和任务块分类。窄屏通过标题栏按需打开项目栏或组件栏。

### TODO 状态与任务块

#### 验收

- 页面展示六类待办状态和整体分布，各画布阶段按待办状态统计就绪与阻塞数，并列出就绪待办。
- 状态卡片展示负责人、依赖阻塞与评审门禁。从阶段列表或状态卡片打开任务块，关闭详情或按浏览器返回后仍在原列表位置。
- 可在现有任务下新建待办，查看详情，编辑标题、状态、负责人和说明，并确认删除。分组超过六条时可展开全部待办。
- TODO、任务图和地图检查器使用同一份待办。保存后统计和详情随之更新，切页和刷新后仍可读取。写入失败时保持已保存的数据和当前草稿，可重试。
- 待办仍被其他待办依赖或评审门禁引用时，显示引用方并保留该条目。删除仅影响待办，保留所属任务、节点位置和任务之间的依赖。

### Canvas Map 浏览与本地编辑

#### 验收

- 地图支持平移、缩放、缩略图和节点拖拽。选择节点或依赖线后，检查器展示对应详情，并可跟随阻塞线索跳转到画布或任务节点，或打开任务块的只读详情。
- 拖拽位置在切页和刷新后保留。保存失败时可重试；重置布局只恢复节点坐标，保留已保存的画布名称和策略。
- 重命名和执行策略修改保存到当前浏览器。最大并发数只接受正整数；执行策略仅供演示。

### 静态运行

#### 验收

- 静态站点可直接打开 TODO 和地图的哈希地址，支持中文、英文、明暗主题及窄屏浏览。
- 阻断 API 和第三方网络请求后，仍可从本地静态资源加载两页并完成页面交互。
