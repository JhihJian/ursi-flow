# 工作区外壳

## 功能意图

`@ursi/workspace-shell` 为宿主提供多栏工作区骨架：按模块列表排出可折叠的栏，维护全局选中，把选中交给工作区区域渲染，并在右侧按选中给出模块声明的上下文操作。外壳不认识任务、运行、会话等领域概念，也不发请求。

## 关键功能与验收

### 模块栏与折叠

宿主传入 `modules` 数组，每项声明 `id`、`title`、`Panel`、可选 `Rail`、默认与最小宽度。外壳用 `react-resizable-panels` 排列，每栏可折叠到 32px。

#### 验收

- 展开态每栏显示标题行与模块内容，标题行右侧 `«` 折叠；折叠后只渲染 32px 窄条，窄条内 `»` 与竖排标题可展开回折叠前宽度。
- 拖拽分隔线可调整栏宽，宽度与折叠状态写入浏览器本地，刷新后恢复。
- 模块不传 `Rail` 时使用外壳的默认窄条。

### 顶部与底部横栏

宿主可选传入 `top` 与 `bottom`，每项含 `title`、`content`、`defaultSize`、`minSize`、`collapsible`。外壳把它们放在主区上方与下方，用垂直分隔线调整高度。

#### 验收

- 传入 `top` 或 `bottom` 时，横栏在主区上下占位，初始高度取 `defaultSize`（缺省 140px），拖拽分隔线可改高度。
- 横栏可折叠为 28px 摘要条，摘要条显示标题与展开按钮，点击任意一处恢复折叠前高度；`collapsible: false` 时不显示折叠按钮。
- 横栏高度与折叠状态写入浏览器本地，与主区列宽分开保存，互不覆盖。
- 未传入时上下不留空白。

### 全局选中与工作区区域

外壳维护唯一选中 `Selection = { kind, id, label? }`，模块用 `useWorkspace().select` 写入。工作区区域按 `selection.kind` 找模块声明的 `WorkspaceView` 渲染。

#### 验收

- 一个模块选中后，其他模块与工作区区域读到同一份选中，不需要各自保存。
- 选中的 `kind` 没有任何 `WorkspaceView` 时显示占位说明，不显示空白。
- 选中只保存类型与 ID，实体由模块按 ID 自取。

### 上下文操作

模块通过 `actions` 声明操作项，含 `appliesTo`、`run`、可选 `disabledReason` 与 `confirm`。

#### 验收

- 右侧操作栏只列出 `appliesTo(selection)` 为真的操作，未选中时为空态说明。
- 操作执行期间按钮显示进行中文案并禁用其他操作；失败时在操作栏显示错误，不丢失当前选中。
- 声明了 `confirm` 的操作先请求确认，取消后不执行。

## 边界

- 不提供路由、鉴权、数据获取和领域状态。
- 不做运行时插件加载，模块在构建期登记。
