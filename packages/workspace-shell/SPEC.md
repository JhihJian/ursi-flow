# 工作区外壳

## 功能意图

`@ursi/workspace-shell` 为宿主提供多栏工作区骨架：按模块列表或页面 profile 排出可折叠的栏与区域，维护全局选中，把选中交给工作区区域渲染，并在操作栏按选中给出模块声明的上下文操作。外壳不认识任务、运行、会话等领域概念，也不发请求。

## 关键功能与验收

### 模块栏与折叠

宿主传入 `modules` 数组，每项声明 `id`、`title`、`Panel`、可选 `Rail`、默认与最小宽度。外壳用 `react-resizable-panels` 排列，每栏可折叠到 32px。

#### 验收

- 展开态每栏显示标题行与模块内容，标题行右侧 `«` 折叠；折叠后只渲染 32px 窄条，窄条内 `»` 与竖排标题可展开回折叠前宽度。
- 模块声明 `hideHeader: true` 时不渲染标题行，模块内容直接贴到栏顶，折叠入口改为分隔线顶部 4px 处的 `‹`（18×34，纵向加大命中区），常驻显示、不遮挡模块内容，指针保持 `pointer`；分隔线其余部分仍可拖动改宽。
- 拖拽分隔线可调整栏宽，宽度与折叠状态写入浏览器本地，刷新后恢复。
- 模块不传 `Rail` 时使用外壳的默认窄条。

### 区域与页面 profile

宿主传入 `profiles`（`WorkspaceProfile[]`）后，外壳按 profile 排布：根布局横向排区域，区域内条目按区域声明的方向（`direction`，缺省 `vertical`）叠放。条目三种：模块栏（`module`）、工作区（`workspace`）、操作栏（`actions`）。提供 ≥2 个 profile 时标题栏出现切换器；未传 `profiles` 时保持单横向平铺全部模块的历史行为。

#### 验收

- 切换 profile 后区域布局与模块集合立即切换；布局与折叠状态按 `${storageKey}:${profile.id}` 隔离持久化，互不影响；当前 profile 存在 `${storageKey}:profile`。
- 纵向区域内模块契约的尺寸字段（`defaultSize`/`minSize`/`maxSize`/`collapsedSize`）作用于该区域的排列轴即高度；折叠窄条变为横排书脊（水平变体），展开按钮纵向指向。
- 区域声明 `defaultSize` 时作为该区域在根布局的默认宽度（仅多区域 profile 生效，缺省 720px）。
- profile 引用了未注册的模块 id 时，该条目显示占位说明，其余条目不受影响。
- 切换 profile 会整体重挂布局表面：iframe 类模块（`keepMounted`）会重载一次，属可接受的低频行为。

### 标题栏与状态栏

外壳自带一条标题栏和一条状态栏，都不参与分栏、不可拖拽：标题栏 40px，左侧显示 `title`，右侧显示 `settings`（未提供 `settings` 但给了 `onSettings` 时渲染默认设置按钮）；状态栏 24px，左侧显示当前选中的摘要，右侧显示宿主的 `status`。

#### 验收

- 标题栏固定在顶部，状态栏固定在底部，中间主区占满剩余高度，两者的高度不随窗口或分栏变化。
- 点击标题栏右侧设置按钮会触发宿主传入的设置入口；未提供任何设置入口时按钮不渲染。
- 状态栏左侧随全局选中更新，未选中时显示 `No selection`；右侧显示宿主给的 `status`，缺省为空。
- 设置这类不占栏的页面通过 `views` 注册，选中后占用工作区区域，不影响模块栏。

### 全局选中与工作区区域

外壳维护唯一选中 `Selection = { kind, id, label? }`，模块用 `useWorkspace().select` 写入。工作区区域按 `selection.kind` 找模块声明的 `WorkspaceView` 渲染。

#### 验收

- 一个模块选中后，其他模块与工作区区域读到同一份选中，不需要各自保存。
- 选中的 `kind` 没有任何 `WorkspaceView` 时显示占位说明，不显示空白。
- 选中只保存类型与 ID，实体由模块按 ID 自取。

### 上下文操作

模块通过 `actions` 声明操作项，含 `appliesTo`、`run`、可选 `disabledReason` 与 `confirm`。

#### 验收

- 右侧操作栏只列出 `appliesTo(selection)` 为真的操作，未选中时为空态说明。
- 操作执行期间按钮显示进行中文案并禁用其他操作；失败时在操作栏显示错误，不丢失当前选中。
- 声明了 `confirm` 的操作先请求确认，取消后不执行。

### 折叠摘要由外壳排版

折叠由外壳负责：模块只通过 `useCollapsedSummary()` 公布关键信息 `{ title, items: [{ label, value }] }`，外壳用竖排书脊式布局渲染，不接收模块自绘的折叠 UI。

#### 验收

- 折叠后窄条只渲染外壳排版：模块标题、以及每项 `label` 与 `value`，各项之间留 18px 间距；未提供该钩子时显示模块标题。
- 模块公布的信息变化时窄条随之更新，不需要展开再收起。
- 窄条整体可点击，点击后回到折叠前宽度。
- `useModuleColumn()` 仍可用于模块内部请求栏宽，与折叠互不影响。

## 边界

模块接入的具体规范见 [MODULE-CONTRACT.md](MODULE-CONTRACT.md)。

- 不提供路由、鉴权、数据获取和领域状态。
- 模块的接入要求（契约、样式作用域、副作用开关、交付物与检查清单）写在 `MODULE-CONTRACT.md`。
- 不做运行时插件加载，模块在构建期登记。
