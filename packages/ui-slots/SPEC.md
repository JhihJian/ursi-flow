# UI 插槽

## 功能意图

为 React 宿主提供类型化插槽。宿主声明插槽名和组件 props，插件注册和移除各自的界面贡献。注册表独立维护内存状态，React 运行时仅用于订阅和渲染。

## 关键功能与验收

### 注册和订阅插槽贡献

#### 验收

- `createSlotRegistry<Slots>` 按传入的名称声明插槽。`register` 和 `entries` 按槽名约束组件 props，运行时拒绝未声明的槽。同槽的重复 ID 被拒绝，不同槽可使用相同 ID。
- 快照按 `order` 数值升序排列，省略时按 `0` 处理。同序按 ID 的字符串顺序排列，与注册顺序无关。槽内容未变时 `entries` 返回同一快照，空槽返回稳定的空数组。
- 注册及实际移除贡献后通知订阅者。重复调用移除函数不会再次通知或移除随后以同一 ID 注册的贡献。取消订阅后不再收到通知。

### 渲染插槽贡献并隔离错误

#### 验收

- `useSlotEntries` 在快照变化时更新宿主。宿主可在快照为空时省略可选布局。`SlotContent` 将 `context` 作为 props 传给每个贡献，不添加布局容器。
- 单个贡献的 React 渲染错误只在该贡献的位置显示通用提示，其他贡献仍正常渲染。已注册的贡献重新排序时保持渲染键，移除并重新注册同一 ID 后获得新键，可以从失败状态恢复。
