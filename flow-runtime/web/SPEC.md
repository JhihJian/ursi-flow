# Flow 控制台

## 功能意图

面向本机 Runtime 的独立控制台。操作者不经工作台和 CLI 即可维护 Flow 包、启动和停止运行、检查节点与路由证据、修改执行配置。交付物为静态包，可单独发布，也可嵌入工作台。

## 关键功能与验收

### 独立交付与同源接口

静态包由同目录的 `server.mjs` 托管，同源 `/api/v1` 请求被翻译成 daemon 的一次 Unix socket 请求。接口路径、请求体与工作台的 Flow 接口一致，嵌入时复用同一份前端代码。

#### 验收

- 只发布 `dist/` 就能在普通静态站点的子目录打开演示页面；刷新详情、返回列表都不需要服务端路由回退。
- 页面不做访问令牌验证。实时模式只需工作目录；工作目录缺失时进入演示模式。daemon 未启动返回 503，页面显示错误且不切换到演示数据。
- 服务只接受 IP 字面量、`localhost` 或 `URSI_FLOW_WEB_HOSTS` 登记的域名作为 Host，其他 Host 返回 403；写请求只接受同源页面发起，跨站写入与跨站 Origin 返回 403。
- 启动运行只使用服务端固定的 `default` 工作区；请求其他工作区返回 400，且不向 daemon 发起运行。
- 校验失败、修订冲突等业务原因随响应返回并显示在页面上，不被替换成固定文案。
- 详情新增两个 GET：`runs/:id/flow` 返回该运行固定修订的包，`runs/:id/nodes/:nodeId/trajectory` 返回节点执行的会话切片。嵌入工作台时宿主需要转发同样两个接口；会话轨迹可能包含 `data:` 图片，页面 CSP 允许同源与 `data:` 图片。

### 包与运行的内部闭环

#### 验收

- 可以创建、编辑、校验、保存和删除包，编辑 `FLOW.md` 及 `references/`、`scripts/` 下的文件。保存携带当前修订；修订过期返回 409，页面保留草稿并提示冲突。
- 点击启动运行先弹出参数框，填写 Run ID 与启动变量后提交，成功后进入该运行详情。运行中自动刷新，确认后可停止，终态以服务端返回为准。
- 参数表单由 `FLOW.md` 元信息的全局变量声明生成：每项显示名称、用途说明、必填或可选，有 `default` 的可留空交给 Runtime 取默认值。表单在浏览器内转成 JSON 提交，不需要额外接口。
- 过程中由节点写入的变量不进入表单：结果变量表声明过的名字，以及节点正文里用 `variables.x` 或「全局变量 `x`」写回的名字视为运行时状态；这类变量带默认值时只在参数框里列出名称和初始值。
- 原始 JSON 作为高级入口，可在参数框内切换。高级模式只接受已声明的全局变量，出现未声明的名字或缺少必填项时在框内报错，不发起运行。
- 详情分「Flow 流转」与「节点执行」两类记录，共用同一份运行事实；运行尚未提交事实时集合按空展示，不中断页面。
- 运行配置可读取并保存模型 provider（服务地址、密钥、模型标识、协议与可选的上下文窗口、单次回复上限、推理标记、思考强度）和并发上限，执行器保持 `local-pi`。密钥只回传“是否已配置”，页面不回显，留空保存表示沿用原值。
- provider 缺任一必填项时，配置页说明缺哪些字段，编辑页禁用“启动运行”并给出跳转入口；服务端同样拒绝启动并列出缺项。
- Agent 节点执行失败时，节点事实与运行记录展示失败原因，不只显示状态码；模型拒绝请求或协议错误的原因来自 provider 返回内容。

### 运行详情的流转图与节点执行记录

#### 验收

- 流转图按运行启动时固定的目录修订读取 `FLOW.md` 绘制，不跟随之后发布的修订；修订不可读或图无法解析时只说明原因，节点执行记录仍可查看。
- 图的节点用运行事实标出未到达、运行中、已完成、失败与中断，当前节点带独立标记；进入过的节点显示访问次数，并行开始点按轮次计。开始节点到首个节点的边、并行分支边与路由决策走过的结果边都标为已走过，没走过的边保持淡显。
- 点选图中节点跳到该节点最近一次执行的记录；同一节点被多次访问时保留全部记录，并说明当前看的是第几次。
- 节点执行记录列全部节点访问。Agent 节点用 Pi 会话轨迹展示消息、思考、工具调用与结果；命令节点展示标准输出与标准错误；执行Flow 节点给出子 Run 入口。每条记录同时保留输入、结果、错误与来源。
- 轨迹来自 daemon 按节点执行保存的 Pi 会话 JSONL 切片。运行中的节点可读到已产生的部分轨迹；旧运行或未产生轨迹的节点说明“还没有会话轨迹”，不报整页错误。轨迹超过服务端上限时不加载全文，只说明大小。
- 「运行参数与启动变量」「路由证据」「子 Run」「并行轮次」「恢复记录」「原始事实」仍可查看；停止、刷新与运行状态不因切换记录类型而消失。
- 详情页的选中记录类型与节点写入地址栏参数，刷新后停在同一条记录。

### 图形与文档编辑

#### 验收

- 图形视图按 `FLOW.md` 的 Mermaid 图渲染节点卡片与结果边，可新增、改名、删除节点，增删改结果边并改连目标。开始节点只保留一条出边；命令节点只保留一条“已执行”出边；执行Flow 节点使用无结果直连边。
- 画布自左向右分层，端口在卡片左侧入口、右侧出口，连线沿分层走线绕开卡片；回边（返工、重试）不进分层，统一从图形下方绕回。布局与节点位置只存在于界面，不写回 `FLOW.md`。
- 拖拽节点只更新被拖节点与相连连线，不触发包内容变化，也不重算整图；拖过的位置在切换选中、编辑名称后保留，“自动布局”可恢复分层位置。
- 图比可视区宽时保留可读缩放并贴住流程起点，不把整图缩到看不清；结果名标在来源卡片的出口行上，选中连线时才在画布上重复显示。
- 图形操作后 `FLOW.md` 的图语句与节点小节同步重写，节点提示词、结果说明等正文逐字保留，新增结果小节自动带非空占位说明。结构问题在画布上列出，例如孤立节点、缺少到结束的路径。
- 文档视图用 marked 渲染 Markdown、用 mermaid 就地绘制代码块，渲染结果经 DOMPurify 清洗；包内相对链接按当前文件所在目录解析并直接打开对应文件。
- 元信息以键值块展示，不参与正文标题层级。
- 包内容按文件类型提供编辑视图，不提供 FLOW.md 的源码视图：`FLOW.md` 用图形或文档视图，`references/` 下的 Markdown 用文档视图，`scripts/` 下的脚本用脚本视图。FLOW.md 解析失败时文档视图仍能改写原文，包不会在控制台里无法修复。
- 改动作类型时同步修正出边，不留规范不允许的组合：命令节点收敛为一条“已执行”出边，执行Flow 收敛为无结果直连边，Agent 节点补齐缺失的结果名；跨族的动作切换换成该类型的默认正文，族内切换保留原文。

### 演示数据与外观

#### 验收

- 未配置 Runtime 时页面标注“演示数据”，样例覆盖成功、失败、运行中与已停止的运行，并带两段可渲染的节点会话轨迹；演示模式不发起 `/api` 请求，也不写入任何数据。
- 页面采用与工作台一致的主题变量，同源时读取 `ursi-flow:theme` 与 `ursi-flow:palette` 外观偏好；桌面与窄屏都不产生横向滚动。
- 界面由 `src/components/ui` 下的 shadcn 组件组装：列表用 `Item`/`ItemGroup` 与 `Table`，表单用 `Input`/`Textarea`/`Select`/`Label`，动作用 `Button`，状态与提示用 `Badge`/`Alert`/`Empty`，视图与确认用 `Tabs`/`Dialog`。页面样式只补画布、Markdown 与主题变量，不用全局元素选择器覆盖组件。
