# agent-runtime

## 功能意图

agent-runtime 定义 agent 的可控接口：会话生命周期（启动、执行、终止）、prompt 下发、能力配置渲染、工具轨迹与日志的事件回流。它是 kernel 驱动 agent 的协议层，只约定接口与数据契约，不绑定具体 CLI；具体 CLI 适配由 agent-cli-adapter 实现。传输（命令执行、文件交换）经 channel 提供的通道完成，本模块不感知通道的底层实现。

## 关键功能与验收

### Agent 可控接口

定义 `Runner` 接口：接收输入（提示词、上游产物上下文、运行上下文、执行环境句柄）与配置（模型、Skills、MCP、凭据），返回结果（输出、产物、用量、错误）。server 仅依赖该接口，不感知具体 CLI。

#### 验收

- `Runner` 接口可被 server 依赖调用，具体适配器实现该接口。
- 执行成功返回输出与产物；执行失败返回非空错误。

### 能力配置渲染

把角色能力定制字段渲染为具体执行器可消费的配置：提示词写入任务描述，模型与思考强度转为 CLI 参数，Skills 物化为技能文件，MCP 工具渲染为 CLI 的 MCP 服务配置。渲染职责的接口在本模块约定，实现由 agent-cli-adapter 承担。

#### 验收

- 给定一个含模型与 MCP 工具的角色，渲染后生成的 CLI 配置包含对应模型参数与 MCP 服务条目。
- 给定含 Skills 的角色，渲染后在执行环境中物化对应技能文件。

### 流式事件回流

执行过程中把工具轨迹与日志以 domain 的 `TelemetryEvent` 契约上报给事件接收方，供过程可观测使用。接口预留观测上报口，sandbox-observe 的采集不改变本接口形状。

#### 验收

- 执行器运行期间产生的工具调用与日志以 `TelemetryEvent` 形式持续上报。
- 事件上报不影响执行器的最终结果返回。
