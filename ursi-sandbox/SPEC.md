# ursi-sandbox

## 功能意图

为独立工具和工作流引擎提供同一种可回收的执行环境。调用方拥有任务的业务含义，沙箱拥有资源和执行状态。交付包括 Gateway、Runtime 和 Client。

## 关键功能与验收

### 独立构建与交付

沙箱独立锁定构建依赖。镜像提供系统程序，bundle 提供会话服务和监督配置，管理员在运行时供应最小配置。

#### 验收

- 只取本目录，在具有 Linux 构建工具和依赖的机器上能按锁文件构建三个二进制并打包 bundle，不需要 Flow 源码、数据库或服务。
- 镜像和 bundle 不包含管理员模型凭据、SSH 私钥或服务令牌。

### 公共协议执行

Gateway 负责供应和回收，Runtime 负责会话。独立客户端或 Flow 可以通过同一 ACP WebSocket 子集提交文本任务，SSH/SFTP 独立访问工作区。

#### 验收

- 已准备工作区后，两个调用方均可创建会话、收到文本及完成响应、显式关闭会话。断线不能视为任务完成或允许重放。
- 重启沙箱保留数据；显式删除后所属容器与数据卷释放。应用层的角色选择、审批、重试和产物归属不进入沙箱协议。
