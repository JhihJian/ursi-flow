# 沙箱资源控制台

## 功能意图

供运维人员管理一个 Gateway 命名空间的实例生命周期，并查看状态、端点及日志。

## 关键功能与验收

### 浏览与检查

#### 验收

- `/sandboxes` 可通过带计数的状态控件筛选实例，桌面使用表格，窄屏使用列表。详情以工作台为主区，规格、端点和按需读取的日志在同一检查区内折叠展示，窄屏时检查区移到工作台下方。直接打开或刷新详情 URL 仍可读取这些信息。
- 空列表、筛选无匹配及请求失败分别呈现。请求失败可重试。

### 管理操作

#### 验收

- 管理员可通过快速创建表单填写镜像、命令和资源，由前端转换为不含端点字段的 SandboxSpec JSON 后提交；也可切换到 JSON 编辑直接提交完整规格。端点由 Gateway 注册表生成，页面只展示逻辑端点状态，不展示地址。查询到运行后可停止、再次启动，也可选择保留数据或销毁数据重建；重建和删除收在更多操作菜单内，需要单独确认。页面依据 Gateway capabilities 隐藏不支持的重建方式。显式确认删除后，等到 Gateway 返回资源不存在才返回列表。
- 只读身份和无身份请求不能执行管理操作；静态演示不改变 Gateway 资源。创建、启停、重建、删除和注册表更新均通过同源服务端代理完成，Gateway 密钥不进入浏览器。

### 端点使用边界

#### 验收

- 沙箱详情统一提供终端、IDE、桌面和应用预览。终端使用 xterm.js 和 SSH PTY，收发输入输出并同步终端尺寸。桌面使用 noVNC，默认只读并可开启键鼠。IDE 与应用由服务端通过已验证主机指纹的 SSH 会话，在沙箱 Chromium 中打开；控制台只接收画面，不在控制台来源中执行沙箱脚本。应用只能选择管理员注册且已就绪的 HTTP 端点。
- 实时连接仅限管理员同源 WebSocket，要求实例运行、无待处理操作、代际匹配以及所需端点就绪。工作台用可键盘手动激活的标签切换视图。刷新详情时保留同实例、同代际且仍符合条件的连接。切换或离开工作台面板、刷新失败、代际变化或连接条件不再满足时释放连接，恢复后须手动连接。Gateway 密钥、SSH 私钥与主机指纹留在服务端。SFTP、ACP 和独立 SSH 命令继续由 Client 使用。
- 静态演示展示本地只读终端样例与工作台入口，不请求任何真实端点。

### 独立交付与身份

#### 验收

- 控制台独立构建，产物可在普通静态站点的子目录运行；刷新详情、返回列表均无需服务端路由回退。页面采用与 Workbench 一致的明暗及黑白主题变量，同源时读取相同的外观偏好。演示数据有明确标记，无需 Gateway。
- 查看者和管理员使用独立密码。界面控件使用独立的 shadcn/ui 组件封装，组件由 Radix UI、CVA 和 Tailwind 提供交互与样式基础。页面依据当前身份开放操作，代理再次鉴权，Gateway 密钥只在服务端使用。
