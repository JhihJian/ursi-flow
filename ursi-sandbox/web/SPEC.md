# 沙箱资源控制台

## 功能意图

供运维人员管理一个 Gateway 命名空间的实例生命周期，并查看能力、状态、端点及日志。

## 关键功能与验收

### 浏览与检查

#### 验收

- `/sandboxes` 可按名称、ID、镜像和状态筛选。桌面与窄屏均可从列表进入详情，刷新详情 URL 后仍可读取规格、端点和日志。
- 空列表、筛选无匹配及请求失败分别呈现。请求失败可重试。

### 管理操作

#### 验收

- 管理员按 SandboxSpec 创建沙箱；查询到运行后可停止、再次启动。显式确认删除后，等到 Gateway 返回资源不存在才返回列表。
- 只读身份和无身份请求不能执行管理操作；静态演示不改变 Gateway 资源。

### 独立交付与身份

#### 验收

- 控制台独立构建，产物可在普通静态站点的子目录运行；刷新详情、返回列表均无需服务端路由回退。页面采用与 Workbench 一致的明暗及黑白主题变量，同源时读取相同的外观偏好。演示数据有明确标记，无需 Gateway。
- 查看者和管理员使用独立密码。界面控件使用独立的 shadcn/ui 组件封装，组件由 Radix UI、CVA 和 Tailwind 提供交互与样式基础。页面依据当前身份开放操作，代理再次鉴权，Gateway 密钥只在服务端使用。
