# 沙箱资源控制台

## 功能意图

供运维人员管理一个 Gateway 命名空间的实例生命周期，并查看状态、端点及日志。

## 关键功能与验收

### 浏览与检查

#### 验收

- `/sandboxes` 可通过统计卡片按状态筛选。桌面与窄屏均可从列表进入详情，刷新详情 URL 后仍可读取规格、端点和日志。
- 空列表、筛选无匹配及请求失败分别呈现。请求失败可重试。

### 管理操作

#### 验收

- 管理员可通过快速创建表单填写镜像、命令和资源，由前端转换为不含端点字段的 SandboxSpec JSON 后提交；也可切换到 JSON 编辑直接提交完整规格。端点由 Gateway 注册表生成，页面只展示逻辑端点状态，不展示地址。查询到运行后可停止、再次启动，也可选择保留数据或销毁数据重建；页面依据 Gateway capabilities 隐藏不支持的重建方式。显式确认删除后，等到 Gateway 返回资源不存在才返回列表。
- 只读身份和无身份请求不能执行管理操作；静态演示不改变 Gateway 资源。创建、启停、重建、删除和注册表更新均通过同源服务端代理完成，Gateway 密钥不进入浏览器。

### 端点使用边界

#### 验收

- Web 页面闭环覆盖沙箱控制面、管理员注册表和端点工作台。SSH、SFTP、ACP 仍由独立 Client 通过 Gateway bridge 承载；页面不实现通用 TCP 转发，也不把 Gateway key、容器地址或宿主端口交给浏览器。IDE、CDP、noVNC 由服务端专用适配器提供受控连接，只有对应 Runtime bundle 实际交付且端点 ready 时才显示入口。

### 独立交付与身份

#### 验收

- 控制台独立构建，产物可在普通静态站点的子目录运行；刷新详情、返回列表均无需服务端路由回退。页面采用与 Workbench 一致的明暗及黑白主题变量，同源时读取相同的外观偏好。演示数据有明确标记，无需 Gateway。
- 查看者和管理员使用独立密码。界面控件使用独立的 shadcn/ui 组件封装，组件由 Radix UI、CVA 和 Tailwind 提供交互与样式基础。页面依据当前身份开放操作，代理再次鉴权，Gateway 密钥只在服务端使用。
