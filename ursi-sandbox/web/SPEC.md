# 沙箱资源控制台

## 功能意图

供运维人员独立查看一个 Gateway 命名空间的实例、资源、端点及日志。

## 关键功能与验收

### 浏览与检查

#### 验收

- `/sandboxes` 可按名称、ID、镜像和状态筛选。桌面与窄屏均可从列表进入详情，刷新详情 URL 后仍可读取规格、端点和日志。
- 空列表、筛选无匹配及请求失败分别呈现。请求失败可重试。

### 独立交付与只读访问

#### 验收

- 控制台可从本目录独立安装、构建、启动。演示数据有明确标记，无需 Gateway。
- 真实数据模式要求独立查看密码，浏览器接收的数据源配置不含 Gateway 密钥。控制台只开放列表、详情和限定行数的日志查询。
