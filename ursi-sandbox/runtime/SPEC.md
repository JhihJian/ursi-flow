# 通用启动支持

## 功能意图

为 SSH 及其扩展镜像提供统一的启动、归档验证、工作区准备与常驻进程监督。镜像提供可信的 profile 检查，已校验的归档提供服务及监督配置。

## 关键功能与验收

### 安装并启动指定归档

bootstrap 检查镜像级别、profile、路径、归档及文件摘要，通过后从按摘要安装的目录启动 supervisord。

#### 验收

- 拒绝损坏归档、非法路径或扩展头、不匹配的 profile、级别过低的镜像。
- 重启可复用已校验的本地缓存；发现缓存文件、权限或路径集合变化时启动失败。
- 工作区保留原有数据，镜像和归档均不含运行凭据。

### SSH 基线

sshd 以 agent 公钥提供 exec、PTY、SFTP。进程监督与 SSH 就绪检查在各镜像共用。

#### 验收

- SSH 镜像配套 SSH 归档时，只读 root 私有配置目录中只需 `authorized_keys`，无需模型配置、会话 token 或二进制。
- 健康检查验证监督控制器和受限公钥的实际 SSH 登录；扩展镜像再验证自己的服务。
