# Sandbox Gateway

## 功能意图

Gateway 是独立沙箱资源管理服务。统一负责创建、启动、停止、删除、重建、状态查询、元数据保存、启动时资源对账、逻辑端点发现及受控访问。可选 tunnel 为客户端提供受鉴权保护的字节中继。可选网络观测接口经同一管理身份转交宿主 Observer，Gateway 不自行抓包。

一个 crate 内划分 gateway-api、lifecycle、driver、tunnel。lifecycle 是唯一沙箱业务状态管理方，driver 将统一规格翻译为基础设施操作。沙箱客户端通过网络契约调用 Gateway，agent 会话在沙箱内处理。首个真实驱动对接本机 Unix socket Docker daemon，进程独占 SQLite 数据库并固定 namespace 和 daemon 身份。

## 关键功能与验收

### 资源生命周期

提供完整生命周期操作，保存创建规格与操作意图，区分停止保留、删除释放与保数据重建。

#### 验收

- 创建后可查询就绪状态和端点，停止后可再次启动。
- 保数据重建后工作区文件仍存在；显式销毁数据的重建按授权范围执行。
- 删除遇到驱动故障时保留删除意图，恢复后继续完成清理。

### 持久化与对账

元数据存储和资源对账由 lifecycle 统一处理。对账同时保留期望操作和观察到的实际状态。

#### 验收

- Gateway 重启后能读回创建规格、操作意图与资源标识并继续对账。
- 数据库绑定的 namespace 或 Docker daemon 身份改变时启动被拒绝，同一数据库路径别名不能绕过进程独占。
- 查询超时不触发资源或记录删除，确认资源不存在后按期望操作收敛。停止或对账失败时保留实例创建时的端点声明，并标为未就绪。恢复后按原声明重新检查端点。

### 端点与可选隧道

按注册表冻结的声明返回逻辑端点与就绪状态；tunnel 只中继已授权端点的 TCP 字节。

#### 验收

- 内部端口不会被发布为宿主公网监听或公共负载均衡入口。
- 关闭 tunnel 时连接接口返回 501；启用后 SSH、ACP 等上层协议无需改变。
- 非法凭据、未知端点和任意目标地址转发请求被拒绝。

### SSH 授权公钥

管理员通过 Gateway 维护每个 Runtime Profile 的 SSH 登录公钥，替代手工编辑管理员配置目录。只保存公开公钥，渲染为 Gateway 私有文件后以只读单文件挂载覆盖容器的 `authorized_keys`。

#### 验收

- 只接受三段式 OpenSSH 公钥，拒绝选项前缀、未知类型、多行和控制字符；单条与单个 profile 有条数上限。重复公钥幂等，删除最后一个公钥返回 409。
- 创建容器时，已登记密钥的 profile 在配置目录挂载之后追加一条只读单文件挂载；未登记时不产生该挂载，管理员配置目录内容不被修改。
- 查询返回每个 profile 的密钥、渲染时间和使用该 profile 的沙箱及其挂载证据。未配置时接口返回 501，fake 驱动不提供该能力。
- 变更只对后续创建或下次启动的容器生效；运行中容器不受影响，撤销公钥不终止既有会话。

### 镜像清单

#### 验收

- 已鉴权的查询列出当前 Docker daemon 上可见的官方镜像，以及所有已登记镜像。分别报告本机镜像 ID 和注册组合，查询不拉取或启动镜像。
- 已登记但本机未查到、镜像查询失败及驱动不支持均可区分。登记组合无效时不返回部分展开结果。

### 可选网络观测

管理员按沙箱 ID 发起观测，Gateway 从本机 Docker 获取该代容器的启动身份。观测历史由配对的 Observer 管理。

#### 验收

- 未配置观测 socket 或使用 fake 驱动时，`observer_enabled` 为 false。配置接入但 Observer 离线时，转发请求返回 503，不改变沙箱状态。
- lifecycle 快照不是 `running` 或已有操作进行中的沙箱不能开始观测；随后还需由 Docker driver 核对当前容器仍属于该代且处于运行中。该检查与受理之间存在并发变化窗口，观测服务会继续用 PID、启动时间和容器 ID 固定一次运行。已删除沙箱的历史仍能按原沙箱 ID 和观测 ID 查询，前提是观测文件仍在。
