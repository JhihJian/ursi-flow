# lifecycle

## 功能意图

统一管理沙箱业务生命周期，拥有元数据、冻结的创建规格、操作意图、状态迁移与恢复策略。服务编排和 SQLite 存储同属此模块，driver 提供基础设施操作与实际状态。

## 关键功能与验收

### 操作编排

受理创建、启动、停止、删除和重建，先保存操作意图，再调用 driver。重建明确区分保留工作区数据与销毁数据，并限制清理范围为本沙箱拥有的资源。

#### 验收

- 并发或重复操作按当前状态和操作标识合并或拒绝，不重复分配资源。
- 驱动创建返回但服务尚未就绪时，沙箱仍处于准备中。
- 解析网络观测目标前要求沙箱状态为 `running` 且没有进行中的操作，否则返回冲突。观测记录不写入沙箱生命周期数据库。
- 保数据重建恢复原工作区，失败时保留可诊断的操作阶段与资源标识。

### 元数据与对账

SQLite 保存创建规格、期望操作、实际状态、端点与错误。修订号条件更新防止过期写入，每个沙箱串行操作，跨沙箱使用有界轮转调度。资源代际和数据代际固定重建清理范围。启动时及运行期间对未完成操作持续对账。短暂查询故障保持记录，已持久化的删除意图持续重试。

#### 验收

- 修改进程默认配置并重启，存量沙箱仍按冻结规格恢复。
- 过期状态更新被拒绝，实际资源仍运行时不会覆盖删除意图为正常运行。
- 模拟资源创建成功但元数据回填前崩溃，重启通过资源关联标识接回原资源。
- 查询超时保留记录；删除失败后重启可继续清理直到确认资源释放。
- 销毁数据重建在新容器已创建、状态尚未提交时中断，重启不删除新代数据卷。
- 超过调度并发上限的沙箱也能获得执行机会，不因列表排序长期饥饿。
- 调度任务崩溃或元数据无法读取时停止受理并使进程失败退出，不出现只受理不执行的状态。
- 正常停止限制 HTTP 退出等待时间，慢请求不会无限占用数据库锁。

### 端点解析与就绪

根据声明端点与 driver 实时结果解析可达地址，执行公开/内部策略校验。就绪检查覆盖该环境配置要求的服务，不能仅凭进程存在判定就绪。

#### 验收

- 未声明的端点被拒绝，解析端点前核实沙箱实际可用状态。
- 内部端点无法通过请求变为公开映射。
- 必需服务未通过检查时不返回就绪；端点变更后返回最新地址。
