# gateway-api

## 功能意图

Gateway 的网络接入层，负责 HTTP 路由、鉴权、参数校验、错误映射与 WebSocket 升级。生命周期业务委托 lifecycle，字节中继委托 tunnel。

## 关键功能与验收

### 控制面接入

暴露生命周期、状态、日志、能力和端点查询。创建异步受理，查询接口呈现实际进度与错误，所有资源操作需要有效调用身份。

#### 验收

- 合法创建返回受理结果和可查询标识，非法规格在供应资源前被拒绝。
- 无效凭据、未知沙箱、冲突操作、不支持能力分别映射为可区分错误。
- 重建的数据保留选项完整传递给 lifecycle。

### 隧道入口

在认证和请求校验后调用 tunnel 解析目标，成功后升级连接。健康检查和鉴权配置不构成资源接口绕过路径。

#### 验收

- 错误子协议、非法端口及未授权请求在升级前被拒绝。
- 内部端口查询不产生公开端口映射。
- 相同业务错误在控制面与隧道升级前具有一致错误类别。

### 观测接入

四个观测路由使用 Gateway 的 Bearer 鉴权。仅开始请求通过 lifecycle 解析目标；查询、停止和分段下载按沙箱 ID、观测 UUID 转发至配置的 Unix socket。

#### 验收

- 未鉴权不能创建观测、读取状态、停止或下载；调用方不能用 PID、容器 ID 或宿主路径替换服务端解析的目标。
- 能力关闭时合法请求返回 501，无法连接 Observer 时返回 503。活动期间请求分段返回 409，结束后已有分段以 PCAP 流返回。
