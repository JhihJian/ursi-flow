# sandbox driver

## 功能意图

把统一 Sandbox Spec 翻译成具体基础设施操作，并报告资源实际状态、可达端点和驱动能力。driver 不保存另一套沙箱业务状态机，操作意图与恢复策略由 lifecycle 管理。

Docker 是首个真实驱动，使用无 shell 的 Docker CLI，启动时固定本地 Unix socket 与 daemon 身份。fake 用于确定性测试与故障注入。Kubernetes 可映射 Pod、Service、PVC 和 LoadBalancer，E2B 可映射模板与快照，这些实现按需求扩展同一边界。

## 关键功能与验收

### 资源适配

实现创建、启动、停止、删除、重建及查询。统一边界涵盖稳定资源关联标识、环境、资源限制、工作区保留策略和服务端点声明。当前 Docker 规格使用镜像引用、受限命令、命名卷和端点配置。能力差异明确返回，不能静默降级。

#### 验收

- Docker 创建后可按资源标识查询、启停和删除。
- 同一创建标识的重试可发现已创建资源，不重复创建第二份资源。
- 请求不支持的保数据重建能力时返回明确错误，原数据保持完整。
- 保数据重建旧卷缺失时失败，不重新创建空卷冒充成功。
- 拒绝镜像额外匿名数据卷，仅按归属标签操作本 namespace 的已知容器与命名卷。
- fake 能注入超时、部分成功和资源不存在，供 lifecycle 恢复测试使用。

### Runtime 配置接入

通过管理员配置目录白名单注入 Runtime 所需凭据与启动配置，API 仅允许引用名称。源目录保持 root 私有并只读挂载，服务进程获得固定的 SSH、降权和回收能力，Agent 子进程清空 capabilities。

#### 验收

- 未配置或未知的 runtime_profile 在资源供应前被拒绝。
- 请求无法指定宿主路径或自定义 capabilities，凭据内容不进入 SQLite。
- 正式 Runtime 的 SSH/SFTP 与会话服务可用，普通 agent 用户无法读取 session token。

### 状态与端点

区分确定不存在、查询失败和实际资源状态。公开端点按受控策略发布，内部端点只返回受控网络地址或隧道可解析目标。

#### 验收

- Docker 的端口发布列表仅包含获准公开的端口，CDP/noVNC 内部端口没有宿主公开映射。
- 超时返回查询错误而非不存在；查询成功返回当前资源状态和地址。
- driver 接收和执行基础设施请求，不启动 agent 会话或解释 ACP 内容。
- Docker 仅为归属匹配且正在运行的容器返回观测目标，含本地 daemon 地址、当前代际、容器 ID、PID 和启动时间。fake 驱动不提供此能力。
