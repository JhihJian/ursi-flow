# 独立 MCP 管理台

## 功能意图

提供可解压启动的 MCP 管理应用。一个进程提供网页与同源 API，使用独立的管理令牌、服务登记、凭据存储和部署策略。

## 关键功能与验收

### 启动与访问

#### 验收

- Linux 交付包包含静态链接的可执行文件和相邻 `web/` 目录。从其他工作目录启动时，首页和既有资源深链均可打开。
- 没有私有管理令牌文件时拒绝启动。`/api/v2` 统一检查 Bearer 令牌，未知 API 返回 JSON 404。直接访问只接受回环客户端和回环 Host。跨设备访问由同机 HTTPS 反向代理转发，并校验配置的 Host；带 Origin 的请求须同源。

### 保存服务与凭据

#### 验收

- 从页面增、改、删平台变量时只返回变量名。重启后保留登记 ID、设置和变量；数据目录和文件为私有权限，同一目录只允许一个进程访问。
- 登记和建立会话都要求部署文件中的完整端点及凭据引用授权。工具调用同时服从部署许可与本地白名单；出站认证只使用平台保存的值。删除值后，新会话无法读取曾依赖该值的服务。
