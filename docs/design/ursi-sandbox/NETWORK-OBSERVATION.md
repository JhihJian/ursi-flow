# 沙箱详情：网络流量观测页

管理员在沙箱详情进入「网络观测」，开始一次采集，检查是否有流量写入，再从结束记录定位报文或下载原始 PCAP。React 页面沿用现有控制台布局、主题和管理员身份。

## 页面与操作

| 时机 | 页面显示 | 可执行操作 |
| --- | --- | --- |
| 尚未开始 | 沙箱 ID、代际、Observer 是否已配置。仅就绪且无待处理操作的沙箱可开始 | 开始观测，或输入已有观测 ID 打开记录 |
| 采集中 | 观测 ID 与开始时间、已写报文数、PCAP 大小、内核与队列丢包、最近一分钟的写入速率 | 复制记录链接、请求停止。离开页面只停止轮询，采集继续 |
| 结束 | 结束时间与原因、最终计数、从 1 编号的分段列表 | 选择一段预览报文，或直接下载原始段文件 |
| 服务离线 | 上次成功读取的时间与数据，当前状态未知 | 重试同一条记录；恢复后由服务返回的状态决定是否可下载 |

详情入口带入沙箱 ID。受理开始请求后，转到 `#/sandboxes/:id/observations/:run`。深链接用这两个 ID 读取记录，刷新不新开采集。即使沙箱已删除，也能通过链接打开仍保留的记录。Gateway 只支持按 ID 查询。管理员可保存链接，供日后查阅或分享给其他有权限的管理员。

## 如何读图与报文

**采集中**：每 2 秒轮询一次状态，同一条观测的相邻有效样本按 `Δbytes / Δ时间 / 1024` 绘制 KiB/s。PCAP 字节包含文件头和记录头，不能当作网卡吞吐量。首个样本显示「等待下一次读数」；隐藏标签页暂停轮询，恢复后从新样本开始，断线区间留白。`degraded` 提示丢包或截断，即使计数为零也不宣称无损。

**结束后**：管理员选段后才读取 PCAP。浏览器 Worker 按块解析 SLL2，首版每段预览前 500 条完整记录，标明预览范围，不一次加载整段或整次采集。显示时间、接口索引、包类型、源与目的、协议、捕获与原始长度；选择行可查看该条记录。地址、协议和方向筛选只作用于已预览的记录。未知协议保留编号，未知接口保留 ifindex，回环的两份内核交付各占一行。加密载荷保持密文。需要检索全部报文时下载完整分段。

### 报文检查器

参考 [Wireshark 主窗口](https://www.wireshark.org/docs/wsug_html_chunked/ChUseMainWindowSection.html) 和 [webShark](https://github.com/QXIP/webshark) 的三窗格结构。上方列表保留采集顺序，显示相对本段首帧的时间、端点和摘要；下方协议分层与 Hex/ASCII 窗格检查同一条选中记录。字段使用从 SLL2 帧首起算的偏移，与 PCAP 文件偏移分开。每条最多保留 512 字节供查看，超出范围的字段仍显示真实位置。HTTP 摘要来自当前 TCP 载荷开头完整的明文 HTTP/1.x 首行，不做流重组或按端口推断应用协议。

## 状态与权限

- 开始返回 `202 starting`。停止返回 202 后显示「正在收尾」，继续轮询。下载仅以 `ended_ms != null` 或 `state == interrupted` 为条件，且必须有可用分段。`limited` 标明已达配额，`error` 展示已有段与错误，`interrupted` 提醒计数可能滞后、末条记录可能不完整；解析遇截尾只展示完整前缀并报告位置。
- 409 表示开始时冲突或分段尚不可读，不自动重发开始请求。404 区分记录与分段不存在，501 显示观测未启用，503 保留旧快照供重试。认证失败时清除敏感内容。重建不会把旧记录切到新代际。
- 复用[现有 Gateway 接口](../../../ursi-sandbox/gateway/CONTRACT.md#网络观测)。Web 同源代理须单独放行这四条路由，查询、下载和写操作一律限管理员。沿用写请求的来源检查，Gateway 密钥只留在代理端。状态走 JSON，PCAP 单独按二进制流转发，客户端取消时中止上游。响应禁止缓存，报文字段按文本渲染，不把报文或下载内容写入浏览器存储。无需让沙箱暴露端口，也无需在后端增设逐包服务。

## 实装验收

1. 管理员能开始、刷新同一观测、停止并等待收尾；查看者直接请求状态或 PCAP 也不能读取。
2. 双沙箱夹具只观测 A，确认 A 的回环收发和对外请求可区分；切换方向后下载文件的大小和内容保持不变。
3. 分段预览达到 500 条即停止读取，切段或离开时取消旧请求。遇截尾、未知协议或空段能说明结果，不阻断原文件下载。
4. 强杀 Observer 时界面保留旧快照并显示状态未知；恢复后，`interrupted` 的记录可以读取已有段。窄屏仅报文表横向滚动，状态、控制和诊断仍可见。
