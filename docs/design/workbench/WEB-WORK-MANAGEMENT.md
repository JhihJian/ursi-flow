# Web v2：工作区与文件包

侧栏「工作」进入默认首页 `/work-items`。按类别和状态筛选「全部事项」，或切换到「项目」查看[地图、画布和待办](WORK-PROJECTS-DESIGN.md)。事项保存人工办理状态，工作包保存材料文件。配方在工作包生成器中维护。

## 工作区与包目录

用户可在全部事项或项目任务卡中创建工作项。需要外部材料时，在 `/mcp-servers` 登记服务并核对资源，再从工作包生成器选择配方、资源与关联事项，显式发起生成。结果出现在事项的关联工作包和生成记录中。包详情可改绑或解除归属，生成来源仍记录原事项。

工作包与配置包分别从 `/work-patches` 和 `/config-patches` 进入。两类页面都按包记录返回的 `directoryId` 打开文件目录。配置包提供提示词、Skills 和 MCP 的专用编辑器，其 `mcp.json` 与平台 MCP 服务登记相互独立。文件操作见[目录编辑台](PATCH-STUDIO.md)。

## 定义目录与运行工具

`/resources` 和 `/executors` 提供目录、历史修订及新版发布表单。执行器绑定指定版本的资源，旧版深链仍可查到原资源正文。发布执行器只保存定义。Agent 草稿可在编辑页试跑，也可从工作包页按已发布修订启动。配置来源与运行边界见[执行器设计](EXECUTOR-DESIGN.md)。

业务页访问同源 `/api/v2`。Flow 工具单独访问 `/api/v1`；已登录时 Flow 集合返回 404 则收起该导航组。桌面侧栏与移动抽屉使用同一份导航。本地演示对话独立于两版服务。页面入口和验收命令见[使用说明](../../../workbench/web/README.md)。
