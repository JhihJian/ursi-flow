# SUMM-Todo 看板设计

看板沿用 SUMM-Todo-Web 的出版物式视觉语言，把只读展示扩展为可维护项目与任务的独立应用。前端使用 React 19、TypeScript、Zustand、`@dnd-kit/core` 与 `react-resizable-panels`，后端使用 Rust + axum + rusqlite。

## 页面结构

```text
统计栏：项目数 · 今日 · 本周 · 本月 · 全部
┌────────────┬────────────────────────────┬──────────────┐
│ 项目列表    │ 项目标题 / 描述 / 操作       │ 活动任务      │
│ 可拖拽接收  │ 周期统计对应的任务表         │ 任务详情      │
└────────────┴────────────────────────────┴──────────────┘
```

三栏由 `Group` / `Panel` / `Separator` 组织，默认宽度为 240px、自适应、300px。项目栏与详情栏使用像素宽度，内容栏保留相对宽度。布局通过 `useDefaultLayout` 存入 `localStorage`，刷新后恢复。分隔线占 6px 宽，中间画 1px 细线，悬停时显示 `⋮` 和深色线，双击恢复默认宽度。

Projects 面板可折叠。表头 `«` 调用面板的 `collapse()`，折叠到 32px；把分隔线拖到最小宽度附近也会自动折叠。折叠态不渲染项目列表，改为单列信息条：内容用 `writing-mode: vertical-rl` 和默认的 `text-orientation: mixed`，整行文字侧转 90°、自上而下排列：拉丁字母随行旋转，中日韩字符保持直立，符合竖排习惯。逐字直立（`upright`）会让拉丁字母显得松散，故不采用。内容依次为项目名、活跃任务数和累计时间。折叠态所有文字统一字号，避免不同字号导致列内左右错位。名称过长时由外层 `overflow: hidden` 从尾部裁掉，完整内容保留在 `title` 中。

由于元素本身是竖排，`margin-block` 会被解析成左右外边距，折叠文字改用 `margin-top/bottom: auto` 实现短名称垂直居中；内容超出栏高时自动外边距归零，文字从顶部开始排列。点 `»` 或信息条调用 `resize()` 恢复折叠前的像素宽度，双击分隔线则回到默认宽度。折叠后的宽度由同一布局保存，刷新后保持。

统计栏保持固定高度，三栏各自纵向滚动，滚动条隐藏但内容仍可滚动。视觉变量、字体、间距和表格样式沿用参考项目：衬线字体做标题，等宽字体做数据，纯灰度、直角、无阴影和渐变。

## 数据流

Zustand store 保存项目、当前任务、活动任务、三份周期统计、当前选中项目和周期。组件只读取 store 并调用动作，所有请求集中在 `api/client.ts`。

- 启动时读取项目，选中活跃任务最多的项目，再并行加载任务、三份统计和活动任务。
- 修改项目或任务后统一刷新项目、任务、统计和活动任务，避免局部数据过期。
- 任务表请求带递增序号，快速切换项目或周期时丢弃过期响应。
- 每 30 秒查询今日完成数，数值增加时播放提示音、发送桌面通知并刷新数据；每 60 秒刷新活动任务。
- 服务端错误直接显示在提示框中，不插入演示数据。

## 拖拽

`@dnd-kit/core` 的 `DndContext` 包住统计栏下方的三栏。任务行首的 `⠿` 是拖拽手柄，指针移动超过 6px 才开始拖拽，因此普通点击仍打开详情。拖拽时显示单行预览，原行降低透明度。状态栏前显示 `drag to` 提示；拖动开始后状态标签和项目项出现虚线放置轮廓，悬停目标再加实色高亮。

两类放置目标：

| 目标 | 数据 | 结果 |
| --- | --- | --- |
| 任务表上方的状态标签 | `{ type: 'status', status }` | `PUT /api/tasks/{id}` 改状态 |
| 左侧项目项 | `{ type: 'project', projectId }` | `PUT /api/tasks/{id}` 改 `project_id` |

拖拽不维护本地顺序，只表达状态和归属，和待办库现有字段一致。状态时间规则由服务端统一处理，见[服务端契约](../../../todo-web/server/HTTP.md)。

## 任务详情

选中的任务会在任务表左侧显示深色标记并加深行底色，活动面板中同一条任务也同步标出。行悬停使用比选中更浅的灰度叠加，进行中和阻塞行也有一致的悬停反馈。右侧详情面板在选中任务或新建任务时展开表单，字段与参考项目一致：标题、优先级、状态、标签、结果和时间信息。新建任务的初始状态固定为 `pending`，状态选择在新建模式下禁用。保存和删除后关闭详情并刷新数据，删除需要二次确认。

## 边界

- 不做登录和权限，服务只应在可信网段或反向代理后使用。
- 不创建或迁移数据库结构，读写现有 SUMM-Todo 库。
- 界面按桌面宽度设计，窄屏时靠面板内部滚动，不提供移动端折叠布局。
