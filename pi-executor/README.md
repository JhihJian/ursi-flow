# Pi Web 前端

Pi Web 的首页 `/` 直接打开 [Pi SDK 会话服务](session-service/README.md) 的工作区。前端沿用上游 Pi Web 的布局、主题、字体和图标。上游版本见 [`upstream.json`](upstream.json)，使用 [MIT 许可证](LICENSE)。

## 构建与部署

在 Node.js 22.19 或更高版本下运行：

```bash
cd pi-executor
npm ci
npm run build
```

用静态文件服务托管 `out/`。若部署到子路径，构建时设置 `PAGES_BASE_PATH`，例如 `PAGES_BASE_PATH=/pi-executor npm run build`。本地开发运行 `npm run dev`，默认端口为 `30143`。

工作区通过同源的 `/api/pi/` 访问会话服务。反向代理保留 API 路径和 Web 入口的 `Host`，对 SSE 关闭响应缓冲和缓存。前端部署到子路径时，API 仍位于域名根路径下。会话服务也可直接托管根路径构建的 `out/`。

## 打开实时会话

打开受信入口的 `/` 进入工作区，使用 `/?session=<id>` 可直达会话。部署时通过 `PI_SESSION_WEB_ORIGIN` 指定入口地址，将 `PI_SESSION_WEB_ACCESS` 设为 `read` 或 `write`。入口的访问范围由受信网络或上游网关控制，详见[服务配置](session-service/README.md)。

工作区负责会话列表、新建会话、权限和地址栏导航。选中会话后，由四个模块协同工作：

| 模块 | 在工作区中的用途 |
| --- | --- |
| 对话 | 显示已保存的消息、实时输出和工具结果。刷新或重连时，从只读订阅获取当前快照。 |
| 运行配置 | 查看系统提示、工具、模型、已加载技能和 MCP。面板用标签区分服务默认配置和会话生效配置。 |
| 会话结构 | 查看消息轨迹、分支和父子会话。选择消息可预览到该条消息为止的历史。可写用户可从选中的历史消息创建独立子会话。 |
| 提示词 | 可写用户在实时视图中发送文本和停止运行。历史预览中隐藏输入框，返回实时后可以继续对话。 |

只有显式发送提示词才启动 Agent 并调用模型。查看配置、预览历史和创建派生会话时，工作区读取或复制已有记录。当前服务未加载技能或 MCP，因此这两处面板显示空态。项目目录、文件和 Agent 配置由工作区之外的部署环境管理。构建产物只连接真实会话服务，原 `/live/` 路径已移除。
