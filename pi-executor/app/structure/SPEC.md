# 会话结构页

## 功能意图

查看消息分支和派生关系，从选定的历史消息创建可独立继续的子会话。

## 关键功能与验收

### 查看分支和派生关系

#### 验收

- `/structure/?session=<id>` 显示父会话、子会话、实时末端及当前消息的轨迹。可选中消息或跳转到分支末端。`&entry=<id>` 记录选中的消息。
- 选择「预览历史」打开对话页的历史快照。父会话和子会话链接指向各自的结构页。浏览和预览不改变实时末端。

### 从历史消息创建子会话

#### 验收

- 可写且空闲的源会话提供派生操作。点击创建按钮时提交选中的消息 ID，请求进行中禁用按钮。
- 派生成功后打开子会话的结构页。失败时显示错误并保留源消息的选择。派生不会启动 Agent 或请求模型。
