# 对话页

## 功能意图

只读查看 Pi 会话的消息、实时输出和工具结果。

## 关键功能与验收

### 实时与历史

#### 验收

- `/conversation/?session=<id>` 订阅会话快照，显示已保存的消息和实时输出，保留消息分组、缩略图和实时末端滚动。
- `&entry=<id>` 按稳定消息 ID 读取历史快照，不开事件流。返回实时后重新订阅。离页或切换会话时中止旧请求。
- 页面只观察服务数据。刷新、重连和预览均不提交提示词或启动 Agent。
