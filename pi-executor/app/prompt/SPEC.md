# 提示词页

## 功能意图

为可写用户提供独立的文本输入、发送和停止入口。

## 关键功能与验收

### 发送和停止

#### 验收

- `/prompt/?session=<id>` 获取会话状态。具有写权限才显示输入框。运行时可点击停止或按 Esc，离开页面后注销该快捷键。
- 提交失败时恢复原会话的文字草稿，保留提交之后输入的新内容。操作失败时显示错误。
- 发送和停止只由用户操作触发，运行状态以实时订阅为准。查看输出需打开对话页。
