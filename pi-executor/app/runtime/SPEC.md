# 运行配置页

## 功能意图

核对 Pi 会话实际使用的模型、系统提示、工具、技能和 MCP，也可查看服务默认配置。

## 关键功能与验收

### 读取和显示配置

#### 验收

- `/runtime/` 显示服务默认配置。带 `?session=<id>` 时读取该会话的运行配置，并定期刷新。未捕获会话生效配置时显示服务默认值。
- 页面标明配置范围，展示模型、系统提示、工具、已加载技能和 MCP。加载、失败和未加载各有对应状态。
- 页面只读取服务提供的配置。读取不启动 Agent 或请求模型。
