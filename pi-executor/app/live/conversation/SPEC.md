# 会话读取与展示

## 功能意图

以统一的 Pi Web 消息视图展示实时会话和指定消息处的历史。

## 关键功能与验收

### 实时与历史切换

#### 验收

- 实时视图订阅会话快照，使用服务端消息 ID 定位历史，保留消息分组、缩略图和滚动行为。
- 选择历史消息时，按消息 ID 读取历史快照并停止实时订阅。切换查看点时，较早请求的结果不会替换当前视图。
- 退出预览后恢复实时订阅，并在之前阅读的消息仍可用时恢复阅读位置。历史视图不接收实时流式内容。
- 展示组件只接收读取模型、交互回调和输入区域插槽，不提交会话命令。
