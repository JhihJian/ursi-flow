# 提问与停止

## 功能意图

在可写的实时会话中提供 Pi Web 输入框，处理发送、停止和草稿恢复。

## 关键功能与验收

### 发送和停止

#### 验收

- 可写的实时会话使用常规 Pi Web 文本输入框。运行时可点击停止或按 Esc。只读入口和历史预览均不显示输入框，也不注册停止快捷键。
- 提交失败时恢复原会话的文字草稿，保留提交之后输入的新内容。当前可写会话的操作失败时显示错误。
- 发送和停止的响应不替换或修改会话快照，运行状态以实时订阅为准。
