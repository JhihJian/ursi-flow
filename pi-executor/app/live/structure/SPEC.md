# 实时会话结构面板

## 功能意图

在 Pi 会话工作区中查看消息分支和会话派生关系，从选定的历史消息创建可独立继续的子会话。

## 关键功能与验收

### 查看分支和派生关系

#### 验收

- 打开面板和运行结束时读取当前结构。面板显示父会话、子会话和从根消息到当前查看点的轨迹。有多个分支时可跳转到各分支末端。
- 选择消息后按其 ID 预览历史。返回实时后清除预览。点击父会话或子会话时，工作区按目标 ID 切换。这些操作均为只读。
- 面板沿用 Pi 主题，提供英语、简体中文和繁体中文界面。读取失败时可重试。

### 从历史消息创建子会话

#### 验收

- 仅可写且未运行时显示创建分支会话的操作。点击创建按钮时提交选中的消息 ID。请求进行中禁用按钮。
- 创建成功后，面板将子会话摘要交给工作区。创建失败时显示错误并保留消息预览。
