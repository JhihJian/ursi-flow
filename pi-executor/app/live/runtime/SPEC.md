# 运行配置面板

## 功能意图

让使用者核对 Pi 会话实际使用的模型、系统提示、工具、技能和 MCP，未选会话时可查看服务默认配置。

## 关键功能与验收

### 识别配置范围

#### 验收

- 打开面板时读取配置。选中会话时读取会话配置，未选中会话时读取服务默认配置。会话尚无运行记录时显示服务默认配置。
- 在运行中的会话打开面板时，定期刷新配置。切换会话后只显示新会话的读取结果。

### 只读展示

#### 验收

- 在会话工具栏查看系统提示和工具，在设置中查看模型、已加载技能和 MCP。面板标明配置范围，显示加载、失败和未加载状态。
- 面板不提供编辑入口，仅从会话服务读取数据。读取不启动 Agent 或请求模型。
