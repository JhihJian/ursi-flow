# Pi Web 前端

## 功能意图

提供可独立部署的 Pi Web 前端。访问者直接进入会话工作区，也可用 `sessionId` 打开外部调用方发起的会话，按权限观察或继续对话。

## 关键功能与验收

### 工作区入口

#### 验收

- 模块可独立安装、构建，静态产物 `out/` 可由普通文件服务托管。工作区通过同源 `/api/pi/` 访问会话服务。
- `/` 是唯一的工作区入口，旧 `/live/` 路径返回 `404`。产物不含样例会话和文件，服务不可用时页面显示错误。
- 工作区沿用 Pi Web 的布局、主题、字体和图标，桌面和窄屏均可打开会话和查看配置。

### 会话导航与权限

#### 验收

- 访问受信 Web 入口无需输入或存储会话令牌。`/?session=<id>` 直达对应会话，先显示已有消息和运行状态，再接收更新。
- 可写入口提供新建、发送、停止和派生操作。只读入口展示会话列表、消息、配置和结构，不显示写入控件。
- 浏览器前进、后退时按地址栏中的会话 ID 切换。刷新页面或网络恢复后，页面通过只读订阅获取当前快照。

### 工作区模块协作

#### 验收

- [对话](app/live/conversation/SPEC.md)按服务快照渲染消息。历史预览读取指定条目的路径，返回实时后恢复订阅。
- [运行配置](app/live/runtime/SPEC.md)只读展示系统提示、工具、模型、技能和 MCP，区分服务默认配置与会话生效配置。
- [会话结构](app/live/structure/SPEC.md)显示消息分支和父子会话关系。浏览历史不改变实时末端。派生成功后，工作区打开新会话 ID。
- [提示词](app/live/prompt/SPEC.md)只在可写的实时会话中提供。命令由用户显式触发，运行结果由对话订阅展示。
- 工作区只展示服务提供的会话与运行配置。项目目录选择、文件浏览和 Agent 配置编辑不属于此工作区。
