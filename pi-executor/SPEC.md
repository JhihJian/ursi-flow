# Pi 执行器界面演示

## 功能意图

提供可独立打开的 Pi 执行器界面原型，以 Pi Web 静态演示版的布局、主题和组件展示模拟会话及工具过程。

## 关键功能与验收

### 静态浏览与模拟交互

#### 验收

- 模块可独立安装和构建，静态产物 `out/` 可由普通文件服务提供。页面交互由浏览器内模拟数据提供，与现有执行器平台和 Flow Runtime 分开运行。
- 首次打开显示样例会话。桌面和窄屏均可查看消息并提交输入，回复以流式方式出现。桌面可预览样例 `README.md`，并查看样例文件变更。
- 保留上游演示版的组件、布局、明暗主题、字体和图标。同一浏览器使用相同视口、主题和样例内容时，主界面与上游演示版一致。
- 文件预览只读取模块内固定的上游样例。构建和运行不扫描宿主仓库，也不启动 Pi Agent 或宿主终端。
