# Pi Web 前端

## 功能意图

提供可独立部署的 Pi Web 前端。访问者直接进入会话工作区，也可用 `sessionId` 打开外部调用方发起的会话，按权限观察或继续对话。

## 关键功能与验收

### 工作区入口

#### 验收

- 模块可独立安装、构建，静态产物 `out/` 可由普通文件服务托管。工作区通过同源 `/api/pi/` 访问会话服务。
- `/` 是唯一的工作区入口，旧 `/live/` 路径返回 `404`。产物不含样例会话和文件，服务不可用时页面显示错误。
- 工作区沿用 Pi Web 的布局、主题、字体和图标，桌面和窄屏均可打开会话和查看配置。

### 会话与服务配置

#### 验收

- 访问受信 Web 入口无需输入或存储会话令牌。`/?session=<id>` 直达对应会话，先显示已有消息和运行状态，再接收更新。
- 可写入口提供新建、发送和停止操作。只读入口展示会话列表、消息和运行状态，不显示写入控件。
- 浏览器前进、后退时按地址栏中的会话 ID 切换。刷新页面或网络恢复后，页面通过只读订阅获取当前快照。
- 系统提示、工具、模型和技能面板只读展示 `/api/pi/runtime` 返回的配置，无需选中会话。未加载的工具和技能显示空态。文件面板显示空态。
