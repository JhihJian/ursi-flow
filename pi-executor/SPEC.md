# Pi Web 前端

## 功能意图

提供独立部署的 Pi Web 静态前端。使用者可以浏览样例，也可以用 `sessionId` 打开会话服务中的真实任务，按权限观察或继续对话。

## 关键功能与验收

### 静态浏览与模拟交互

#### 验收

- 模块可独立安装和构建，静态产物 `out/` 可由普通文件服务提供。
- 首页显示样例会话。桌面和窄屏均可查看消息、发送输入并观察模拟流式回复，桌面可预览样例文件及其变更。
- 首页保留上游演示版的组件、布局、主题、字体和图标。构建和运行只使用模块内固定样例，不扫描宿主仓库。

### 实时会话

#### 验收

- `/live/` 与演示首页共用 Pi Web 的布局、会话侧栏、消息区、输入区、文件面板框架和外观设置。同一视口、主题和面板状态下，这些共享区域使用相同的样式、字体和图标。
- `/live/` 从会话服务读取会话、流式回复和工具结果。演示数据仅在首页生效，实时页的文件面板显示空态，实时页的可用操作以会话服务支持的能力和入口权限为准。
- 通过受信 Web 入口直接打开 `/live/`，页面无需输入或存储会话令牌。使用 `?session=<id>` 可直达对应会话，先显示已有消息和运行状态，再接收更新。
- 可写入口提供新建、发送和停止操作。只读入口展示会话列表、消息和运行状态，不显示写入控件。
- 浏览器前进、后退时按地址栏中的会话 ID 切换。刷新页面或网络恢复后，实时页通过只读订阅获取当前快照。
