# Pi Web 前端

## 功能意图

提供可独立部署的会话目录和四个可直达的功能页。外部调用方和浏览器用同一个 `sessionId` 定位会话。

## 关键功能与验收

### 会话目录

#### 验收

- 首页 `/` 列出服务中已有的会话，可按标题或 ID 筛选，并通过链接打开对应的页面。会话不存在、列表为空或服务不可用时显示对应状态。
- 可写入口提供新建会话，新建后打开提示词页。只读入口可以浏览会话，页面不提供写入操作。

### 独立页面

#### 验收

- [对话](app/conversation/SPEC.md)、[运行配置](app/runtime/SPEC.md)、[会话结构](app/structure/SPEC.md)和[提示词](app/prompt/SPEC.md)各自拥有固定路由。页面独立读取所需数据，通用页头仅提供导航。
- 会话 ID 通过 URL 查询参数传递。复制链接、刷新和浏览器前进后退均按 URL 打开页面及其对应会话。项目目录选择、文件浏览和 Agent 配置编辑由工作区之外的系统管理。

### 静态部署与权限

#### 验收

- 前端可独立安装和构建，静态产物 `out/` 可由普通文件服务托管。根路径和子路径部署均通过域名根路径的 `/api/pi/` 访问会话服务。旧 `/live/` 返回 `404`。
- 访问受信 Web 入口无需输入或存储会话令牌。构建产物不含样例会话和文件。桌面和窄屏均可打开目录和功能页。
