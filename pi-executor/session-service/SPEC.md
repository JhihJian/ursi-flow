# Pi SDK 会话服务

## 功能意图

独立运行 Pi 会话，让外部调用方和浏览器通过同一个 `sessionId` 提交对话或观察执行过程。服务持有运行实例及持久化历史。

## 关键功能与验收

### 提交与会话归属

#### 验收

- 服务无需前端即可启动。对话调用方可创建会话、提交文本和停止运行。创建返回的 ID 与 Pi SDK 会话 ID 一致。
- 外部调用方提交后，浏览器用同一 ID 读取历史并续聊。一个会话同时只接收一个运行，冲突提交返回 `409`。
- 服务重启后，历史仍可读取。显式提交新消息时，Pi 从该会话历史继续。进程中断的运行不会在启动时重放。

### 授权观察

#### 验收

- 外部 API 使用 Bearer 令牌。只读令牌可列出会话、读取快照并订阅事件流，尝试创建、提交或停止时返回 `403`。无有效凭据时返回 `401`。
- 受信 Web 入口可显式设为免登录只读或可写。服务按配置校验请求来源并执行权限。无效 Bearer 凭据不能借用免登录权限。
- 运行中订阅先获得已有消息和当前输出，然后收到新输出和结束状态。断开连接或重新订阅不影响正在进行的运行。
- 对空闲或已有历史的会话执行任意读取操作，均无需创建 Agent、修改历史或请求模型。订阅不存在的 ID 返回 `404`。

### 运行配置

#### 验收

- 服务通过显式配置的 OpenAI 兼容端点使用模型。Pi 实例使用独立状态目录，不从宿主项目或用户目录发现技能、扩展或默认工具。
- 第二个进程尝试接管同一状态目录时启动失败。服务可在无 Web 构建产物的环境中独立运行。
