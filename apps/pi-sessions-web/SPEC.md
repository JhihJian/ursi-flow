# Pi 会话浏览

## 功能意图

读磁盘上已有的 pi 会话文件，给出「按项目分组、按活动排序」的会话侧面板与轨迹正文，供人翻阅、复核历史会话。模块不启动 pi，也不改写会话内容；唯一的写操作是用户主动删除会话文件，以及记录「特别关注」这层侧边栏偏好。模块不依赖 `apps/pi-web` 运行时；会话目录由使用者当场指定，因此同一份代码既能看本机 `~/.pi/agent/sessions`，也能看挂载进来的备份、别人导出的会话集合或某次实验的临时目录。

## 关键功能与验收

### 指定任意 sessions 根目录

根目录指磁盘上任意绝对路径，扫描在它下面三层以内找 `*.jsonl`，不假设 `<root>/<项目>/<文件>` 的固定布局。

#### 验收

- 侧栏顶部显示当前根目录的末两段路径，悬停给出完整路径；点开后是选目录浮层，可输入绝对路径直接打开，也可从子目录列表逐级进入或退回上一级。
- 子目录列表按各自直接包含的 `.jsonl` 数量排序并显示该数量，用来判断哪一层才是会话目录。
- 根目录来自 URL 的 `root` 参数、上次选择（浏览器本地存储）或服务端默认值，按此顺序取第一个可用的；切换根目录后清空当前选中会话与搜索词。
- 指向不存在的路径、非绝对路径或文件时，服务端返回 400 与中文说明，界面在列表位置显示该说明而不清空已有选择以外的状态。
- 子目录中的符号链接不被跟随；`~` 前缀在服务端展开为当前用户的家目录。
- 文件数超过上限（默认 5000）时停止收集并在侧栏脚注标出「已截断」。

### 侧面板按项目分组列出会话

#### 验收

- 每个会话显示名称、相对时间与规模。名称取会话改名（`session_info`），没有则取首条用户消息，再没有则取 id 前 12 位；首条用户消息在服务端按 200 字符截断后传输。
- 会话按 `<root>` 下的项目目录与会话头部的 `cwd` 归组，组名取 `cwd` 的最后一段（缺 `cwd` 时取目录名去掉首尾连字符），组按组内最新活动时间倒序，组内同样倒序。
- 搜索默认收起成标题行右端的一个图标，点开后展开输入框；再点图标或按 Esc 收起并清空关键词，避免留下看不见的过滤条件。
- 侧栏标题行的操作图标成组贴住内容区右边缘，与列表内容对齐，不散落在中间。
- 搜索按空格分词，每个词都要命中名称、首条用户消息、项目名、项目路径、目录名或 id 之一；命不中的会话与因此空掉的组不出现，结果为空时给出提示。
- 默认只展开第一个组与包含当前选中会话的组，其余折叠；点组标题折叠或展开，用户点过的组此后按用户选择。
- 每个组默认显示 8 条，「显示更多」一次再放 20 条，展开超过 8 条时出现「收起」。
- 侧栏脚注给出会话总数、项目数与还在补明细的文件数。
- 侧栏可折叠成 32px 窄条，显示当前会话名称与规模的竖排文字，点击恢复原宽度。
- 列表、选目录浮层与轨迹正文都不显示滚动条，滚动仍然可用（滚轮、触控板、键盘）。

### 按日期筛选

侧栏顶部有一片与侧栏等宽的日期区，用条形图呈现会话在时间上的分布。

#### 验收

- 条形固定覆盖最近 7 个日历日（含今天），最旧的一天在最左、今天在最右；没有会话的日子同样占一格、计数为 0，保证七根条代表七个连续的日子。
- 每根条的宽度与该天会话数占七天总数的比例成正比，最少保留 3px 以便点中。
- 打开页面或换根目录时默认只筛今天，列表因此只显示今天的会话；条形区的两根快捷按钮为「全部」与「今天」，分别切到不筛日期与只看今天。
- 条形区上方给出这七天的日期区间与已选状态。点一根条按该天筛选会话，再点一次取消（反选）；可以同时选中多天，列表显示落在任一所选日子的会话。
- 筛选与搜索叠加生效；筛选中某一天时侧栏脚注写出该日期（如「筛选 11-26」），选中多天时写出天数。
- 所选日期没有会话时给出对应说明，而不是套用「目录里没有会话文件」。
- 条形始终按整份会话列表统计，不随搜索或筛选结果变化，选中某天后其它条仍可继续选择。
- 七天之外的会话不进入条形区，但这些会话仍可在「全部」下浏览与搜索。

### 特别关注的项目

把常用项目提到侧栏最前，跨会话、跨浏览器保持。

#### 验收

- 项目组标题右键出菜单，含「设为特别关注」或「取消特别关注」，菜单顶部给出项目名。
- 已关注的项目整组排在最前的「特别关注」区段，顺序是关注顺序的倒序（最近关注的在最上），并带一个圆点标记；其余项目在「全部项目」区段里保持按活动排序。
- 关注列表存在服务端偏好文件里，换浏览器或重启后保持；重新关注同一个项目不会产生第二项，取消后该组回到「全部项目」段。
- 关注列表里保留已从当前根目录消失的项目键：该组只是不显示，等项目再出现时恢复关注，与项目顺序的处理一致。
- 关注段为空时不显示「特别关注」标题，因此侧栏不会多出一条空的区段。

### 右键菜单与删除会话

#### 验收

- 会话行右键菜单为：打开、复制会话 ID、复制文件路径、删除会话…。
- 选「删除会话…」后同一位置弹出确认菜单，标题是「删除「会话名」？」，含「删除会话文件」与「取消」，只有点前者才真正删除。
- 删除会移除该会话的 `.jsonl` 与其同名目录（pi 放在那里的 subagent 运行记录），同一项目里的其它会话不受影响。
- 删除成功后列表刷新且该会话消失；若它正被打开，正文回到未选择状态。文件已不存在时接口返回 404，界面提示而列表不变。
- 菜单点空白、按 Esc、滚动或改变窗口大小时关闭。

### 会话列表的冷启动与刷新

#### 验收

- 首次列目录只读每个文件的头部行就返回全部会话行，消息数与首条用户消息由服务端后台补齐；响应里的 `pendingDetails` 是等待补齐的文件数，客户端据此自动再拉取，补齐后停止。
- 文件大小与修改时间都未变的会话不重新读取，直接复用上次结果；会话被追加或改写过才重新解析。
- 服务端把这份扫描结果按文件指纹写入本机缓存目录，重启后不必重新读取一遍已有文件；缓存不可写或损坏时退回重新扫描，不影响功能。
- 点击侧栏的重新扫描按钮立刻重扫当前根目录。

### 渲染选中会话的轨迹

#### 验收

- 选中会话后正文区显示头部一行元信息（项目、id、名称、体积、修改时刻、格式、轮数、消息数、工具调用数）与轨迹视图，轨迹由 `pi-agent-trajectory-viewer` 渲染，支持 Ledger / Reading / Trace / Diagnostic 视图切换。
- pi 的助手消息多数只带工具调用、没有文字。阅读视图与执行视图对这种卡片说明本步调用了几个工具，细节交给同一步的工具卡，不标记成「没有文本」；只有真正没有任何内容的空消息才标为未记录文本。
- 内容按行转换成组件库要求的形状：缺少 `type: "session"` 首行的老格式会话补出行头，`user`/`assistant` 行改写成 `message` 行并保留 `uuid`/`parentUuid` 的父子关系，坏行丢弃。
- 会话体积超过服务端上限（默认 64MB）时返回 413 与中文说明，界面显示该说明并保留 Raw JSONL 链接。
- 解析失败时显示组件库给出的原因，并提示可用 Raw JSONL 检查原始内容。
- 头部提供重新读取按钮与 Raw JSONL 链接；Raw JSONL 打开转换后的纯文本，支持 gzip。

### 访问边界

#### 验收

- 写操作只有两种：删除会话文件、记录特别关注的项目。服务假定运行在可信局域网，两者对任何能连上服务的来源都放行。
- 删除只接受服务端自己定位到的、位于当前根目录内的 `.jsonl`，客户端不能传文件路径，因此写操作的作用范围受当前根目录约束。
- 默认监听所有网卡以便局域网直接打开；需要收紧时把监听地址设成 `127.0.0.1`。
- 除删除外不改动任何会话内容：轨迹按原文件只读渲染，浏览与搜索都不会写回。
- 监听与默认根、上限、静态目录、索引位置都由环境变量覆盖，见 [README](README.md)。
