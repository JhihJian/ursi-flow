# 项目门户

## 功能意图

门户在独立首页展示品牌和项目资料，让用户管理页面布局和可选应用入口。

## 关键功能与验收

### 首页与布局设置

#### 验收

- 直接访问门户 `/`，可以看到品牌、项目名称和简介，并打开布局设置与插件管理。没有启用任何插件时，以上内容和操作仍然可用。
- 桌面可把扩展区域放在主内容右侧或下方。窄屏自动改为上下排列，空扩展区域不占空间。
- 用户更改布局或插件开关后，刷新页面仍保留选择。偏好按浏览器来源和项目 ID 存储。

### 启停源码插件

门户声明 `home.entries` 和 `home.aside` 两个插槽。插件通过构建时登记的清单加载，插件管理只提供清单内插件的开关。

#### 验收

- 启用插件后，对应插槽出现贡献。停用后贡献被移除，加载中停用的插件不会在随后激活。
- 插件模块加载或激活失败时，插件管理显示失败，首页和其他插件仍可用。单条贡献渲染失败时，该位置显示错误提示，其他贡献仍可用。

### Workbench 入口

#### 验收

- 启用 Workbench 插件时，首页显示 Workbench 入口。配置有效的 `VITE_WORKBENCH_URL` 后，该入口链接到 Workbench 自己的部署；地址缺失或无效时显示未配置状态。
- 停用 Workbench 插件只移除门户入口。Workbench 的后端、认证和路由保持独立。
