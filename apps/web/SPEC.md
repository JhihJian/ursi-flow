# 项目门户

## 功能意图

门户在独立首页展示项目资料和可选应用入口。配置人员可编辑、预览并导出首页配置，由部署方审核发布。

## 关键功能与验收

### 首页与发布配置

#### 验收

- `/` 展示品牌、项目名称、简介和管理入口。宽屏左栏为应用导航，右栏可放辅助资料。窄屏可从顶栏展开导航，辅助资料排在主内容下方，空扩展区不占空间。
- 生产首页读取同源 `/portal-config.json` 的发布修订。配置缺失、超时或校验失败时，显示基础首页和配置异常，所有插件停用，管理入口仍可用。
- 两个访客读取同一发布文件时看到相同的页面文案、布局和插件开关。替换文件后，刷新读取新修订，回退文件后恢复旧配置。

### 页面管理

#### 验收

- `/manage/#pages` 可编辑首页品牌、项目名称、简介、仓库地址和宽屏扩展区位置。站点地址 `/` 和项目 ID 由部署确定。
- 草稿在同一标签页按项目和发布修订保留最后一版有效输入。宽窄屏预览渲染真实首页组件，草稿不改变访客首页。
- 无效输入阻止导出，预览保留上一次有效内容。还原回到当前发布配置。导出生成携带新修订的 JSON，由部署流程发布。

### 插件管理与 Workbench

门户声明 `home.entries`（应用导航）和 `home.aside`（扩展区）两个插槽，清单在构建时登记可信源码。

#### 验收

- `/manage/#plugins` 支持搜索、按启停筛选、查看贡献位置和配置预览。开关只影响草稿预览，发布后才改变访客可见的贡献。
- 管理台区分模块加载失败、加载超时、激活失败和单条贡献渲染失败。其他插件和首页仍可用。加载中停用或超时的插件不会在随后激活。
- 插件启用且 Workbench 配置了有效的 HTTP(S) 地址或站内路径时，首页入口链接到对应部署。地址为空时显示未配置；开关不改变 Workbench 的认证、路由、后端或可访问性。
