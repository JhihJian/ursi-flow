# SUMM-Todo 看板

## 功能意图

看板为 SUMM-Todo 的本机待办库提供独立 Web 界面。用户按项目查看任务与投入时间，维护项目和任务，并可通过拖拽调整任务状态或归属。看板不依赖 ursi-flow 的其他模块，任务与项目实体、状态机、写入规则统一由本目录 [`core`](core/src/task.rs) crate（`todo-core`，最早来自 SUMM-Todo）提供，看板自身不重复定义字段与状态迁移规则，数据由同目录的[服务端契约](server/HTTP.md)定义。

## 关键功能与验收

### 项目与任务浏览

#### 验收

- 打开页面自动选中活跃任务最多的项目。项目名称、活跃任务数与累计时间只显示在左侧列表，内容栏不重复展示；项目描述和路径通过列表项的悬停提示查看。
- 左侧项目列表显示每个项目的活跃任务数与累计时间，点击切换项目。任务表按未完成优先、优先级和创建时间排序，已完成和已取消项置灰。项目计数覆盖进行中、阻塞、待办、完成与取消五种状态。
- 项目列表的折叠形态随宿主而定。独立页面里侧栏按宽度折叠：折叠后只剩 32px 竖栏，内容是一条侧转 90°、自下而上的单列文字（拉丁字母随行旋转，中文直立），依次为当前项目名称、活跃任务数和累计时间，名称过长时从尾部截断、开头始终可见，悬停可看全文；点窄条或展开按钮恢复折叠前宽度，把分隔线拖到最小宽度也会折叠。嵌入工作区外壳时由外壳的 `SidebarFrame` 上下折叠，窄条横向铺开当前项目、未完成数与累计时间，与文件、终端、沙箱的侧边栏同形。
- 任务列表上方左侧显示最近七天每天新建任务数的条形区（状态标签在右侧），与 pi-sessions 的按日筛选同形：一行「按日筛选」、日期范围 `MM-DD — MM-DD` 和 `全部`、`今天` 两个快捷项，下面是七天分布条。条形区随内容区宽度伸展，各天按当天任务数占比分配宽度，零数量仍保留最小可点宽度；悬停显示日期与数量。内容区变窄时先隐藏时间列，再隐藏条形区，把宽度留给任务标题。
- 条形可多选：点击某天按创建日期筛选，再点同一条形取消；`全部` 清空筛选并加下划线表示当前不按日期筛，`今天` 只选今天。多选时按所选日期合并查询，空闲提示按单选或多选分别给出日期或天数。按天或按状态筛选都不会关闭已打开的详情面板。
- 任务列表上方的状态标签只显示状态符号与计数、不显示状态单词，可点击按状态筛选：再次点击同一标签或点击其他标签会切换，全部取消后恢复显示全部任务；筛选为空时提示当前状态没有任务。计数始终按当前项目的全量任务统计。
- 任务 ID 只在详情面板的元信息行展示，点击可复制，复制成功后短暂显示反馈；任务表不显示 ID 列。当前打开详情的任务在任务表中显示选中标记。
- 详情标题行右侧的复制按钮把当前面板内容导出为 Markdown 文本：标题、状态、优先级、标签、时间、记录和结果。复制成功时按钮短暂显示对勾；局域网 http 访问也能复制。
- 详情面板停靠在任务列表下方，打开时自下而上弹出；列表被压缩后仍独立滚动，最后一行不会被面板遮挡。
- 详情按一篇连续文档呈现：大标题、一行元信息（状态、优先级、标签、时间）、Markdown 记录与结果两个编辑区和底部工具条，不使用分块表单。
- 两个编辑区都是所见即所得的 Markdown 编辑区，编辑时直接看到渲染结果，没有源码与预览的切换。输入 `**加粗**`、`# `、`- `、`> ` 等语法会即时生效，选中文字可用快捷键切换加粗、斜体与行内代码。
- 编辑区覆盖 CommonMark 子集：标题、段落、列表、引用、代码块、行内代码、链接、粗斜体、分隔线和图片。GFM 表格等扩展语法不在此编辑器内，按普通文本保存。原始 HTML 不作为标签执行。
- 拖动面板顶部横条可调整高度，高度在刷新后保留；双击横条恢复默认高度。

### 任务关系图

任务区可以在任务表与关系图之间切换。关系图只读复用任务已有的 `parent_id` 与 `pre_id`，把层级与顺序依赖画成一张图，不引入新的存储字段。

#### 验收

- 任务区头部右侧有 `列表` 与 `图` 两个视图按钮，当前视图高亮；选择在刷新后保留，切换视图不关闭已打开的详情面板，也不改动按日与按状态筛选。任务表视图才显示按日筛选与状态标签。
- 关系图按当前项目的全量任务绘制，不受按日、按状态筛选影响。`parent_id` 表现为嵌套：父任务是一个包含子任务的分组节点，标题条右侧显示直接子任务数量，子任务逐层缩进放在父节点框内，不再画父子连线。`pre_id` 表现为虚线前置边，箭头由前置任务指向后置任务。
- 同一分组内的前置依赖优先按依赖顺序排列子任务，前置在上；相邻兄弟之间画一条短竖线，隔着其它子任务时绕到分组右侧，不穿过其它节点。跨分组的依赖以分组外框为端点，目标在右列时从左到右连线，同列上下排列时分组的竖线相连，箭头指向目标任务所在的分组。
- 默认只画待办、进行中与阻塞任务。完成与已取消任务只在直接关联未完成任务时出现（作为父、子、前置或后置），其余不画；头部说明这条规则。
- 节点尺寸与字号固定，不随标题长度变化：宽高统一，标题超出宽度时截断、悬停显示全文；优先级符号与状态图标大小也固定。点击节点打开该任务详情，当前打开详情的节点显示选中标记。
- 把节点拖到另一个节点上松开，被拖节点成为目标的子任务（`parent_id` 指向目标）；从节点左侧端点拖到另一个节点上松开，前者成为后者的前置任务（目标 `pre_id` 指向前者）。拖动超过阈值才开始，普通点击仍然打开详情。
- 在连线上右键弹出菜单，选择 `Remove prerequisite link` 删除该前置依赖；在节点上右键，存在父任务时可选择 `Remove parent link` 解除嵌套。两种操作都直接写库并刷新图，不做二次确认。
- 关系写入走 `PUT /api/tasks/{id}` 的 `parent_id`、`pre_id`：已是同一关系时不发请求，指向自身或会在父链、前置链上成环时提示错误且不写入，服务端拒绝时显示错误信息并保留原图。
- 布局从左到右分层：前置任务排在右侧任务之前，没有入边的根任务位于第一列。前置字段出现环时布局不失败，回边绕到节点下方；父子字段出现环时断开成根节点，不会无限嵌套。
- 当前项目没有可显示的任务时显示空状态提示，不展示演示数据。

### 维护项目与任务

#### 验收

- 项目操作全部从列表右键菜单发起，侧栏与内容栏都不提供按钮：项目项右键为 `New task`、`New project`、`Edit project`、`Delete project`，列表空白处右键为 `New project`。
- 项目的名称、描述和路径在底部面板中编辑。项目和任务的删除都需要二次确认；删除当前项目时其中任务保留为未归属状态，并自动切到下一个项目。
- 可在当前项目下新建任务，并在任务列表下方的详情面板编辑标题、优先级、状态、标签、过程记录和结果。记录与结果都是可选的 Markdown 文本，保存时为空则清空对应字段。元信息行用 `status`、`pri`、`tags` 三个小标签分别对应状态下拉、优先级下拉和标签输入；保存后列表和统计同步刷新，优先级变化会改变任务在表中的排序。
- 状态变更走 `todo-core` 的状态机：完成任务必须填写结果，阻塞任务必须填写原因，不可达的迁移和已取消任务的再次变更返回错误并保留当前输入。
- 过程记录独立于完成动作，完成任务和撤销完成都不会清空记录。
- 服务端提供 `POST /api/tasks/{id}/result/append`，接受 `{ "text": "..." }` 并以空行分隔追加到已有结果，返回追加后的完整结果；空文本返回 400，任务不存在返回 404，不触发状态机。
- 删除任务只从任务行右键菜单发起，需要二次确认。详情面板底部只有 `Close` 和 `Save`，关闭不保存。标题为空或服务端拒绝请求时显示错误提示，界面保留当前输入。

### 拖拽调整状态与归属

#### 验收

- 拖动任务行首的 `⠿` 手柄到状态标签，任务按 `todo-core` 状态机迁移并刷新列表。进入进行中或完成时补记开始与完成时间；缺少结果或迁移非法时不落库，界面显示服务端错误。
- 拖动任务到左侧项目项，任务改归属到该项目。开始拖动后状态标签和项目项显示虚线放置提示，悬停目标有明确高亮。项目栏与任务表不响应文本选择，拖动时不会选中文字；详情编辑区仍可正常选择。
- 拖拽只在移动超过阈值后开始，普通点击仍打开任务详情。

### 完成提醒

#### 验收

- 待办库中出现新的完成任务时，播放提示音并发送桌面通知，随后刷新任务。通知被静音时只刷新不提示，静音设置跨刷新保留。

### 独立构建与部署

#### 验收

- Web 可单独构建为静态包，通过同源 `/api` 访问服务端；服务端可单独启动并托管该静态包，不依赖 ursi-flow 其他服务。
- 项目栏与内容栏的宽度可拖动调整并在刷新后保留；双击分隔线恢复默认宽度。服务端未启动时页面显示加载错误，不展示演示数据。
