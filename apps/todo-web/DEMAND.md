# SUMM-Todo 看板

整个看板不用 alert / prompt / confirm，错误就地显示。

## project-list
- 项目操作全部从右键菜单发起，侧栏与内容栏都不提供按钮。
- 打开页面自动选中活跃任务最多的项目。
- 项目名称、活跃任务数与累计时间只显示在左侧列表，内容栏不重复展示。

## task-list
- 任务表按未完成优先、优先级和创建时间排序，已完成和已取消项置灰。
- 任务 ID 只在详情面板的元信息行展示，任务表不显示 ID 列。
- 状态标签只显示状态符号与计数，不显示状态单词。
- 按天或按状态筛选都不会关闭已打开的详情面板。

## task-detail
- 详情按一篇连续文档呈现，不使用分块表单。
- 两个编辑区都是所见即所得的 Markdown 编辑区，没有源码与预览的切换。
- 记录与结果左右并排，各占一半宽度，中间以竖线分隔。
- 详情面板停靠在任务列表下方，打开时自下而上弹出。
- 详情面板底部只有 close 和 save，关闭不保存。

## project-editor
- 项目的名称、描述和路径在底部面板中编辑。
- 非法输入就地显示错误且不保存。
