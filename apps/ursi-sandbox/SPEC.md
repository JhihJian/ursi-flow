# 沙箱平台

## 功能意图

为工具和工作流提供可回收的执行环境。平台负责沙箱管理、bundle 管理、端点管理与 bundle 镜像构建。SSH、浏览器和 Agent 服务通过端点交付；业务任务、会话和产物归服务及其调用方管理。

## 关键功能与验收

### 沙箱管理

[Gateway](gateway/SPEC.md) 管理实例、资源代际与工作卷。[控制台](web/SPEC.md) 使用同一管理接口，可选的 [Observer](observer/SPEC.md) 独立记录网络观测。

#### 验收

- 启停保留工作区；重建显式选择数据保留策略，删除释放容器与卷。创建请求不触发构建。
- 未启用 Observer 时生命周期仍可用。启用后管理员可开始和停止观测并下载 PCAP。

### Bundle 管理

[注册表](catalog/SPEC.md) 校验镜像的组件组合。[服务包](bundles/SPEC.md) 自行持有协议、程序和配置约束。

#### 验收

- 拒绝缺失依赖、依赖环和组合端点冲突；修改注册表不更改已有实例冻结的端点声明。
- Pi 会话协议和模型凭据不进入沙箱创建请求，纯 SSH 环境无需会话服务或模型配置。

### 端点管理

Gateway 按实例返回逻辑端点和就绪状态，通过[鉴权隧道](gateway/src/tunnel/SPEC.md)交给调用方。端点消费者解释服务协议。

#### 验收

- 未注册的端点或任意目标地址不能拨号；沙箱停止后端点不可用。
- 对同一实例可分别查询资源状态、端点状态。隧道断开不产生任务完成或重放事件。

### Bundle 镜像构建

[构建器](builder/SPEC.md) 根据选定的能力组合交付镜像、归档和能力清单。[启动程序](runtime/SPEC.md) 在容器内校验并装配服务。

#### 验收

- 仅取本目录即可按锁文件构建。SSH 构建不需要 Pi 二进制；加入 Pi 后新增 ACP 端点，无需改动 Gateway。
- 构建产物不含管理员私钥、模型凭据或令牌；相同归档输入生成相同摘要。
