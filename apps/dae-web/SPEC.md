# dae 路由观察台

## 功能意图

本机 dae 以 eBPF 透明代理接管全部出站流量，但自带能力只有 JSON API 和内存态记录，没有页面。观察台把 dae 的 native API v1 变成可读界面：看清当前连接走了哪个出口、命中哪条规则、消耗多少流量，并回溯一条连接的路由判决过程。服务端以同源方式转发 `/api`，浏览器无需跨域，也不依赖 dae 自身开放公网监听。

## 关键功能与验收

### 观察运行状态与出口

概览展示 dae 进程与数据面的健康摘要，以及按出口聚合的累计流量。

#### 验收

- 打开页面自动拉取版本、运行态、出口计数、流量历史与内存历史；概览给出累计上下行、当前速率、活跃连接数、进程内存、运行时长六项指标。
- 出口表按 `direct` 与各代理组分行列出活跃连接、累计连接、上下行字节与错误数；流量曲线按采样点画出最近窗口的上下行速率。
- 数据面区块显示 eBPF 后端、程序与 hook 状态、路由发布 generation、健康标记与配置修订前缀。
- dae 停止或 API 不可达时，页面显示明确错误文本，不白屏；恢复后下一次刷新自动复原。

### 查看活跃连接与流历史

连接表按窗口流量排序展示当前会话，流历史保留已关闭记录；两者都能看到连接由哪条链路转发。

#### 验收

- 连接表显示开始时间、进程、目标（域名与地址）、出口、链路、窗口增量与累计上下行，支持按 TCP/UDP 与关键词过滤；关键词覆盖域名、地址、进程与出口。
- 流历史表显示开始时间、持续时长、网络、进程、目标、出口、链路与状态，支持按进行中/已关闭和网络过滤。
- 列表为空、记录被截断或 dae 未记录命中规则时，页面用占位文本说明当前状态，不显示伪造数值。
- 页面注明这些记录只存在 dae 进程内存中：流的保留窗口、连接列表的可见性都按 API 返回如实展示。

### 回溯一条连接的路由决策

选中连接后，用同一五元组请求 dae 回放当前规则，解释它为什么走这个出口。

#### 验收

- 选中连接或流记录后底部面板展示该条目的完整元信息，可拖动顶部横条调整高度，高度刷新后保留。
- 点击「回溯路由」调用 `POST /api/v1/routing/trace`，展示最终出口与命中的规则；切换「展开全部规则」后逐条列出 `matched`、`not_matched`、`skipped` 的判定结果。
- 回溯成功后，面板中的「规则」一行用回放到的命中规则补齐 dae 未记录的 `rule_id`。
- 目标地址缺失或 dae 返回错误时，面板显示错误文本并保留已有信息。

### 管理连接与 DNS 缓存

页面提供关闭单条连接、删除单条缓存与清空缓存三个写操作。

#### 验收

- 关闭连接后该行从列表消失，已打开的面板关闭；dae 返回错误时面板显示错误文本。
- 删除单条缓存或清空全部缓存后列表立即刷新。
- 写操作只在请求来自回环地址时放行；局域网访问时这三个操作返回 `read_only` 错误，读视图不受影响。

### 查看分流与 DNS 规则

规则页把流量规则与 DNS 请求、响应规则分开列出。

#### 验收

- 流量规则按 `rule_id` 顺序展示表达式与出口，并显示当前 generation；DNS 规则分别展示请求与响应两侧的表达式、动作与上游。
- 页面说明首个命中的规则决定出口，规则改动只影响新连接。

### 观测 DNS 解析与缓存

DNS 页展示解析日志与本地缓存，可按域名过滤。

#### 验收

- 解析日志显示时间、域名、类型、状态、来源（缓存或上游）、耗时与应答地址；非 `NOERROR` 结果用区分色标注。
- 缓存页显示域名、类型、正负缓存状态、剩余过期时间与应答地址，可删除单条或清空全部。
- 应答地址过多时只展示前若干条并标注剩余数量，不撑破列表布局。

### 跟随运行日志

日志页通过 dae 的 SSE 通道持续接收日志。

#### 验收

- 打开日志页建立 `text/event-stream` 连接，按级别过滤（trace/debug/info/warn/error），切换级别时重开连接并清空当前缓冲。
- 默认跟随最新一行，可关闭跟随、清空列表；连接状态在已连接、连接中、已断开之间如实显示，断线后浏览器自动重连。
- 页面注明日志只在 dae 进程内存中保留 300 秒。
