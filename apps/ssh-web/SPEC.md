# SSH 终端

## 功能意图

ssh-web 为内网主机提供独立的浏览器 SSH 终端，也是 ursi-flow 工作区的一栏模块。用户以「名称 + 一条 ssh 命令」维护连接配置，点击连接即由服务端启动系统 OpenSSH 子进程（`ssh -tt`）建立会话，前端用 xterm.js 通过 WebSocket 操控远端 PTY。认证（密码、口令、agent）、跳板、`~/.ssh/config` 别名等全部交给 OpenSSH 自身处理，交互提示直接出现在终端里。远端有 tmux 时会话接入 `tmux new -A -s <会话名>`：浏览器断开后远端会话保活，重新连接自动恢复屏幕；无 tmux 时回退普通 shell 并提示。服务端另按需采样远端 `/proc`，得到 CPU 使用率与负载、内存构成、磁盘、网卡收发速率与 ssh 通道往返延迟，并取内存占用最高的几个进程：状态栏缩略显示 CPU、内存与延迟，工作区右侧资源面板展开完整指标与走势线。服务与页面由同一个 Rust 进程托管，数据保存在本机 SQLite，不依赖 ursi-flow 的其他模块。界面为 todo-web 的出版物风格；独立入口与工作区嵌入共用同一套组件，侧边栏与工作区在嵌入时分别落到外壳的侧栏堆叠与中间工作区，样式作用域在模块容器内，API 前缀由入口注入。

## 关键功能与验收

### 连接配置管理

#### 验收

- 左侧为树状连接面板（固定 200px）：连接为父行，默认全部展开，选中行即选中该连接；每个连接的 tmux 会话子级独立加载与刷新（含默认入口 main、远端客户端数标记 ●、创建时间），右键连接行为 `New connection`、`New session`、`Edit`、`Delete`，空白处为 `New connection`，标题行另有 `+`（新建）与 ↻（刷新全部连接的会话列表）。点会话子行不在侧栏内切换，而是在终端区顶部标签栏打开/激活对应标签。
- 顶部标签栏常驻显示：每个打开的会话一个标签，标签内容与会话子行一致（会话名），点标签激活、点 × 或中键关闭，标签栏尾部 `+` 新建会话；同一 (连接, tmux 会话) 只允许一个标签。当前标签用白底黑字加顶部黑线标记，未激活标签退到灰字，标记不跟随终端亮暗主题。多个标签常驻堆叠渲染，仅激活的可见，每个标签面板铺满同一块终端区（绝对定位叠放，尺寸随终端区伸缩），切标签不重建、不重连 SSH，非激活标签的输出照常写入。
- 列表空白处或连接项右键打开菜单：空白处为 `New connection`，连接项为 `New connection`、`New session`、`Edit`、`Delete`。侧栏标题行右侧另有 `+` 按钮直接新建。
- 连接字段在终端区底部升起的面板维护，仅两项：名称（唯一）与 ssh 命令（如 `ssh jhihjian@10.0.0.5`，支持 `~/.ssh/config` 别名、`-p`、`-i`、`-J` 等全部 OpenSSH 参数）。服务端保存时做基本校验：命令首词必须是 `ssh`，其余原样保留。
- 保存前先自检：服务端以批量 ssh 执行一次 `hostname`（`POST /api/connections/test`）验证命令能否连上，只测传输层与认证、不读 tmux；连得上才写库并刷新会话列表。连不上时面板内显示 OpenSSH 的失败原因（主机名解析、认证、超时等），并给「Still save」二次确认，允许离线机器或需交互密码的连接先保存。编辑时命令未变不重复自检。
- 删除连接需在侧栏底部内联确认区输入连接名称二次确认，名称不匹配时不执行并提示；删除时该连接的会话标签一并关闭。
- 命令原样存于本机 SQLite（`~/.ursi/ssh/ssh.db`）并完整回传展示，无独立凭证字段，不存在"只写不读"的凭证。

### 终端与 tmux 会话

#### 验收

- 布局为左侧树状连接面板 + 右侧顶部会话标签栏与终端区：嵌入 ursi-flow 工作区时，连接树进外壳的侧边栏堆叠，标签栏与终端进中间工作区；独立入口用同一对组件配一栏可折叠侧边栏。布局纯 flex 实现，不用可拖拽分隔条（折叠后重开靠远端 tmux 恢复屏幕）。
- 选中连接后，树中该连接下实时列出远端 tmux 会话（`GET /api/connections/{id}/tmux-sessions`，实时执行远端 `tmux ls` 不缓存，每个连接独立加载与刷新）；远端未安装 tmux 时显示「远端未安装 tmux，连接后将回退普通 shell，断开即结束」并列出安装命令（Debian/Ubuntu `sudo apt install tmux`、Fedora/RHEL `sudo dnf install tmux`、macOS `brew install tmux`，命令可选中复制）；SSH 失败（认证失败、不可达）时错误显示在该连接的子级区，错误下方同样给出这份安装指引供排查。默认入口 main 展示为「默认会话 ssh-main」。
- 点击任一会话项（含默认入口）即在顶部标签栏打开（或激活）标签并启动全新 OpenSSH 子进程：认证失败、主机不可达等失败原因原样显示在终端区（OpenSSH 自身的错误输出），不产生会话。WS 握手即启动子进程，服务端无会话注册表。新建 tmux 会话经标签栏 `+` 或右键 `New session` 展开内联表单，名称限 ASCII 字母数字下划线连字符（1–64），服务端与前端同校验；重名由远端 `tmux new -A` 语义兜底（直接 attach 已有会话）。
- 远端有 tmux 时，PTY 启动命令为 `tmux new -A -s <会话名>`：SSH 断开、刷新页面或关闭浏览器后远端 tmux 会话与其中进程继续运行；重新点击同一会话即 attach 回去，屏幕内容完整恢复。tmux 内 `exit` 退出 shell 会结束 tmux 会话，前端收到退出码。改名在终端内执行 tmux 命令完成；移除会话由侧栏承担：tmux 会话子行右键 `Remove session`，在侧栏底部内联输入会话名二次确认后服务端在远端执行 `tmux kill-session -t <会话名>`（其中进程一并结束），打开中的对应标签关闭，失败原因（ssh 失败、会话不存在）原样显示在侧栏提示区。
- 远端没有 tmux 时自动回退普通 shell，并在终端内显示黄色提示：首行「远端未安装 tmux，已回退普通 shell，断开后会话不保留」，次行给出 Linux（`sudo apt install tmux` / `sudo dnf install tmux`）与 macOS（`brew install tmux`）的安装命令；回退判断由远端一行启动命令完成，服务端不解析输出。
- 终端为 xterm.js 面板，PTY 类型 `xterm-256color`。初始列行由 xterm 实测的 cell 尺寸与面板盒子算出（扣掉内边距与滚动条宽度），并随 WS 握手参数直接用于服务端建 PTY：连接后不会先按 80×24 排版再被 resize 冲刷，握手期间面板尺寸变化会在 WS 打开时补发一次 resize。窗口缩放（含拖拽面板分隔条）时经 ResizeObserver 自适应，列行连续两帧稳定后才落盘，resize 命令 debounce 100ms 同步远端，列行上限 500。
- 渲染使用 xterm 的 Unicode 11 宽度表并补零宽连接符折叠（中文、emoji、ZWJ 序列不量错格）。WebGL 渲染仅在 WebGL2 可用且渲染器不是软件渲染时启用，否则留在 DOM 渲染；上下文丢失后释放 GPU 上下文、退回 DOM 并重排重绘，60 秒内连续丢失 3 次以上不再重试。跨屏拖动或缩放导致 devicePixelRatio 变化、以及切回标签页时，自动修复画布像素比并重绘整个视口。
- 终端内搜索：右键菜单「Search in terminal」或 `Ctrl/Cmd+F` 打开搜索条（快捷键在模块容器内拦截，指针或焦点不在模块内时不枪宿主同名快捷键），支持区分大小写与正则开关、显示命中计数（如 `3/14`）、增量高亮所有命中并标出当前命中；Enter/Shift+Enter 跳转下一个/上一个，Esc 关闭并把焦点还给终端。搜索装饰色按亮暗主题分别取值（灰块与砖红块，与版面专色同源），保证两种底色上都看得见。
- 输出中的 URL 可 `Ctrl/Cmd+点击`打开，悬停时在终端区左下角显示完整 URL 与打开方式提示。被软换行折断的长 URL 由同一个解析器跨行拼回，首行和续行整段都可点；解析按中文句读与句末标点收尾，不会把后面的句号、右括号吞进链接。
- 终端字体与页面共用同一条等宽字体链（`--ssh-font-mono`，终端直接继承面板的 computed fontFamily，避免页面与终端回退到不同字体），字号 13px、字重 400，与页面正文同级；亮色为白底黑字（默认，与整版白底出版物风格一致），暗色为 gray-900 底 + gray-200 字，在终端区右键菜单切换，选择跨刷新保留。两套主题的 ANSI 调色板都是灰阶 + 六种低饱和印刷专色，不出现高纯度终端色。`white`/`brightWhite` 这两个图形槽位在亮色下取中灰而不是近白：块状进度条、`\e[47m` 反显、tmux 状态栏这类字形在 xterm 里绕过最小对比度门限（暗 3:1、亮 4.5:1），取近白会在白底上整块消失。选中底色与搜索高亮色分属两套色相（选中为偏靛淡染，高亮为灰块加砖红当前项），互不混淆；滚动条滑条按前景色染色。切换主题只改 xterm 的 theme，不重建终端、不重连 SSH，滚动内容与远端会话保持原样。
- 键盘输入即时送达远端；输出按原始字节流渲染，粘贴长文本自动分片发送。终端历史保留 5000 行，可滚动回看。终端区右键菜单提供新建 tmux 会话与亮暗色切换。
- 服务端推送的事件不打断终端：消息以带颜色的文本内联写入终端尾部（错误红色，远端退出黄色，tmux 内 `exit` 后退出码可见），同时在终端区底部显示一条事件条说明结果，终端已有内容保留供回看。
- 服务端不持久化任何会话：WS 断开即终止 ssh 子进程，同一时间一个 tmux 会话只接一个终端；持久性完全由远端 tmux 承担。多标签仅为前端形态：关闭标签即断开对应 WS，远端 tmux 会话保留。嵌入工作区时侧边栏折叠即卸载全部终端，重开点击会话重新 attach 恢复屏幕，折叠窄条上实时显示激活标签的会话与连接状态（连接中/已连接/已退出/出错/未连接）及打开数。服务端侧的会话保活、自动重连不在范围内。
- ssh 子进程以 `ssh -tt` 强制分配远端 PTY，`StrictHostKeyChecking=accept-new` 首次连接自动接受主机密钥；服务端不做额外主机密钥校验，这是内网工具的明确边界。

### 设备资源面板

#### 验收

- 设备采样按需进行：只有某连接至少有一个终端标签处于已连接（live）时，前端才每 15 秒请求一次 `GET /api/connections/{id}/metrics`，同一连接不叠加在途请求；没有连接中设备时一次请求都不发。折叠模块后终端卸载、标签落回未连接，轮询随之停止。
- 状态栏在激活终端已连接时显示该连接的缩略指标：`CPU x% · 内存 x% · 延迟 x ms`，取最近一次采样；尚无采样时三项都显示「—」而不是 0。嵌入工作区时该状态来自外壳状态栏槽位，独立入口在页面底部自绘一条同内容、同高度的状态栏。
- 状态栏末尾的「资源」按钮开合资源面板。面板展开后占据终端区右侧固定宽度一栏，不影响终端标签切换与远端会话；关闭面板不停采样，状态栏继续更新。
- 面板只列有 live 终端的连接。每台设备先给一段摘要：连接名、远端主机名、已运行时长与交换用量，以及一条内存构成条（已用 / 可回收缓存 / 空闲）和图例。
- 摘要下面是四项带走势线的指标：CPU 使用率（两次 `/proc/stat` 差值）附 1/5/15 分钟负载与核数；内存百分比附已用 / 总量；延迟附网卡收发速率；根分区使用率附已用 / 总量。每项保留最近 30 个采样点的走势线。
- 指标下面是内存占用最高的 5 个进程（名称、RSS、占内存百分比），按 `ps` 的常驻内存降序；取不到进程表时不展示该段。无连接中设备时整个面板显示空态。
- 采样失败时面板显示原因（含 ssh 自身 stderr），并保留上一次成功的数值供参考；删除连接时该连接的采样状态一并清除。
- 服务端不缓存取样：每次请求跑一轮独立批量 ssh（不分配 PTY），整轮 15 秒超时，延迟应答 4 秒超时；远端先两次读 `/proc/stat`（间隔 0.25s）算 CPU 使用率，再取负载、内存、交换、根分区、运行时长、网卡累计字节与内存前 5 进程，延迟取通道一问一答的往返耗时（不含 ssh 握手）。网卡速率由前端按两次采样的差值除以时间得到。
- 采样依赖远端 Linux 的 `/proc`。非 Linux 远端（如 macOS）的终端照常可用，资源面板显示采样失败原因。
- 采样与 tmux 列表一样以 `BatchMode=yes` 批量执行，要求密钥 / agent 免交互认证；交互密码仍可在终端会话里输入。

### 工作区嵌入

#### 验收

- ssh-web 以 `@ursi/ssh-web/module` 接入 ursi-flow 工作区外壳：侧边栏是连接树与会话入口，工作区是标签栏加终端；`createSshModule({ apiBaseUrl })` 工厂创建独立的 store 实例，不设模块级单例；独立入口与嵌入共用同一套组件。
- 嵌入时宿主 vite 把 `/api/ssh-web/*` 代理到 8091 并重写为 `/api/*`（HTTP 与 WS 同规则），服务端路由保持 `/api` 不变；模块所有请求（含终端 WS）都走注入的前缀。
- 样式全部作用域在 `.ssh-embed` 容器内，类名带 `ssh-` 前缀，右键菜单 portal 进容器并以容器坐标系定位，不越栏、不吃宿主样式；亮暗主题偏好存于带模块前缀的 localStorage 键（`ssh.terminal-light`）。
- `Ctrl/Cmd+F` 仅在指针或焦点落在 ssh 模块内时拦截，其余场景不干扰宿主快捷键。

### 服务与接口

#### 验收

- 服务默认监听 `0.0.0.0:8091`（`PORT` 可覆盖），托管静态页面与同源 API；数据库路径可用 `URSI_DATA_DIR`（默认 `~/.ursi`）与 `SSH_DB_PATH` 覆盖。接口契约见 [server/HTTP.md](server/HTTP.md)。
- `GET /api/health` 返回 `ok`。连接增删改查、tmux 会话列表、设备资源采样与终端 WS 全部走同源 `/api` 前缀，错误统一为 `{error, code}` JSON。
