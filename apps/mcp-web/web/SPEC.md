# 平台 MCP 管理界面

## 功能意图

宿主注入已认证的请求方法与凭据入口，即可在 React Router 中嵌入 MCP 服务管理页面，或只引用客户端访问相同 API。

## 关键功能与验收

### 服务目录

#### 验收

- `/mcp-servers` 列出已登记的名称、Streamable HTTP 地址和可选的凭据方式：引用名或已存密钥标记，支持按名称或地址搜索、刷新登记。加载与刷新目录不出站探测，也不显示在线状态。
- 每行可显式检查协议。上次成功检查匹配到的标签按规则名称显示在名称旁。复查失败保留标签并显示错误，成功复查或规则变更后重新检查时更新标签。
- 新增服务在弹窗内选择凭据方式：无凭据、凭据引用或直接填写密钥，宿主提供引用列表时从中选择，否则输入引用名。提交前显示凭据来源和接收地址；直接密钥提示会保存在登记中。失败时保留表单。删除经确认后才提交。

### 服务检查与资源预览

#### 验收

- `/mcp-servers/:id` 展示登记信息、本次发现状态、协商版本、服务实现标识和声明的能力。工具、提示词和资源模板目录按需发现，显示实际条目、参数和结果。发现不触发工具调用。带 inputSchema 的工具默认提供表单填写模式：按参数类型生成输入框、枚举下拉、数字框、布尔开关和数组/对象 JSON 域，必填项提交前校验；可切换到 JSON 模式直接编辑参数对象，两种模式相互转换时保留已填内容。无 inputSchema 的条目只显示 JSON 模式。目录页为双栏卡片布局：左侧目录列表完整展示每项描述（不折叠，名称单行截断悬停看全名，授权开关独立操作）且高度受限内部滚动（窄屏上限 24rem，宽屏随双栏行高）配右侧详情面板（参数填写、结果展示），服务功能用分段式选项卡切换。工具结果默认结构化视图：优先 `structuredContent`，无则尝试解析首个 content 文本中的 JSON；对象数组渲染为分页表格（列取标量字段，链接可点击，嵌套值折叠），顶层标量渲染为键值行，嵌套对象可展开；纯文本按原文展示。可一键切换「原始 JSON」查看完整响应。用户可保存 GitHub 工具集、只读设置和本地调用白名单；工具默认禁止，授权后每次确认才提交。空列表、未声明资源、发现失败具有不同提示。
- `/mcp-recognition-rules` 整组编辑识别规则的 ID、标签名称、元数据键和等于值，可添加、删除或清空规则，重复 ID 或重复规则在提交前提示。保存前确认「现有协议检查结果将全部清除」，保存后重新读取规则并刷新服务标签。
- 详情显示最近成功的协议检查结果和时间，支持独立于资源发现重新检查。标签含义为上次检查时按识别规则匹配到的结果，不表示在线或授权。
- 工具和资源使用 shadcn Data Table，支持筛选、分页和行级选择。工具行的调用授权与 GitHub 工具集行的显式启用分开保存，清空工具集显示 GitHub 默认模式。
- 发现报告区分当前版本和 `server/discover` 的 `supportedVersions`，展示服务器自报身份、全部能力及可选说明；旧握手不推断支持版本列表。
- 桌面并排显示列表与预览，窄屏纵向排列。列表可按名称、URI 或媒体类型搜索，可重新发现。选择状态写入 `uri` 查询参数；重新打开地址时读取仍存在的资源，并明确提示不在本次列表中的 URI。
- 预览单独显示读取状态，失败后可重试。文本按原文显示，最多预览 16 384 个字符，可复制全文或 URI。二进制仅显示媒体类型与大小，不渲染内容。

### 宿主挂载

#### 验收

- 可独立构建。最小 React 宿主通过公开路由工厂挂载服务页，登记、预览与调用确认可用，页面具有自带样式。
- 宿主可以提供凭据名列表与管理页地址。未提供管理页地址时，登记页不显示管理链接。凭据值不进入前端包，密钥输入框不回显已提交的值。
