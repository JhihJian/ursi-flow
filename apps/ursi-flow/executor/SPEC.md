# Flow Executor

## 功能意图

定义引擎与外部世界之间唯一的契约：`prompt(agentName, instruct)` 执行一个 Agent 节点，`command(invocation)` 执行一个命令节点。适配层按这个契约接入具体执行方式，引擎只依赖契约，不依赖任何适配器。

## 关键功能与验收

### 两个方法的契约

#### 验收

- `prompt` 收到节点名、已渲染的提示词、本步允许的结果与说明、当前全局变量、本次运行内第几次进入该节点，以及上一次提交被拒的原因；返回结果名与可选的变量。
- `command` 收到已渲染的 `request`（`command`、`args`、`stdin`、`cwd`）与运行、步骤、节点标识；返回退出码、标准输出与标准错误。
- 退出码非 0 仍按“已执行”路由，命令证据交给流程自己判断。
- 执行器无法确认结果时抛出 `ExecutorUnconfirmed`，运行进入待核实而不换结果重跑。
- 契约不包含会话复用、模型配置、凭据、子进程管理与超时策略；这些只在适配器内部，不向引擎泄漏。

### 适配层

#### 验收

- 适配器只需实现契约的两个方法即可被引擎使用，不需要改动 `core` 或 `runtime`。
- 新增适配器不改变 `FakeExecutor` 与已有适配器的行为，也不向契约增加可选方法。

### Fake 适配器

#### 验收

- `FakeExecutor` 按节点名消费预设回执与命令结果，按访问顺序取用。
- 没有预设时取第一条结果边（可配置为最后一条），没有可选结果边时直接报错，不猜结果。
- 没有预设回执时为本节点结果声明的变量填占位值，且不覆盖调用方提供的全局变量。
- 命令默认返回退出码 0 与空输出；`output: "variables"` 的节点返回空变量信封。
- 同一运行内 Agent 调用次数超过上限即报错，并保留全部调用记录供断言。
