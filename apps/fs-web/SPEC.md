# fs-web 文件资源管理器

## 功能意图

fs-web 为工作区提供类资源管理器的文件能力。每个 workspace 是一个目录，来源由 provider 抽象统一：第一版实现本机目录（local），SSH 远程目录与虚拟目录按设计预留接口后续接入。模块按[工作区外壳契约](../../packages/workspace-shell/MODULE-CONTRACT.md)接入：模块栏内为二级侧边栏，一级是记录的目录（workspace）列表，二级是当前目录的 git 摘要与文件树；文件编辑经全局选中交给外壳的工作区区域，由 Monaco Editor 渲染。

设计决策与分阶段范围见 [README](README.md)。

## 关键功能与验收

### workspace 清单与运行时目录管理

workspace 清单由服务端持有并可运行时变更：首次启动用内置默认（当前工作目录，显示名取目录名）或 `FS_WEB_CONFIG` 指向的 JSON 数组播种，写入运行时状态文件（默认 `$XDG_STATE_HOME/fs-web/workspaces.json`，回退 `~/.local/state`，可用 `FS_WEB_STATE` 覆盖）；此后状态文件是唯一事实源，`FS_WEB_CONFIG` 不再生效。静态配置的 `id` 只允许小写字母、数字与短横线；运行时添加的目录 `id` 取 root realpath 的 sha256 前 16 位 hex，跨重启稳定。

#### 验收

- 打开模块后一级侧栏列出全部目录并点击切换；切换后树与选中复位为新目录的根。
- 目录条目两行展示：第一行是显示名（可右键重命名），第二行是完整路径小字，点击即复制（成功短暂提示「已复制」）；一句话说明与名称都能右键修改，说明只在悬停 tooltip 中展示，不占列表行；说明只做展示，不参与任何路由。
- 头部「+」展开内联输入，回车提交绝对路径添加目录：服务端 realpath 探活、必须是目录，同名重复添加返回 409；成功后列表追加并自动选中，默认显示名取目录名。
- 目录行右键可重命名、编辑一句话说明与移除（内联输入，只改元数据，不影响已打开文件与展开状态）；移除只从清单删除、不动文件系统，其打开的文件视图与指向它的选中一并关闭，root 已失效（未就绪）的目录同样可移除。
- 运行时变更即时原子写回状态文件，重启服务后保留；状态文件损坏或条目非法时启动直接失败并给出明确错误，不静默回退。
- root 不存在或不可读时该目录标错可见（感叹号标记，悬停看错误），不影响其他目录。

### 本机目录浏览

目录树惰性加载：首次展开目录时请求其子项，按目录优先、名称排序。列表用虚拟化渲染，超 200 行仍可流畅滚动。

#### 验收

- 展开目录显示其子目录与文件，含名称、类型、大小与修改时间；再点击折叠。
- 刷新按钮重新拉取当前展开目录；加载中与失败状态就地可见，失败不吞掉其他目录。
- 路径越界（`..`、绝对路径段、NUL）被服务端拒绝并返回明确错误；workspace `root` 先经 realpath 解析，符号链接跳出的路径不可读写。
- 点击文件发布 `workspace.file` 选中，外壳工作区区域打开编辑器；点击目录仅树内高亮。

### 文件编辑

编辑器按文件类型分流：`.md` 默认用 ProseMirror 所见即所得编辑器（todo-web 同款：markdown-it 解析、prosemirror-markdown 序列化，直接编辑渲染结果，支持标题/列表/引用/代码块/行内样式的语法快捷输入），顶栏可切「源码」回 Monaco；其余文件用 Monaco Editor。两者都本地打包（不经 CDN），保存走 `Ctrl/Cmd+S` 或保存按钮。

#### 验收

- 打开 `.md` 文件默认进入所见即所得编辑：标题、列表、引用等渲染为排版样式而非原始标记；输入 `# `、`- `、`**加粗**` 等语法即时生效；顶栏「源码/预览」可切回 Monaco 源码编辑，草稿在两种模式间保留。
- 打开文本文件可编辑并保存；保存成功后脏标记清除，重新打开内容一致。
- 文件大于 2MB、或内容含 NUL（二进制）时不进编辑器，给出说明；保存请求体上限 5MB。
- 保存时携带打开时的 mtime，服务端发现文件已被外部修改则返回 409；界面提供「覆盖外部修改并保存」与「放弃本地修改重新加载」两条路。
- 编辑器切换文件时草稿保留在工作区存储中，切回不丢；脏文件在关闭前无需确认（后写覆盖语义）。

### 目录与文件操作

新建文件夹、重命名、删除直接对服务端文件系统生效，不做回收站。

#### 验收

- 工具条「新建文件夹」在当前选中目录（未选中时在根）下创建，重名或非法名称返回明确错误。
- 双击树内目录或文件行进入行内重命名，回车生效、Esc 取消；名称为空、含 `/`、与现有条目冲突时报错。
- 树行悬浮出现删除按钮，点击后弹内联确认对话框（契约禁原生 `confirm`）；删除目录递归生效；删除后父目录刷新，正在编辑的该文件视图关闭并刷新父目录。
- 目录重命名后，树内已展开的子树、草稿与选中状态自动迁移到新路径。
- 操作失败时错误可见，树不进入不一致状态。

### Git 状态视图与上游同步

资源管理器的主要浏览对象是 Git 仓库，最高频的问题是「仓库现在什么状态、刚改了哪些文件」。服务端跑三条只读命令（`git --no-optional-locks status --porcelain=v1 -z --branch`、`rev-parse --show-toplevel`、`diff --numstat HEAD`）拼出快照，与用户终端的 git 操作并存；快照里的分支行同时解析 ahead/behind 计数。`gitStatus` 是 provider 的可选能力，仅 local 实现。前端由独立的 git store 持有快照，树行按变更状态显示字母徽标（M/A/D/R/C/U），目录聚合变更计数。

除快照外，摘要条提供两个同步动作：推送（`git push`）与拉取（`git pull --ff-only`，分叉或冲突时拒绝，不产生合并提交）。同步命令前置校验当前分支有 upstream，60 秒超时，失败不重试；每次同步结束（无论成败）都重取快照。provider 对应可选能力 `gitPush` / `gitPull`，仅 local 实现。

#### 验收

- git 仓库 workspace 显示分支（detached 显示 detached）、变更文件数、+x/-y 行数，以及待推送（↑N）与待拉取（↓M）计数；点击分支或变更 chip 手动刷新。
- ↑N 点击推送、↓M 点击拉取；无 upstream 或计数为 0 时按钮禁用并给出原因提示；同步进行中两个按钮均禁用。
- 同步进行中底部状态条显示方向、不定态进度条与实时耗时；失败时状态条显示错误，点击关闭；成功后快照自动刷新，计数归零。
- 拉取遇分叉历史或冲突时拒绝快进，仓库保持原状，错误可见。
- 树内变更文件行显示状态字母徽标，目录行显示聚合计数；徽标随刷新更新，保存、新建、重命名、删除成功后同样更新。
- 暂存重命名只显示新路径单条；untracked 目录归并为单条目录徽标；冲突码透传为 U。
- 非 git 目录的 workspace 不显示任何 git 区块，不算错误；git 执行失败时摘要条显示「获取失败，点击重试」，重试成功后恢复。
- 不做轮询，快照仅随切换目录、点击刷新、文件操作与同步动作更新。

### 目录变更感知

第一版不做 watch 与推送：本机目录变更靠刷新按钮与重新展开。SSE 推送属后续阶段，接入时按外壳契约提供开关且嵌入模式默认关闭。

Git 仓库的状态快照沿用同一刷新语义：切换目录、点击刷新、文件操作成功后重取，不做轮询；推送/拉取动作结束时也重取。

#### 验收

- 外部修改本机目录后，点击刷新能看到最新内容，无需重启服务或刷新页面。

### 目录列表（一级侧栏）

二级侧边栏的一级列展示记录的目录列表，交互参考 todo-web 项目侧栏：点击切换、右键菜单操作、行内输入。

#### 验收

- 列表行显示目录显示名（默认目录名），悬停显示完整路径；当前激活目录高亮。
- 「+」与列表空白处右键都展开添加表单；重命名、移除走右键菜单，确认与输入一律内联，不用原生对话框。
- 添加失败（路径不存在、指向文件、重复目录）时错误就地可见，不关闭表单语义（下次添加重新展开）。
- 列表宽度固定 144px，不做栏内拖宽与折叠；外壳折叠按钮仍是整栏折叠入口。

## 边界

- provider 抽象只声明 local；SSH 与虚拟目录的接口预留写在 README，不在本版实现。
- 服务无鉴权，默认只绑定 `127.0.0.1`；改为对外监听必须同时引入访问控制。
- 带浏览器 `Origin` 头的请求必须来自回环地址或与 Host 同名的站点，否则拒绝（403 `forbidden_origin`），防止恶意网页盲打写接口；无 Origin 的客户端（curl 等）不受影响。
- 运行时可添加任意本机目录，攻击面等于「本机文件系统经 HTTP 可读写」；这以默认仅回环监听 + Origin 校验为前提，对外部署必须自行加鉴权。
- 服务只暴露清单内的目录；不做文件搜索、上传下载、二进制预览与权限编辑。
- Git 状态视图为只读：仅 local provider，不做暂存、提交、推送与 diff 内容查看，不自动轮询。
