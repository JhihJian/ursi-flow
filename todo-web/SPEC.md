# SUMM-Todo 看板

## 功能意图

看板为 SUMM-Todo 的本机待办库提供独立 Web 界面。用户按项目查看任务与投入时间，维护项目和任务，并可通过拖拽调整任务状态或归属。看板不依赖 ursi-flow 的其他模块，也不接管待办库的写入规则，数据由同目录的[服务端契约](server/HTTP.md)定义。

## 关键功能与验收

### 项目与任务浏览

#### 验收

- 打开页面自动选中活跃任务最多的项目，展示项目描述、路径、累计投入时间与任务数。
- 顶部显示项目数、今日、本周、本月与全部任务数；点击统计块按周期筛选任务表，未完成任务始终可见，已完成任务按完成时间过滤。
- 左侧项目列表显示每个项目的活跃任务数与累计时间，点击切换项目。任务表按未完成优先、优先级和创建时间排序，完成项置灰。
- 任务 ID 可点击复制，复制成功后短暂显示反馈。

### 维护项目与任务

#### 验收

- 可新建、编辑和删除项目；删除项目时其中任务保留为未归属状态，并自动切到下一个项目。
- 可在当前项目下新建任务，并在右侧详情面板编辑标题、优先级、状态、标签和结果；保存后列表、统计和活动任务同步刷新。
- 删除任务需要二次确认。标题为空或服务端拒绝请求时显示错误提示，界面保留当前输入。

### 拖拽调整状态与归属

#### 验收

- 拖动任务行首的 `⠿` 手柄到状态标签，任务状态更新并刷新列表与统计。移动到进行中或完成时按服务端规则补记开始与完成时间。
- 拖动任务到左侧项目项，任务改归属到该项目。开始拖动后状态标签和项目项显示虚线放置提示，悬停目标有明确高亮。
- 拖拽只在移动超过阈值后开始，普通点击仍打开任务详情。

### 活动任务与完成提醒

#### 验收

- 右侧活动面板列出所有项目中进行中和阻塞的任务，显示项目、标题和已用时间；点击后切到对应项目并打开详情。
- 待办库中出现新的完成任务时，播放提示音并发送桌面通知，随后刷新任务与统计。通知被静音时只刷新不提示，静音设置跨刷新保留。

### 独立构建与部署

#### 验收

- Web 可单独构建为静态包，通过同源 `/api` 访问服务端；服务端可单独启动并托管该静态包，不依赖 ursi-flow 其他服务。
- 三栏宽度可拖动调整并在刷新后保留；双击分隔线恢复默认宽度。服务端未启动时页面显示加载错误，不展示演示数据。
