# SUMM-Todo 看板

## 功能意图

看板为 SUMM-Todo 的本机待办库提供独立 Web 界面。用户按项目查看任务与投入时间，维护项目和任务，并可通过拖拽调整任务状态或归属。看板不依赖 ursi-flow 的其他模块，任务与项目实体、状态机、写入规则统一由本目录 [`core`](core/src/task.rs) crate（`todo-core`，最早来自 SUMM-Todo）提供，看板自身不重复定义字段与状态迁移规则，数据由同目录的[服务端契约](server/HTTP.md)定义。

## 关键功能与验收

### 项目与任务浏览

#### 验收

- 打开页面自动选中活跃任务最多的项目。项目名称、活跃任务数与累计时间只显示在左侧列表，内容栏不重复展示；项目描述和路径通过列表项的悬停提示查看。
- 左侧项目列表显示每个项目的活跃任务数与累计时间，点击切换项目。任务表按未完成优先、优先级和创建时间排序，已完成和已取消项置灰。项目计数覆盖进行中、阻塞、待办、完成与取消五种状态。
- Projects 侧边栏可折叠为 32px 单列窄条。折叠后不显示项目列表，改为一条侧转 90°、自下而上的单列文字（拉丁字母随行旋转，中文直立），依次为当前项目名称、活跃任务数和累计时间；名称过长时从尾部截断、开头始终可见，悬停可看全文。点击窄条或展开按钮恢复折叠前宽度，把分隔线拖到最小宽度也会折叠。
- 任务列表上方左侧显示最近七天每天新建任务数的条形区（状态标签在右侧）。条形区总宽固定，各天按当天任务数占比分配宽度，零数量仍保留最小可点宽度；日期标签占固定宽度，无筛选时留空，悬停显示日期与数量。
- 点击某一天的条形按创建日期筛选任务，日期以 `MM-DD` 显示在条形左侧；再次点击同一条形取消筛选。筛选当天空闲时提示该日期没有任务。按天或按状态筛选都不会关闭已打开的详情面板。
- 任务列表上方的状态标签只显示状态符号与计数、不显示状态单词，可点击按状态筛选：再次点击同一标签或点击其他标签会切换，全部取消后恢复显示全部任务；筛选为空时提示当前状态没有任务。计数始终按当前项目的全量任务统计。
- 任务 ID 只在详情面板的元信息行展示，点击可复制，复制成功后短暂显示反馈；任务表不显示 ID 列。当前打开详情的任务在任务表中显示选中标记。
- 详情标题行右侧的复制按钮把当前面板内容导出为 Markdown 文本：标题、状态、优先级、标签、时间和正文。复制成功时按钮短暂显示对勾；局域网 http 访问也能复制。
- 详情面板停靠在任务列表下方，打开时自下而上弹出；列表被压缩后仍独立滚动，最后一行不会被面板遮挡。
- 详情按一篇连续文档呈现：大标题、一行元信息（状态、优先级、标签、时间）、Markdown 正文和底部工具条，不使用分块表单。
- 正文是所见即所得的 Markdown 编辑区，编辑时直接看到渲染结果，没有源码与预览的切换。输入 `**加粗**`、`# `、`- `、`> ` 等语法会即时生效，选中文字可用快捷键切换加粗、斜体与行内代码。
- 编辑区覆盖 CommonMark 子集：标题、段落、列表、引用、代码块、行内代码、链接、粗斜体、分隔线和图片。GFM 表格等扩展语法不在此编辑器内，按普通文本保存。原始 HTML 不作为标签执行。
- 拖动面板顶部横条可调整高度，高度在刷新后保留；双击横条恢复默认高度。

### 维护项目与任务

#### 验收

- 项目操作全部从列表右键菜单发起，侧栏与内容栏都不提供按钮：项目项右键为 `New task`、`New project`、`Edit project`、`Delete project`，列表空白处右键为 `New project`。
- 项目的名称、描述和路径在底部面板中编辑。项目和任务的删除都需要二次确认；删除当前项目时其中任务保留为未归属状态，并自动切到下一个项目。
- 可在当前项目下新建任务，并在任务列表下方的详情面板编辑标题、优先级、状态、标签和备注。元信息行用 `status`、`pri`、`tags` 三个小标签分别对应状态下拉、优先级下拉和标签输入；保存后列表和统计同步刷新，优先级变化会改变任务在表中的排序。
- 状态变更走 `todo-core` 的状态机：完成任务必须填写结果，阻塞任务必须填写原因，不可达的迁移和已取消任务的再次变更返回错误并保留当前输入。
- 删除任务只从任务行右键菜单发起，需要二次确认。详情面板底部只有 `Close` 和 `Save`，关闭不保存。标题为空或服务端拒绝请求时显示错误提示，界面保留当前输入。

### 拖拽调整状态与归属

#### 验收

- 拖动任务行首的 `⠿` 手柄到状态标签，任务按 `todo-core` 状态机迁移并刷新列表。进入进行中或完成时补记开始与完成时间；缺少结果或迁移非法时不落库，界面显示服务端错误。
- 拖动任务到左侧项目项，任务改归属到该项目。开始拖动后状态标签和项目项显示虚线放置提示，悬停目标有明确高亮。
- 拖拽只在移动超过阈值后开始，普通点击仍打开任务详情。

### 完成提醒

#### 验收

- 待办库中出现新的完成任务时，播放提示音并发送桌面通知，随后刷新任务。通知被静音时只刷新不提示，静音设置跨刷新保留。

### 独立构建与部署

#### 验收

- Web 可单独构建为静态包，通过同源 `/api` 访问服务端；服务端可单独启动并托管该静态包，不依赖 ursi-flow 其他服务。
- 项目栏与内容栏的宽度可拖动调整并在刷新后保留；双击分隔线恢复默认宽度。服务端未启动时页面显示加载错误，不展示演示数据。
