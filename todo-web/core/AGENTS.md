# todo-web/core 变更约束

本目录是任务与项目实体、状态机、错误码和 ID 规则的唯一来源，看板服务端直接依赖这里的类型与纯函数。

## 硬性约束

- 未经用户明确确认，不得修改本目录下的任何文件，包括实体字段、状态迁移、错误码、ID 规则和依赖版本。
- 需要调整时，先说清改什么、影响哪些调用方、库数据会受什么影响，得到用户确认后再动手。
- 修复编译告警、格式化、升级依赖、补测试同样算修改，也需要确认。
- 发现问题时先报告现象、根因和建议方案，不要顺手改代码。
- 只读操作不受限制：阅读代码、搜索、`cargo test`、`cargo clippy` 等检查命令可以先跑。
