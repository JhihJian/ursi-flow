# 工作清单

## 功能意图

经办人按类别维护待办事项，按需从某次事项与配方快照生成独立的文件型工作包。清单与按模板派出的办理单分别存储。

## 关键功能与验收

### 维护事项和配方

#### 验收

- 仅提供标题即可新建。初始类别为 `pending`，说明为空、配方为 `null`、修订为 1。按类别查询和重启后的详情均反映最后一次保存。
- 类别可以在 `pending`、`active`、`continuous`、`completed` 间直接切换。保存配方时保留资源顺序，拒绝空标识、重复别名与空脚本。保存不触发资源读取或派工。
- PUT 修改事项内容时递增修订，重复保存相同内容保持修订。提交过期修订返回 409，保留已保存的内容。

### 生成工作包

#### 验收

- 成功生成返回工作包，文件按相对路径和原始字节写入，当前归属为该工作项。包保留转换器提供的来源快照。
- 同一工作项使用相同 `requestId` 重试，返回原包的当前记录。并发提交只发布一份目录和包；服务重启、工作项改版或包改绑后仍能找到原包。新的请求标识产生独立包。
- 转换使用开始时的工作项快照，登记目录、包和请求结果时重新核对修订。生成期间工作项改版或删除返回 409。转换失败、文件非法或版本检查失败均不发布目录或包。

### 删除和解绑

#### 验收

- 删除事项和清除关联包的 `workItemId` 在一次存储更新中完成。已改绑其他工作项的包保留其归属。
- 删除后仍能通过原包 ID 和目录 ID 读回包、文件及生成来源。
