# 规划画布

## 功能意图

画布模块维护两层规划图：项目地图由画布节点组成，单张画布由任务卡节点组成。关系表达规划先后，布局记录节点位置。事项归属由工作规划模块协调，画布模块可独立维护空图。

## 关键功能与验收

### 画布、任务卡与关系

#### 验收

- 初建图包含一张默认画布，新增画布追加到列表末尾。改名保持 ID，项目至少保留一张画布。
- 地图关系只连接项目内的画布；画布关系只连接同一张画布的任务卡。跨作用域、重复、自环和成环的关系被拒绝。重接关系保持原 ID 和作用域。
- 删除任务卡清除关联边与坐标；删除画布清除地图上的关联边和坐标，并清除该画布的任务卡、关系和布局。

### 独立布局

#### 验收

- 地图和每张画布分别校验布局修订。提交全量坐标覆盖当前图的布局，空坐标集重置布局。坐标只接受当前图内节点和有限数值。
- 过期修订返回冲突。结构删除清除已保存坐标时，对应布局修订递增，过期布局无法恢复已删除的坐标。
