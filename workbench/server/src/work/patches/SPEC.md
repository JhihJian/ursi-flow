# 工作包与配置包目录

## 功能意图

一个包是 Server 私有目录中的一棵文件树，另有一个名称。工作包保存一次任务需要的文件，配置包用 `AGENTS.md`、`skills/` 和 `mcp.json` 维护一套智能体配置。包只做文件存取，不接入执行、SOP 或版本。

## 关键功能与验收

### 包的建立与查找

#### 验收

- 新建只接受 `name`：去掉首尾空白后为 1 至 80 个字符，不含控制字符，其他字段一律拒绝。成功返回 `{id,name}`，标识由服务端生成。
- 列表只返回 `{id,name}`，不含磁盘路径、条目数或更新时间。两类包分别在 `patches/work/<id>` 与 `patches/config/<id>` 下，用另一类的标识访问返回 404。
- 新建时先建私有目录并写入初始内容，再登记记录；任一步失败都删除目录，包不出现在列表中。首次启动自动建立两类包的根目录，已存在的目录同样要通过私有目录校验。
- 包名只在界面与列表中出现，不参与路径；私有根只由类别和服务端标识拼成。

### 配置包锚点

#### 验收

- 新建配置包自带空 `AGENTS.md`、空目录 `skills/` 和内容为 `{"mcpServers":{}}` 的 `mcp.json`；新建工作包初始为空。
- 写入 `mcp.json` 前校验正文为合法 JSON 对象，失败返回 400 且原文件不变。该检查在取得写锁之前完成，坏正文不进入临界区。
- 三个锚点不能被移动、改名或删除（409），也不能被其他条目改名占用；`skills/` 之下的内容不受限。工作包没有锚点，只受通用路径规则约束。

### 包内路径与内容

#### 验收

- 接口只接受包根相对路径：按 `/` 分段后每段非空、不超过 255 字节、不是 `.` 或 `..`、不含控制字符；整条路径不超过 1024 字节且最多 32 段。绝对路径、空路径、重复分隔符和 `.` 段一律 400。
- 逐级解析父目录，任意一级是符号链接或不是目录即拒绝；父目录不存在返回 404，不隐式创建。列出全树时列出普通点文件，跳过符号链接与使用保留前缀 `.workbench-tmp-` 的内部文件，只公布 `{path,kind,size}`。
- 文件按原始字节读写，不经过文本解码；单文件上限 8 MiB，超限返回 400 且不落盘。空文件是合法内容。
- 写入默认只新建不存在的文件，已存在返回 409；只有 `replace=true` 才覆盖。写入先在同目录建临时文件、写满并同步，再原子改名到目标名，最后同步目录项；失败时删除临时文件。
- 包内写操作都在同一个存储写锁内完成，并发写同一路径不会交错，最终内容必定是某一次写入的完整结果。不同包互不影响。
- 移动或改名不覆盖已存在的目标（409），也不能把目录移入自身子树（400），目标父目录不存在返回 404。删除可作用于非空目录，目标不存在返回 404。

### 边界

#### 验收

- 包内容不由服务执行或加载，不产生工作项、执行尝试或 SOP 修订，也不改变派工模板。
- 服务不提供通用宿主文件浏览；只有持有管理令牌的调用方能通过这批接口读写包。
