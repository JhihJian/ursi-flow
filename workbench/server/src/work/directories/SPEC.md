# 虚拟目录资源

## 功能意图

一个目录是 Server 私有根下的一棵文件树，用服务端生成的标识寻址，不保存名称。目录只做文件存取，可附加两类路径约束：固定位置不能移动或删除，指定文件必须是 JSON 对象。工作包、配置包等上层资源复用本模块建立目录，并在同一笔存储更新中登记自己的记录。

## 关键功能与验收

### 建立与查找

#### 验收

- `POST /v2/directories` 只接受空 JSON 对象，返回 `{id}`，标识由服务端生成。列表与元数据接口也只公布 `{id}`，不含宿主路径、条目数或更新时间。
- 每个目录的私有根是 `directories/<id>`。首次启动自动建立 `directories/`；已存在的根同样要通过私有目录和符号链接校验，不满足时服务拒绝启动。
- 新建先建私有目录、执行调用方 seed，再在同一笔存储更新里登记目录元信息和调用方记录。seed 或登记失败时删除磁盘目录，列表与调用方表都不出现半成品。
- 路径约束随目录记录保存。直接通过目录接口建立的目录没有路径约束；上层资源可在创建时声明约束。

### 路径与内容

#### 验收

- 接口只接受目录根相对路径：按 `/` 分段后每段非空、不超过 255 字节、不是 `.` 或 `..`、不含控制字符；整条路径不超过 1024 字节且最多 32 段。绝对路径、空路径、重复分隔符和 `.` 段一律 400。
- 逐级解析父目录，任意一级是符号链接或不是目录即拒绝；父目录不存在返回 404，不隐式创建。列出全树时列出普通点文件，跳过符号链接与使用保留前缀 `.workbench-tmp-` 的内部文件，只公布 `{path,kind,size}`。
- 文件按原始字节读写，不经过文本解码；单文件上限 8 MiB，超限返回 400 且不落盘。空文件是合法内容。
- 写入默认只新建不存在的文件，已存在返回 409；只有 `replace=true` 才覆盖。写入先在同目录建临时文件、写满并同步，再原子改名到目标名，最后同步目录项；失败时删除临时文件。
- 目录内写操作都在同一个存储写锁内完成，并发写同一路径不会交错，最终内容必定是某一次写入的完整结果。不同目录互不影响。
- 移动或改名不覆盖已存在的目标（409），也不能把目录移入自身子树（400），目标父目录不存在返回 404。删除可作用于非空目录，目标不存在返回 404。

### 路径约束

#### 验收

- `fixed` 中的精确路径不能移动或删除，移动目标也不能占用这些路径。对固定路径的上级目录做移动或删除同样返回 409，因为会一并带走固定位置；写入也不能用文件占住受保护路径的上级目录。固定目录之下的普通条目不受限制。
- `json_objects` 中的路径只能写入合法 JSON 对象，失败返回 400 且原文件不变。移动条目到这类路径时校验来源正文，不能借移动绕过写入检查。
- 约束在取得写锁之前判断。调用方在 seed 中直接使用文件操作建立初始内容，不受接口约束。

### 冻结

#### 验收

- 目录记录带 `state`，取 `writable` 或 `frozen`。新建目录为 `writable`。
- 冻结只看元信息，不改变文件内容。对冻结目录的写入、建目录、移动和删除返回 409，读取正文和全树清单不受影响。
- 工作包和配置包不冻结，它们的可写行为与路径约束保持不变。

### 边界

#### 验收

- 目录资源不依赖工作包、SOP、执行、来源或版本，不产生工作项或执行尝试。上层记录只保存目录标识。
- 服务不提供通用宿主文件浏览；只有持有管理令牌的调用方能通过这批接口读写目录。没有公开的冻结接口。
