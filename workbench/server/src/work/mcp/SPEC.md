# 平台 MCP 资源与工作包转换

## 功能意图

经办人从已登记的 MCP 服务选择资源，用工作项的 Python 配方把本次读取的材料转换为工作包文件。管理员掌握出站地址和凭据授权；工作项只保存服务标识、资源 URI 和配方。转换产物交给工作清单模块登记。

## 关键功能与验收

### 登记与发现

#### 验收

- 管理 API 可以列出、登记和删除服务。登记成功得到持久的服务标识。删除后，原标识无法用于发现或生成。
- 页面登记绑定完整服务地址与可选的平台变量名，无需部署策略文件。引用不存在或不能用于 Bearer 的值时拒绝登记。服务记录与列表只含引用。新会话使用当前平台值，删除变量后停止连接。
- 部署级策略文件存在时，登记和连接必须匹配完整地址与凭据引用；文件策略模式始终要求该文件，且仅此模式允许回退到同名进程变量。
- 使用官方 `rmcp` SDK 协商 Streamable HTTP 会话并逐页请求 `resources/list`，兼容 POST 返回的 JSON 和 SSE。资源数组包含名称、URI、可选媒体类型和描述。每个 HTTP 响应累计不超过 4 MiB，通信不自动重连或重放。
- 检查接口同时返回本次协商的协议版本、对端实现标识及资源、工具、提示词的能力声明。未声明资源能力的服务可完成检查，结果中资源数组为空，且不请求 `resources/list`。
- 协议错误、游标循环、超时或响应超限使整次发现失败。

### 工具、提示词与模板

#### 验收

- 认证接口按服务能力发现工具、提示词、资源模板；支持分页，重复项、循环游标或限额超出时整次失败。
- 工具调用前检查精确名称白名单和可选部署策略，默认拒绝。调用保留原始 MCP 结果，不重放请求。提示词接受字符串参数，返回消息。
- 每个服务独立保存设置。GitHub 工具集和只读头仅发往官方默认 HTTPS 端点，不改变本地调用许可。

### 单个资源预览

#### 验收

- 预览接口接收服务标识和资源 URI，新建会话调用 `resources/read`，返回每个分片的 URI、可选媒体类型和 `text` 或 `blob` 之一。URI 为空或超过 4096 字节时拒绝请求，不建立连接。
- 预览与发现、生成共用四个并发名额和 4 MiB 响应上限，单次限时 25 秒。远端 JSON-RPC 错误和连接失败只返回固定的不可用提示，不回显远端原文。预览只读取，不写入工作项、目录或生成记录。

### 读取与隔离转换

#### 验收

- 每次生成重新调用所选服务的 `resources/read`。脚本读取生成开始时工作项的 ID、标题、说明、类别与状态，按别名取得资源内容，Unicode 文本与 Base64 二进制均可转换为文件。读取失败时不执行脚本。
- 只有命名空间、权限限制和系统调用过滤器全部就绪后，平台才发送脚本和输入。脚本不能打开宿主文件、创建进程、连接网络或取得平台凭据。隔离设施缺失时返回错误。
- 转换有 CPU、地址空间、总时长和管道字节限额。超过限额、抛出异常、非法编码、路径越界、重复路径、文件与目录冲突均使整次转换失败。
- 成功结果含包名、校验后的文件字节和生成来源：工作项 ID、标题、修订、脚本 SHA-256、各资源的别名、服务标识、URI、内容 SHA-256 和读取时间。转换器不写正式文件目录。
