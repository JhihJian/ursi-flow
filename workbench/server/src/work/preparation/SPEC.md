# 工作包准备

## 功能意图

按类型创建工作包草稿并准备需求与材料。草稿不绑定 SOP 版本，执行时才选定并冻结。

## 关键功能与验收

### 手动准备材料

#### 验收

- 创建工作包只接受类型和需求，类型提供推荐默认 SOP 引用，草稿不保存 SOP 绑定。固定材料角色随类型保存，材料不齐时仍可保存需求。
- 需求非空且每个材料角色都已收存时 `ready` 为 true。就绪只表示材料准备完成，不冻结工作包，也不代表执行或验收结果；冻结只发生在执行时。
- 每个角色接收一份不超过 16 MiB 的原始文件，不解压，重复收存返回冲突。文件名不参与路径计算。
- 首次执行前可撤回某个角色的材料，释放其正文并把该角色空出来供重新收存；撤回先落盘元数据再删除旧文件，同一工作包的其他角色、其他工作包的同名文件都不受影响。
- 其他工作包的同名文件独立。工作包冻结或已有执行尝试后不再接受材料撤回、材料收存或需求修改。
