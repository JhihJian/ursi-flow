# 工作包生成

## 功能意图

把 Python 转换脚本发布为版本化生成器，从已登记的 MCP 资源独立生成文件型工作包。运行可关联工作项作为业务上下文，也可作为试运行独立执行；清单模块只提供事项信息，本模块不写事项字段。

## 关键功能与验收

### 版本化生成器与运行记录

#### 验收

- 生成器定义（标识、名称、输入别名、脚本）按修订发布，修订从 1 递增且历史不可变。发布新版、提交运行均不改变已有运行记录。
- 运行请求统一为 `{generator:{id,revision}, resources, workItemId?}`。受理即登记运行并校验生成器修订、资源别名对应关系与工作项存在性；同 ID 同请求重放原记录，异请求返回 409。生成不依赖 Flow 或提交连接。
- 试运行首次发布即为只读目录；关联工作项的运行发布可编辑包并登记归属。发布时只校验事项仍存在，已删除则整次回滚。读取、转换、校验及发布失败均保留阶段且没有可见产物。
- 每次生成重新读取资源并校验快照总量。读取失败时不运行脚本。沙箱就绪后才发送脚本与材料，脚本无法获得宿主文件、子进程、网络或平台凭据；隔离不可用、超限或产物非法时整次失败。
- 重启将未完成的运行记为中断。同一 ID 可查回终态，不重跑。历史记录保留生成器修订、输入引用和已完成运行的内容摘要，已发布包可通过来源回到记录。

### 删除和解绑

#### 验收

- 工作项删除不触碰运行记录与已发布包；包的归属清除后仍能通过原包 ID 和目录 ID 读回包、文件及生成来源。
