# 手动工作包与 SOP

## 功能意图

经办人按工作包类型提交一份需求和材料，由指定版本的 SOP 运行并取得本次产物。内置 Echo 在当前进程中只读材料，不需要外部服务。

## 关键功能与验收

### 定义与准备

#### 验收

- 初次启动即可使用单条线索报告类型。默认 SOP 为 `receipt@1`，必交材料为 `finding` 和 `source`。发布同名 SOP 新修订不改变已选定的旧修订。
- 草稿允许材料未齐，只有材料齐全且需求非空才能执行。文件名是显示信息，两个工作包的同名文件独立保存，压缩包不解压。

### 执行与取件

#### 验收

- 执行时冻结需求、材料清单和固定版本绑定；新尝试读取实际上传的字节并写出带内容摘要的回执。结果不代表漏洞判断或交付验收。
- 同单重跑生成新尝试。按单号和尝试号查看或下载该次回执，读取另一单的尝试不能取得成果。重启不丢失历史。
