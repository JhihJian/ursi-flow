# 执行尝试面板

## 功能意图

执行器编辑页可用当前草稿试跑，工作包页可用指定修订启动执行。两个入口按尝试 ID 核对结果，查看和下载本次生成的文件。

## 关键功能与验收

### 启动与试跑

#### 验收

- `AttemptPanel` 接收 `target`、可选的 `workPatchId` 和 `storageKey`。指令非空白且有目标时才能启动。请求包含该目标、原样保留的 UTF-8 指令和选定的工作包 ID；没有工作包时省略该字段。
- 面板可放入既有表单，试跑、启动、取消和读取文件都不提交外层表单。
- 试跑后按启动时的 `previewDefinition` 内容比较当前配置。编辑草稿后标明旧结果，还原相同内容后撤去提示。目标变为空时禁用启动，保留本次状态、取消入口和已取得的制品。

### 状态核对与恢复

#### 验收

- 一次启动生成一个 UUID，只发送一次 PUT。若回执丢失，使用原 UUID 发 GET；仅接受 ID 匹配且状态已知的回执。回执不符时不打开其制品目录，查询失败仍显示原 ID 和重新查询入口。
- 指定 `storageKey` 时，在发出 PUT 前按该键保存 UUID。重新打开同一工作包只查询该 ID，切换键读取对应工作包；不持久化指令、草稿或文件内容。
- 启动中、运行中及待核实的尝试按同一 ID 串行轮询，可发出取消请求；以后端回报确认终态，成功、失败或已取消后停止轮询。迟到的查询不能覆盖取消结果。

### 只读制品

#### 验收

- 有 `artifactDirectoryId` 时，通过虚拟目录客户端读取文件树，按相对路径打开文件；空目录显示空态。目录或文件读取失败可重读，切换文件不沿用旧内容。
- 小型 UTF-8 文本以纯文本显示；二进制或超过 256 KiB 的文件提示下载。下载使用原始 Blob 和文件名，不提供文件写入操作。
