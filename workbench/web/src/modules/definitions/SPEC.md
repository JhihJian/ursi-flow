# 工作定义

## 功能意图

维护资源、执行器和派工模板，按固定版本核对依赖、发布新版或发起工作。派工模板是旧的派工定义，页面统一挂在 `/templates`；读取和发布仍用 `/api/v2/packages`，也不与新的工作包（`/workspaces`）共用页面。

## 关键功能与验收

### 目录、历史和跳转

#### 验收

- `/templates`、`/resources`、`/executors` 列出最新版本及对象启停状态。执行器目录额外展示固定契约 `workspace + workInstruction → artifactDirectory`、固定资源摘要和配置字段数量；资源可按 Skill、提示词和 MCP 引用筛选。读取失败提供重试，成功但无结果显示空态。
- 用户熟悉的 `/packages` 和 `/packages/new` 直接进入真正的工作包列表与新建（`/workspaces`、`/workspaces/new`），不显示派工模板目录或表单。
- `/:id` 读取最新详情，`/:id/revisions` 展示历史，`/:id/revisions/:revision` 直接打开冻结正文。查看旧版本时同一行同时显示正在阅读的修订号、最新修订号和对象启停状态，并标明历史版本只读。
- 派工模板展示目标、办理说明、输入输出、交付文件、验收标准，以及每个动作绑定的执行器与资源版本。动作按「动作名 → 执行器版本 → 资源版本」展示，并如实标注快照不保存动作级输入输出声明。执行器详情只展示 `workspace + workInstruction → artifactDirectory` 契约、资源依赖、configSchema 动态表单和日志记录位置；执行器不展示或编辑业务输入输出端口。
- 「发起工作」携带正在阅读的模板 ID 与修订号，跳至 `/items/new?package=…&revision=…`，模板更新后旧版本的链接仍带原修订号。确认停用前告知对新派工和新引用的影响，并说明已有单据及其派工快照不受影响；停用后仍可打开历史版本。

### 表单发布

#### 验收

- 从各目录的 `/new` 可依次发布文本资源、引用它的通用执行器以及固定该执行器版本的派工模板，执行器表单只提交 ID、固定资源和可选 configSchema，并以只读方式展示通用执行契约；执行器不编辑输入输出端口，端口声明只属于派工模板及动作。普通流程通过有标签的输入框、选择器和可增删的字段行完成。小屏表单按单列排列。
- MCP 资源只填写服务与凭据引用，页面说明连接参数由管理员管理、当前执行后端不支持运行时注入，因此不能选为可执行依赖。执行器不提供 Agent、Flow、环境或后端绑定选择，程序、工作目录、环境变量和命令由服务端管理。
- 派工模板支持模板级资源和输入输出、多个动作、动作级资源、继承或覆盖模板声明。交付物按行录入文件名并忽略空行；重复动作名、重复声明字段名不能覆盖先前的输入。
- 指定版本的 `/edit` 基于该版生成草稿。模板快照中展开的资源和执行器转为固定引用；模板资源与固定执行器已提供的资源默认作为继承项，剩余资源归入对应动作。结构化目标按原 JSON 类型保存。
- 旧模板快照无法区分重复资源的原始归属，也不包含原动作级输入输出声明。草稿说明此限制，允许逐动作重设；须勾选「我已核对动作资源和输入输出声明」才能发布。读取固定依赖失败时可重试，不用最新版替代。
- 缺少可用执行器时，表单提供补建依赖的入口。未发布的草稿只保存在当前标签页，返回同一编辑页时提示已恢复并允许放弃；发布失败或校验失败保留已填内容，成功后清除草稿并打开响应给出的新版本。停用的 ID 不提供发布入口。
- 执行器和动作目标只保留 `id`、`revision`、`resources`、`configSchema`。响应中的 `configSchema` 只依据服务端 schema 渲染 `string`、`url`、`secret`、`enum`、`integer`、`number`、`boolean` 和 `configPackage` 动态表单，默认值仅用于展示；发布请求不生成 `config`，也不新增或推导 `kind`、`environment`、`flowId`、`flowRevision` 字段。
- 动态表单区分 schema 默认值与未声明值，`false` 和 `0` 正常展示。`secret` 只显示受控的密码控件和服务端管理提示，不回显内部引用或明文；配置值不进入发布请求。
- `configPackage` 只消费配置包的公开 `id/name`，通过 `/api/v2/patches/config` 读取，不显示 `directoryId`、宿主路径或目录内容。服务端未提供 schema 时，编辑器不显示动态字段区。
