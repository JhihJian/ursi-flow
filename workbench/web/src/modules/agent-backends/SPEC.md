# Agent 后端设置

## 功能意图

用户在平台设置查看 Agent 适配器的公开状态，并在选择执行器后端前检查连通性。适配器安装路径和启动配置由管理员管理。

## 关键功能与验收

### 后端列表与检查

#### 验收

- 桌面和移动导航都可打开受登录保护的 `/settings/agent-backends`。列表显示每个后端的名称、ID、能力、配置状态、最近连通性和本地检查时间。未经检查、检查失败与已连通可区分，无时间记录时显示占位文字。
- 读取列表不会触发检查。手动检查已配置的后端时，只向该 ID 发送 POST，更新该行，不影响其他后端。页面说明仅验证适配器控制接口，不运行模型或验证工具执行。
- 空列表与读取失败可区分，网络失败可重试，不回显管理员路径或底层错误正文。从执行器编辑页进入时可返回同一草稿，重新取得该配置包的匹配结果。
