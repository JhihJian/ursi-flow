# Web 图形画布

## 功能意图

`CanvasGraph` 为 Web 页面提供可复用的有向图交互。组件负责图形呈现与交互，调用方负责排布初始坐标、校验和保存变更、切换作用域及提供窄屏备用界面。

## 关键功能与验收

### 展示与定位

#### 验收

- 传入带坐标的节点和带起止节点 ID 的边，桌面画布在自有高度内显示节点卡片和方向箭头。卡片支持自定义内容，卡内操作独立于图节点操作。
- 用户可平移、缩放和适应视图。`showMiniMap` 开启缩略图。`focusNodeId` 指向的节点完成布局后，画布居中显示该节点并保留当前缩放比例。每个聚焦请求执行一次。同一节点的新请求可通过 `focusKey` 发起，普通数据更新保留用户调整的视口。

### 交互与数据同步

#### 验收

- 拖动节点时画布展示临时位置，松手时通过 `onMove` 回传最终坐标。松手后展示调用方提供的坐标，调用方可以先更新坐标再保存，也可以直接采用服务端回传结果。切换作用域时，调用方以 `key` 创建新的画布实例。
- 图上高亮取自调用方的 `selection`。选中节点或边时回传目标，点击空白清空选择；双击节点通过 `onOpenNode` 回传 ID。
- 提供 `onContext` 时，右键点中空白、节点或边会回传目标和菜单锚点。调用方决定操作，卡内自定义内容也可处理自己的右键事件。
- `editableEdges` 与对应回调同时启用时，连接和重接分别回传端点 ID、或边 ID 与新端点 ID。画布以调用方提交的新边列表展示结果。
