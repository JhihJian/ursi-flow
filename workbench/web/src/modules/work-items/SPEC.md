# 工作清单与平台资源

## 功能意图

记录可独立维护的工作事项，按需从指定的 MCP 资源和 Python 配方生成文件型工作包。

## 关键功能与验收

### 事项与当前归属

#### 验收

- `/work-items` 按类别筛选，显示标题、类别和当前关联包数。只填标题即可建一项待开始工作，无需先配置 MCP。
- 查看说明、配方和关联包；包名链接到工作包编辑台。编辑携带读取时的修订号，冲突时显示错误并保留草稿。
- 删除前提示将解绑的包数和保留的材料。包数读取失败时不能以零代替，也不能确认删除。

### 平台服务与配方

#### 验收

- `/mcp-servers` 登记服务名称、地址和可选的凭据环境变量名；可列出服务资源、删除服务。凭据只使用引用。
- 资源按服务列出，用户可跨服务选择同名资源，按选择顺序指定唯一别名；保存配方保留 `(alias, serverId, uri)` 与脚本原文，关闭来源可保存为 `null`。
- 生成只使用已保存的配方。同次生成的失败重试沿用请求标识，成功后打开返回的工作包，再次主动生成使用新标识。生成不调用派工接口，也不改变类别。
