# 工作清单

## 功能意图

记录可独立维护的工作事项：标题、说明、类别与状态。事项可选绑定一个工作包生成器作为工作包来源，绑定与生成流程由工作包生成器模块承担。

## 关键功能与验收

### 事项管理

#### 验收

- 新建表单不提供状态选择；只填标题即可创建一次性、待开始的工作项，无需先配置 MCP。类别为一次性工作（`one_time`）或持续工作（`continuous`），状态为待开始（`pending`）、进行中（`active`）或已完成（`completed`）。编辑其中一项不改变另一项，详情和列表均显示已保存的类别与状态。
- `/work-items` 每行显示标题、类别、状态和当前关联包数。类别与状态可单独筛选，组合时仅显示同时匹配的项。URL 查询参数 `category` 和 `status` 记录已选条件，刷新可恢复；清除一个条件保留另一个。
- 详情展示说明、工作包来源和关联包；包名链接到工作包编辑台。编辑携带读取时的修订号，冲突时显示错误并保留草稿。
- 删除前提示将解绑的包数和保留的材料。包数读取失败时不能以零代替，也不能确认删除。删除后关联包保留并解除关联。

### 绑定工作包生成器

#### 验收

- 编辑工作项可绑定一个生成器版本或保持未配置。保存绑定时固定已选版本，并为各输入别名保存 MCP 引用；「清除绑定」保存为 `null`。
- 工作项详情链接到绑定的指定版本。发布新版后旧绑定保持原样。点击生成使用已保存的绑定，打开本次生成详情；从「生成记录」可查看按工作项筛选的历史。
