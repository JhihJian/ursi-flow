# 工作清单

## 功能意图

记录可独立维护的工作事项：标题、说明、类别与状态。工作包生成由工作包生成器模块独立承担，清单只保留事项信息与按工作项筛选的生成记录入口。

## 关键功能与验收

### 事项管理

#### 验收

- 新建表单不提供状态选择；只填标题即可创建一次性、待开始的工作项。类别为一次性工作（`one_time`）或持续工作（`continuous`），状态为待开始（`pending`）、进行中（`active`）或已完成（`completed`）。编辑其中一项不改变另一项，详情和列表均显示已保存的类别与状态。
- `/work-items` 每行显示标题、类别、状态和当前关联包数。类别与状态可单独筛选，组合时仅显示同时匹配的项。URL 查询参数 `category` 和 `status` 记录已选条件，刷新可恢复；清除一个条件保留另一个。
- 详情展示说明、关联包和本项的生成记录入口；包名链接到工作包编辑台。编辑携带读取时的修订号，冲突时显示错误并保留草稿。
- 删除前提示将解绑的包数和保留的材料。包数读取失败时不能以零代替，也不能确认删除。删除后关联包保留并解除关联。

### 项目规划工作区

#### 验收

- 从「工作项目」创建项目并获得默认画布。侧栏树按项目、画布、任务卡、TODO 展示，支持分别展开各层、置顶和刷新。点项目打开地图，点画布打开编辑器，点任务卡或 TODO 定位回画布。TODO 行显示人工状态，卡内顺序与画布一致。原全局清单和登录落点不变。
- 当前项目的树和主视图共享快照。改名、新建、删除、重排和更新事项后同步显示。项目导航恢复最近可用项目，显式 URL 优先。
- 地图上显示各画布全量 TODO 状态。打开地图节点可进入可编辑画布；桌面支持拖动、缩放及关系编辑，窄屏通过列表和表单维护规划。地图与单张画布的布局独立保存，可分别重置。
- 桌面右键空白可新建画布或任务卡，空图也可操作。右键画布节点、任务卡、关系线和 TODO 时显示对应操作。菜单沿用现有编辑表单及删除保护，支持键盘选项和 Esc 关闭。窄屏保留列表和表单入口。
- 一张任务卡可创建或加入多条现有事项，同一项目内可以在卡之间移动、在卡内重排，或移出并保留在全局清单。连线只表达计划先后，关闭 Flow 仍可使用。
- TODO 面板按已有人工状态分组，画布、任务卡和类别筛选保留在 URL。侧栏可编辑原工作项及定位到卡内对应条目，从画布返回后保留筛选。旧工作项详情可以打开其当前画布，继续提供包与生成记录入口。
- 保存遇到修订冲突时提示并重读快照，不覆盖服务端新数据。事项筛选和规划修改不能触发生成、自动办理状态更新或执行。
