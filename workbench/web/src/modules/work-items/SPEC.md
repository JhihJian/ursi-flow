# 工作清单与平台资源

## 功能意图

记录可独立维护的工作事项，按需从指定的 MCP 资源和 Python 配方生成文件型工作包。

## 关键功能与验收

### 事项与当前归属

#### 验收

- 新建表单不提供状态选择；只填标题即可创建一次性、待开始的工作项，无需先配置 MCP。类别为一次性工作（`one_time`）或持续工作（`continuous`），状态为待开始（`pending`）、进行中（`active`）或已完成（`completed`）。编辑其中一项不改变另一项，详情和列表均显示已保存的类别与状态。
- `/work-items` 每行显示标题、类别、状态和当前关联包数。类别与状态可单独筛选，组合时仅显示同时匹配的项。URL 查询参数 `category` 和 `status` 记录已选条件，刷新可恢复；清除一个条件保留另一个。
- 查看说明、已保存的工作包来源和关联包；包名链接到工作包编辑台。编辑携带读取时的修订号，冲突时显示错误并保留草稿。
- 删除前提示将解绑的包数和保留的材料。包数读取失败时不能以零代替，也不能确认删除。

### 资源配方

#### 验收
- 资源按服务列出，用户可跨服务选择同名资源，按选择顺序指定唯一别名；保存配方保留 `(alias, serverId, uri)` 与脚本原文，关闭来源可保存为 `null`。
- 配方生成使用已保存的配方。同次生成的失败重试沿用请求标识，成功后打开返回的工作包，再次主动生成使用新标识。生成后工作项类别与状态保持不变。

### 绑定工作包生成器

#### 验收

- 编辑工作项可选择内嵌配方、生成器或不配置来源。保存生成器绑定时固定已选版本，并为各别名保存 MCP 引用。切换来源时清除另一种已保存的来源。
- 工作项详情链接到绑定的指定版本。发布新版后旧绑定保持原样。点击生成使用已保存的绑定，打开本次生成详情；从「生成记录」可查看按工作项筛选的历史。
