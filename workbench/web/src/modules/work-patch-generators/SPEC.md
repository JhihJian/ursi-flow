# 工作包生成器与生成记录

## 功能意图

将 Python 转换和输入别名发布为可复用的版本。用户可独立试运行，也可从工作项发起生成，并从记录查询当时的输入、状态和结果。

## 关键功能与验收

### 发布与历史版本

#### 验收

- Flow 关闭时仍可从 `/work-patch-generators` 创建生成器、发布新版、查看历史版本并打开原脚本。发布新版后，旧版深链和对此版本的引用保持原样。
- 每个版本的试运行按该版声明的别名选择已登记的 MCP 资源。填齐后才可运行，提交项保留原别名、服务 ID 与 URI。零输入的版本可直接试运行。

### 运行状态与结果

#### 验收

- 同一次请求失败后的原样重试沿用 UUID v4。已收到运行记录后，再次发起使用新标识。内网 HTTP 使用同一套提交入口。
- `/work-patch-generation-runs` 按服务端顺序显示最近记录，可按生成器和工作项筛选。直接打开运行深链时，运行中状态自动更新，查询错误可重试。
- 详情展示当时的生成器修订、工作项快照标题、时间、输入引用及服务端返回的读取证据。失败或中断显示状态及已记录的原因。
- 试运行成功后可预览或下载只读结果文件。工作项生成的记录保留生成时的文件清单，并链接到可编辑的工作包。工作项删除后，原运行仍可独立打开。
