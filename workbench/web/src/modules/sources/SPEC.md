# 外部来源

## 功能意图

展示服务端配置的外部来源及其当前导出条目，让操作者通过固定动作派工并回到派工记录。

## 关键功能与验收

### 来源浏览

#### 验收

- `/sources`、`/sources/:provider/items` 和 `/sources/:provider/items/:id` 分别读取来源索引、实时条目列表和实时条目详情。
- 每次读取都重新请求服务端并禁用缓存；页面上的「刷新」调用重新读取，替换导出后列表和详情显示新材料，不回退到旧条目。读取失败时不继续展示上一次的条目材料。
- 来源未配置的 404、空列表和 503/网络故障分别显示未启用、空态和可重试故障；条目在读取或派工时已移除显示「条目已不可用」。工作清单不受来源探测失败影响。
- 条目材料只读展示，不回显服务端路径或原始错误材料，也不出现「已同步历史单据」一类声明。已派出的单据由派工记录按开单时的材料展示。
- 页面不提供连接、凭据、来源映射或包绑定的配置入口。

### 固定动作派工

#### 验收

- 派工请求体只提交 `requestId` 和服务端公布的 `action`，包、修订、输入和执行器不由客户端控制；页面只展示详情接口公布的动作名。
- 同一条目动作重试沿用原 `requestId`，响应丢失或 503 后重试不会重复建单；切换动作后使用各自的请求标识。
- 成功后进入 `/items/:id`。服务端返回 409 或条目已移除时作废本次请求标识、重新读取条目并清空动作选择，由操作者重新核对材料和动作后显式派工，不静默改参数重发。
- 响应丢失、503 和其他一般故障保留动作选择并显示错误；重试沿用原标识，401 仍交由登录流程处理。
