# 工作区

## 功能意图

「工作」统一承载全部事项和项目规划。项目用地图、画布和待办组织同一批事项。工作包生成仍由生成器模块负责，事项详情提供按事项筛选的生成记录。

## 关键功能与验收

### 事项管理

#### 验收

- 新建表单不提供状态选择；只填标题即可创建一次性、待开始的工作项。类别为一次性工作（`one_time`）或持续工作（`continuous`），状态为待开始（`pending`）、进行中（`active`）或已完成（`completed`）。编辑其中一项不改变另一项，详情和列表均显示已保存的类别与状态。
- `/work-items` 每行显示标题、类别、状态和当前关联包数。类别与状态可单独筛选，组合时仅显示同时匹配的项。URL 查询参数 `category` 和 `status` 记录已选条件，刷新可恢复；清除一个条件保留另一个。
- 详情展示说明、关联包和本项的生成记录入口；包名链接到工作包编辑台。编辑携带读取时的修订号，冲突时显示错误并保留草稿。
- 删除前提示将解绑的包数和保留的材料。包数读取失败时不能以零代替，也不能确认删除。删除后关联包保留并解除关联。

### 项目规划工作区

#### 验收

- 「工作」内切换「全部事项」和「项目」，默认落在全部事项，包含未归入项目的事项。项目页可创建、置顶及继续最近的项目。项目内切换「地图」和「待办」，可打开大纲展开当前项目的画布和任务卡。点击画布、任务卡或 TODO 进入对应位置，TODO 行显示人工状态和卡内顺序。
- 宽屏在项目内左侧并列显示可收起的大纲，切换画布时保持打开；其余宽度通过抽屉打开，导航后关闭。点分支箭头只展开或折叠。深链及前进后退按当前 URL 选中并展开对应画布、任务卡或事项。
- 当前项目的大纲、地图、画布和待办共享快照，修改后同步重读。清单和其他模块不预读项目。切换项目时取消旧读取，显式深链保持有效。
- 项目地图和任务卡画布共用工具栏。桌面可切换图形与列表，在图中拖动节点、平移、缩放，通过缩略图浏览，在任务卡端口连线或重接。宽度不超过 767px 时用列表和表单编辑同一份数据。地图和每张画布的布局独立保存、分别重置，刷新后恢复已保存的节点位置和关系。
- 地图节点显示各画布全量 TODO 状态和打开入口。图形地图详情显示所选画布或关系，点空白清空选择。规划画布的任务卡、关系、设置及 TODO 共用详情栏。桌面宽屏并列显示详情，其余宽度分行展示。任务卡保留可滚动的标题和状态预览。关系入口可按需列出全部边，在窄屏和列表模式也可维护。
- 桌面可右键或按 `Shift+F10` 打开空白、节点、边或 TODO 的对应操作菜单。编辑和删除确认使用对话框，关闭时焦点回到仍存在的触发对象。保存、取消和冲突重读保留当前画布平移与缩放。新节点在视口外时只平移到该节点，保留缩放。窄屏保留列表和表单入口。
- 一张任务卡可创建或加入多条现有事项，同一项目内可以在卡之间移动、在卡内重排，或移出并保留在全局清单。连线只表达计划先后，关闭 Flow 仍可使用。
- TODO 面板按已有人工状态分组，画布、任务卡和类别筛选保留在 URL。侧栏可编辑原工作项及定位到卡内对应条目，从画布返回后保留筛选。旧工作项详情可以打开其当前画布，继续提供包与生成记录入口。
- 保存遇到修订冲突时提示并重读快照，不覆盖服务端新数据。事项筛选和规划修改不能触发生成、自动办理状态更新或执行。
