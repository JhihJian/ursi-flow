# 平台 MCP 页面与环境变量接入

## 功能意图

为 Workbench 的平台 MCP 页面提供同源认证、导航和凭据名称，集中维护可用于连接的变量。配方与服务页使用同一 MCP 客户端。

## 关键功能与验收

### 平台变量

#### 验收

- `/platform-env` 只列出平台保存的变量名，可新增、替换值、确认删除。编辑时密码框为空，成功后关闭并刷新列表。失败时保留输入，显示错误。
- 删除前提示使用此平台凭据的服务将无法新建连接。MCP 登记表单提供变量管理入口。

### 管理页接入

#### 验收

- 原 `/mcp-servers` 与 `/mcp-servers/:id?uri=...` 导航和直达链接仍可使用。页面请求使用现有认证客户端。
- 在配方编辑页可选择登记服务和资源。删除凭据后，重新打开服务检查页会显示读取失败。
