# 平台 MCP 服务与资源检查

## 功能意图

集中管理平台只读 MCP 服务。浏览资源时，用户能区分已登记的配置、本次连接发现结果和所选资源的读取结果。

## 关键功能与验收

### 平台变量

#### 验收

- `/platform-env` 只列出平台保存的变量名，可新增、替换值、确认删除。编辑时密码框为空，成功后关闭并刷新列表。失败时保留输入，显示错误。
- 删除前提示使用此平台凭据的服务将无法新建连接。MCP 登记表单提供变量管理入口。

### 服务目录

#### 验收

- `/mcp-servers` 列出已登记的名称、Streamable HTTP 地址和可选的凭据环境变量名，支持按名称或地址搜索、刷新登记。加载与刷新目录不出站探测，也不显示在线状态。
- 新增服务在弹窗内填写名称、地址，从已保存的平台变量中选择凭据或不使用凭据。提交前显示所选变量名与接收地址，默认部署全程无需编辑文件；提交失败时显示原因并保留表单。删除经确认后才提交，已生成的工作包仍保留。

### 服务检查与资源预览

#### 验收

- `/mcp-servers/:id` 展示登记信息、本次发现状态、协商版本、服务实现标识和声明的能力。工具与提示词能力仅展示，不发起调用。空列表、未声明资源、发现失败具有不同提示。
- 桌面并排显示列表与预览，窄屏纵向排列。列表可按名称、URI 或媒体类型搜索，可重新发现。选择状态写入 `uri` 查询参数；重新打开地址时读取仍存在的资源，并明确提示不在本次列表中的 URI。
- 预览单独显示读取状态，失败后可重试。文本按原文显示，最多预览 16 384 个字符，可复制全文或 URI。二进制仅显示媒体类型与大小，不渲染内容。
