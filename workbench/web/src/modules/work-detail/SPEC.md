# 工作项详情

## 功能意图

经办人与验收人围绕同一张单的派工快照办理、核对执行事实、提交报告并按版本验收。

## 关键功能与验收

### 办理与导航

#### 验收

- 页首展示单号、派工模板版本、经办人和业务状态。待办理、办理中默认打开办理，待验收、已交付默认打开交付。返回清单保留状态筛选。
- 输入与来源在办理说明和固定绑定之前展示。来源单展示来源类型、来源、条目和获准动作，动作下拉只含快照中的获准动作，没有获准动作时不提供执行。开始办理需要经办人。派工模板发布新版不改变本单办理说明、动作或验收标准。
- 页面只读派工快照，不请求目录最新版。固定动作展示执行器 ID 与版本，以及快照中的固定资源引用。

### 执行与核实

#### 验收

- 执行一次只派发一次，按尝试 ID 查询；启动结果不明先查本单历史。活动尝试持续查询，终态或离页停止轮询，查询错误可重试。
- 每次尝试分别显示结果、执行器绑定、工作区、后端会话标识与目录能力引用。页面不根据执行器契约推导 Agent、Flow 或环境标签。取消后显示实际结果；待核实只接受有证据和原因的失败或取消结论。

### 执行详情

#### 验收

- 展开一次尝试后，依次展示「平台记录日志」「执行器记录日志」「制品目录」三个区域，顺序固定，之后再展示旧 `output`、中断前状态、恢复提示和核实记录。后端会话标识只在服务端返回时显示，不生成 Flow 或环境详情链接。
- 两个日志区域只显示状态与条数（`暂无…` 或 `已记录 N 条，日志查看器待实现`），不渲染正文、不实时流、不过滤、不高亮。
- 制品区域读取 `artifactDirectory.id` 的 `/tree` 清单并逐个列出路径与类型/大小，标明 `已冻结（只读）` 或 `执行中可写`，读取失败可重试。`artifactDirectory` 为空时明确显示「无制品目录」。
- 只有 `executorLogPage` 是非空真实地址时才渲染自定义日志页链接。当前服务端恒返回 `null`，页面不生成任何猜测的 URL。

### 交付与验收

#### 验收

- 快照验收标准与指定版本文本在宽屏并排、小屏上下排列。办理中可提交全部必需文本及本单来源尝试；未结束和待核实尝试列出原因并可定位记录。
- 每份交付文件分别读取。任一文件读取失败、返回空响应或 HTML 页面时，指明具体文件名、停用通过和退回并允许重新读取本版；读齐本版全部文件后才提供验收操作。
- `/items/:id/deliveries/:version` 固定展示该版文件、关联尝试与验收记录。无效版本不回落到当前版。只有当前待验收版本可审，验收人必填，退回需要意见，通过后标出通过版本。
- 冲突后重读本单，保留未提交文字，旧意见不进入新版验收表单。退回后可在同一张单上提交新版。
- 已知边界：提交新版交付时服务端只校验工作项处于办理中，不校验起草时看到的最后交付版本。双标签页下被退回后的 `working` 单据仍会接受旧页提交的旧稿。是否增加原子版本前置条件待产品与 Server 负责人裁决，本模块在裁决前按现状展示实际结果。
