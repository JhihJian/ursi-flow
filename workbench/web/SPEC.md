# Flow 工作台

## 功能意图

使用同源 HTTP 服务维护 Flow 包、运行和配置，通过独立的本地对话入口保留演示体验。登录后的首页是「工作」的全部事项视图。用户可维护事项、从资源生成文件包，并独立发布资源和执行器定义。结构与边界见 [Web v2 界面设计](../../docs/design/workbench/WEB-WORK-MANAGEMENT.md)。

## 关键功能与验收

### 工作区与生成配方

#### 验收

- 侧栏「工作」进入 `/work-items`，工作区内切换全部事项和项目。项目内部切换地图与待办，从地图或项目大纲进入画布。工作包生成器独立选用 MCP 资源和已保存的配方，包详情可变更或解除归属。
- 删除清单项后仍可打开工作包、查看文件和生成来源。

### 工作定义与历史版本

#### 验收

- 桌面与移动浏览器均可在 `/resources` 发布提示词，在 `/executors` 发布绑定其指定修订的执行器。发布两者的新版后，从旧执行器深链仍可打开原提示词正文。真实 Server 与浏览器的验证范围见[定义联合验收](acceptance/SPEC.md)。

### 独立目录

#### 验收

- 从工作包入口创建空文件目录，从配置包入口独立编辑提示词、Skills 和 MCP。两类目录可独立使用，无需启动执行器。
- 包记录保存名称与目录标识，工作包另有可空的当前归属与独立的生成记录。列表与新建的响应都返回 `directoryId`，两个页面按该标识打开同一套虚拟目录客户端。

### Flow 工作区操作

#### 验收

- 登录后可创建、读取、编辑、验证和删除含多个文件的包。更新携带读取时的目录 revision。
- 从已保存包在 default 工作区启动运行，列表与深链可查看真实状态、参数和历史；停止请求后重新读取运行结果。
- 工作包执行页与 Flow 编辑页均可选择已发布的 Agent 修订启动 Flow，Workbench 将固定的 `executorRef` 传给同源启动接口。管理页面导航与业务 API 地址分别配置。
- 可读取运行配置并更新模型和最大并发数。

### 认证、导航与对话

#### 验收

- 默认构建无令牌不发出业务请求，手动输入后仅通过 Authorization 请求头认证。刷新保持登录，退出清除会话令牌。
- `lan-preview` 单独构建，仅用于隔离样例数据。受信 IPv4 网段可直接打开工作清单和项目深链、编辑规划数据。代理校验实际连接来源、精确主机与同源请求，只转发规划接口。后端仍验证服务令牌，浏览器不接触该令牌。
- 开发与预览服务监听所有网卡，同一网段的设备可按本机地址打开页面；主机名访问需在 `URSI_ALLOWED_HOSTS` 中列明，其他主机头仍被拒绝。
- 桌面和移动导航均区分真实服务和本地演示，后端失败显示错误。
- 对话会话可在未登录时创建、流式展示与刷新恢复，消息不发送到运行服务。
