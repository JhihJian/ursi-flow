# 工作定义联合验收

## 功能意图

用真实 Web 和 Server 验证资源与执行器可独立发布，并按版本读取。

## 关键功能与验收

### 浏览器发布与版本固定

#### 验收

- 从工作清单登录，桌面侧栏与移动抽屉均可进入资源库和执行器。
- 在浏览器发布提示词和引用它的执行器，分别发布新版后，新执行器指向新资源版本。
- 重新打开旧执行器深链，仍能打开其固定的旧资源版本并读到原文。

### 隔离运行

#### 验收

- 使用独立临时业务数据、回环端口和本次生成的令牌。真实 Server 关闭 Flow，验收只需 Web 和 Server，无需模型服务。
- 验收结束后停止服务并清理临时业务数据，失败时保留日志和浏览器追踪。
