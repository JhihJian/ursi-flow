# Web v2：工作清单与文件包

默认首页 `/work-items` 展示可按类别和状态组合筛选的工作清单。清单项记录事项与可选的生成配方；工作包保存材料文件。工作状态由用户编辑，生成文件包不会改变类别或状态。

## 工作清单与包目录

用户可直接新建一项工作。需要外部材料时，在 `/mcp-servers` 登记获准的服务，再回到工作项编辑页，选择具体资源、设置别名并保存 Python 配方。详情页的「生成工作包」读取当次材料，新包出现在关联工作包列表。包详情支持改绑或解除归属，生成来源仍记录原工作项。

工作包与配置包分别从 `/work-patches` 和 `/config-patches` 进入。两类页面都按包记录返回的 `directoryId` 打开文件目录。配置包提供提示词、Skills 和 MCP 的专用编辑器，其 `mcp.json` 与平台 MCP 服务登记相互独立。文件操作见[目录编辑台](../PATCH-STUDIO.md)。

## 定义目录与运行工具

`/resources` 和 `/executors` 提供目录、历史修订及新版发布表单。执行器绑定指定版本的资源，旧版深链仍可查到原资源正文。发布执行器只保存定义。[通用执行器提案](../EXECUTOR-DESIGN.md)描述未来的运行契约。

业务页访问同源 `/api/v2`。Flow 工具单独访问 `/api/v1`；已登录时 Flow 集合返回 404 则收起该导航组。桌面侧栏与移动抽屉使用同一份导航。本地演示对话独立于两版服务。页面入口和验收命令见[使用说明](README.md)。
