# 工作台

## 功能意图

工作台将[服务端](server/SPEC.md)与[浏览器界面](web/SPEC.md)组织为同一项目。用户通过同源 API 维护工作清单、工作包、配置包和版本化定义。启用 Flow 时可另外管理流程包与运行。

## 关键功能与验收

### 工作清单与资源转包

#### 验收

- 未接入外部服务也能创建、筛选、编辑和删除四类工作项。
- 从平台登记的 MCP 服务选择资源，在工作项保存 Python 配方。每次主动生成一个文件型工作包，重试同一次请求只发布一个包。删除工作项时保留包、文件及生成来源，每包当前至多归属一个工作项。详见[工作清单与工作包来源](WORK-LIST-DESIGN.md)。

### 工作包与配置包目录

#### 验收

- 虚拟目录可独立创建和读写。工作包、配置包各自保存元信息与目录引用。输入包名即可创建包及其目录；工作包自由管理文件，配置包分别维护提示词、技能与 MCP。读写无需 Flow 或执行环境。

### 前后端联合验收

#### 验收

- 从工作台 Cargo 工作区构建 Server，从 `web/` 构建界面。浏览器可通过真实服务发布提示词及引用它的执行器，打开历史执行器修订后仍能查到当时引用的资源版本。
- 执行器目录只管理定义。[通用执行器提案](EXECUTOR-DESIGN.md)描述未来如何调用这些定义。
