# 工作台

执行器的项目概念、版本结构、资源关系与运行边界见[执行器设计](EXECUTOR-DESIGN.md)。

## 功能意图

工作台将[服务端](server/SPEC.md)与[浏览器界面](web/SPEC.md)组织为同一项目。服务端保存业务记录，界面通过同源 API 提供从派工到验收的操作入口。

## 关键功能与验收

### 工作包与配置包目录

#### 验收

- 虚拟目录资源可独立创建和读写。工作包、配置包各自保存元信息与目录引用。输入包名即可创建包及其目录；工作包自由管理文件，配置包分别维护提示词、技能与 MCP。读写无需 Flow 或执行环境。

### 执行器制品与执行详情

#### 验收

- 一次执行尝试独占一个 workspace 引用和制品目录，冻结工作指令并保存两类日志。平台向本地 Agent 提供 `URSI_ARTIFACT_DIR`，当前内置 Pi 调用尚未开放写文件工具，因此本切片先完成目录传递与清单管道；平台登记目录、列出清单并在终态后冻结。重试使用新目录，历史制品只读保留。
- 执行详情按「平台记录日志」「执行器记录日志」「制品目录」的顺序展示；日志只给占位与条数，制品区列出目录清单，无目录时明确提示。没有真实的自定义日志页地址时不渲染链接。
- 当前为迁移切片：交付仍为文本文件对象，日志查看器与执行器静态日志页尚未实现，边界见[执行器设计](EXECUTOR-DESIGN.md)。

### 前后端联合办理

#### 验收

- 从工作台 Cargo 工作区构建 Server，从 `web/` 构建界面。浏览器联合验收默认连接该工作区构建的 Server。
- 关闭 Flow 并配置本地 Agent 后，经办人可在浏览器按同一派工模板版本派出两单，分别执行动作、提交交付并查看各自的验收记录。
