# 工作台

## 功能意图

工作台将[服务端](server/SPEC.md)与[浏览器界面](web/SPEC.md)组织为同一项目。服务端保存业务记录，界面通过同源 API 提供从派工到验收的操作入口。

## 关键功能与验收

### 前后端联合办理

#### 验收

- 从工作台 Cargo 工作区构建 Server，从 `web/` 构建界面。浏览器联合验收默认连接该工作区构建的 Server。
- 关闭 Flow 并配置本地 Agent 后，经办人可在浏览器按同一工作包版本派出两单，分别执行动作、提交交付并查看各自的验收记录。
