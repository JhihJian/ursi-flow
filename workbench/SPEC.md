# 工作台

## 功能意图

工作台将[服务端](server/SPEC.md)与[浏览器界面](web/SPEC.md)组织为同一项目。服务端保存业务记录，界面通过同源 API 提供从派工到验收的操作入口。

## 关键功能与验收

### 工作包与配置包目录

#### 验收

- 虚拟目录资源可独立创建和读写。工作包、配置包各自保存元信息与目录引用。输入包名即可创建包及其目录；工作包自由管理文件，配置包分别维护提示词、技能与 MCP。读写无需 Flow、SOP 或执行环境。

### Echo 工作区准备与执行

#### 验收

- 关闭 Flow 时，工作包可以只凭需求和材料准备就绪。SOP 可在没有工作包时发布和查阅。执行时从目录选择一个固定修订，同一工作包的各次回执分别可读。

### 前后端联合办理

#### 验收

- 从工作台 Cargo 工作区构建 Server，从 `web/` 构建界面。浏览器联合验收默认连接该工作区构建的 Server。
- 关闭 Flow 并配置本地 Agent 后，经办人可在浏览器按同一工作包版本派出两单，分别执行动作、提交交付并查看各自的验收记录。
