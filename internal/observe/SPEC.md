# internal/observe

## 功能意图

observe 承担过程可观测的事件采集与订阅。它接收 engine 与执行器上报的观测事件（节点状态变化、工具轨迹、日志、产物发布），统一为 domain 的 `TelemetryEvent` 契约，并提供订阅接口把事件推送给 api 与 web。observe 只负责采集与转发，持久化由 repo 承担。

## 关键功能与验收

### 事件采集

提供统一的事件上报入口，接收节点状态、工具轨迹、日志、产物发布事件，规范化为 `TelemetryEvent`。

#### 验收

- 上报一个节点状态事件后，可查询到规范化的事件及其类别与阶段。
- 上报的执行器工具轨迹与日志事件保留原始内容且带时间与节点归属。

### 事件订阅

提供订阅接口，订阅方可按运行与节点过滤接收事件流，用于 api 的 SSE 推送与页面实时呈现。

#### 验收

- 订阅某个运行后，该运行新产生的事件按产生顺序推送给订阅方。
- 未订阅的运行事件不推送给订阅方；订阅关闭后不再推送。
