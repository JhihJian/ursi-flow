# artifacts

## 功能意图

artifacts 管理产物内容与元数据，记录 run、node、generation、attempt 归属，提供稳定的内容写入、读取和列举能力。generation 为持有代数，attempt 为 runs 分配的节点累计执行编号，返工后继续递增。
模块位于 `flow-core/src/artifacts`，复用同一 crate 的 domain 产物契约，通过 storage 与受控内容目录保存数据。
模块交付产物契约检查结果，节点状态和当前输出的选择由 runs 决定。

## 关键功能与验收

### 内容写入与归属记录

接收调用方提交的内容、逻辑名称及完整归属，保存稳定内容标识、内容类型、大小和校验信息。
成功返回意味着元数据与完整内容可一起读取，失败写入不产生可见的半成品记录。

#### 验收

- 写入指定 run、node、generation、attempt 的文件后，读回相同字节与全部归属字段。
- 缺少归属字段或元数据与内容不一致时返回明确错误，列举结果中没有该失败产物。
- 在内容落盘与元数据提交边界注入故障，重新打开存储后可见记录均对应完整可读取内容。

### 稳定读取与范围列举

提供按产物标识读取元数据及内容、按运行和节点及代数和尝试范围列举的接口。
内容标识对应不可变内容，同名的新产物作为新归属或新内容记录保存。

#### 验收

- 关闭并重新打开临时 SQLite 与内容目录后，原标识读取的内容和校验信息保持一致。
- 为多个运行、节点、代数和尝试写入同名文件，全量列举返回全部归档记录，范围列举仅返回匹配记录。两者均只读元数据，按创建时间、产物标识升序排列。
- 新产物写入后旧标识继续读取旧内容，缺失标识或损坏内容返回可识别错误。

### 重试幂等与冲突识别

写入请求以归属和调用方稳定幂等标识识别重复提交，成功重试复用原记录。
相同幂等标识携带不同内容或关键元数据时返回冲突，不同 attempt 或 generation 保持独立。

#### 验收

- 同一请求串行或并发重试后仅形成一条逻辑记录，返回相同产物标识与内容。
- 同一幂等标识提交不同字节时返回冲突，原内容与元数据保持不变。
- 相同节点在不同 attempt 或 generation 提交同名产物时，能够分别列举和读取。

### 路径安全与内容交付

将逻辑产物路径限制在受控内容根目录，隔离调用方名称与物理存储位置。
内容交付依据稳定产物标识，校验路径、链接和实际读取目标的范围。

#### 验收

- 合法嵌套相对路径可保存与读取，返回结果具有可供调用方交付的稳定内容标识。
- 绝对路径、目录穿越和指向根目录外的符号链接被拒绝，根目录外文件保持原样。
- 元数据校验信息与实际内容不符时读取失败，错误结果不会包含根目录外文件内容。

### 产物契约检查

按 domain 契约检查必需产物、名称、路径和内容类型，返回逐项结果及可定位的失败原因。
检查结果供 runs 决定节点成功、失败或重试，本模块仅记录和交付产物事实。

#### 验收

- 提交满足声明的产物集合，检查返回通过并能定位每个匹配的产物标识。
- 缺失必需文件或内容类型不匹配时，返回对应契约项的失败结果。
- 检查通过或失败均不写入运行、节点状态，也不改变任何代数的当前输出选择。

## 交付与验收边界

- 独立环境使用临时 SQLite、临时内容目录与内容输入替身，覆盖真实本域元数据和文件存储。
- 独立交付覆盖写入、读取、列举、归属隔离、重试幂等、路径安全、故障一致性及契约检查。
- 沙箱内容由 runs 调用 sandboxes 获取后提交 artifacts，本模块接收内容且依赖方向独立于 runs 和 sandboxes。
- runs 或 server 的 app 组织真实沙箱回收与产物交付联调，验证沙箱释放后已回收内容仍可稳定读取。
- server 集成测试组织输入交接联调，验证历史产物保留及不同运行、节点和执行轮次的数据隔离。
- 联合验收交错执行返工、重试与旧请求迟到写入，覆盖同一 generation 内返工且 attempt 递增，确认旧 generation 或 attempt 的产物不会成为当前输出。
- 替身验证内容入口与检查结果，真实回收、当前输出选择和节点状态流转以联合验收结果为准。
