# connections

## 功能意图

connections 管理模型服务连接，统一提供 endpoint、模型选择所需信息和凭据引用。
模块位于 `flow-core/src/connections`，通过 storage 保存连接配置，为角色编辑和执行装配提供受控的连接查询入口。
执行器适配能力通过运行时能力描述接口获取，角色规则由 roles 管理，执行与调度由运行侧负责。

## 关键功能与验收

### 连接配置管理

提供连接创建、列表、详情、修改与删除接口，保存连接名称、服务类型、endpoint 和凭据引用。
配置写入前校验字段与 endpoint 格式，使用稳定标识区分连接。

#### 验收

- 创建合法连接后能够列举和读回，重新打开临时 SQLite 后配置与标识保持一致。
- 修改 endpoint 或凭据引用后读取新配置，非法地址及缺失必需字段返回明确错误并保留原配置。
- 删除无引用连接后查询返回不存在，已取得的运行快照按其冻结规则读取原配置。

### 引用登记与删除约束

提供连接存在性检查及角色引用登记接口，登记与角色写入共享 storage 事务。连接删除在事务中检查登记，保留被当前角色引用的连接。

#### 验收

- 已登记引用的连接删除返回冲突，无引用连接可删除。
- 重复登记保持幂等，解除指定登记保留其他角色的引用。
- 与角色写入共用的事务失败时，连接登记同时回滚。
- 并发删除连接与保存角色引用时，只产生引用有效或角色保存失败的结果。

### 凭据引用与受控解析

连接的业务存储与对外配置只保存凭据引用，实际密钥从受控凭据来源解析。
凭据解析入口仅向授权的执行装配方交付运行时所需值，凭据来源可通过接口替换。

#### 验收

- 使用凭据解析替身时，输入正确引用得到对应值，错误引用返回可识别的缺失或访问失败。
- 创建、查询、更新的 DTO、持久化连接配置和运行快照均不包含密钥明文。
- 解析失败的日志与错误响应保留连接定位信息，同时隐藏密钥及包含密钥的上游响应。

### 运行时能力描述查询

通过注入的能力描述接口读取执行器对服务类型、模型连接参数及认证方式的支持情况。
connections 依据描述结果提供配置可用性判断，能力来源负责描述适配范围。

#### 验收

- 注入两种能力描述后，同一连接按各自支持范围返回匹配或不匹配结果。
- 能力描述接口不可用时返回明确的未知或查询失败结果，调用方可以区分其与确定不支持。
- 能力查询只读取描述信息，调用记录中没有启动执行会话、调度节点或修改角色的操作。

### 连接配置交付

向角色查询方交付连接标识、模型信息和能力判断，向运行创建方交付可冻结的连接配置及凭据引用。
运行时凭据解析与配置读取分开调用，配置交付结果具有明确的缺失及失效语义。

#### 验收

- 查询存在的连接时返回完整非敏感配置，查询不存在或已删除的连接时返回明确失败。
- 读取可冻结配置后再修改连接，已交付值保持原样，后续读取返回修改后的配置。
- 仅调用列表、详情或配置交付接口时，凭据解析替身没有被调用。

### 存储失败与敏感信息隔离

连接写入以完整记录提交，存储失败时保持原有可读取配置。
业务错误、访问日志及调试输出采用一致的敏感字段隔离规则。

#### 验收

- 在连接更新提交处注入存储错误，重新读取只得到旧记录，列表与详情一致。
- 使用带识别标记的测试密钥触发成功和失败路径，DTO、日志与快照中均搜索不到标记。
- endpoint 含内嵌认证信息等明文敏感参数时，拒绝保存并返回脱敏的字段错误。

## 交付与验收边界

- 独立环境使用临时 SQLite、凭据解析替身和运行时能力描述替身，执行真实连接存储读写。
- 独立交付覆盖 CRUD、配置校验、能力匹配、凭据引用解析入口和敏感信息隔离。
- 能力适配依赖由 app 注入的运行时能力描述接口，真实 CLI 实现由沙箱 session-service 装配。
- server 集成测试组织真实 roles、connections、storage 联调，验证引用删除并发约束与模型选择正确传递。
- 联合验收使用真实凭据来源和执行器完成认证，检查密钥实际注入且未进入 DTO、日志或快照。
- 连接或角色修改后的新旧运行隔离由运行快照联合验收覆盖，替身认证结果仅验证接口契约。
