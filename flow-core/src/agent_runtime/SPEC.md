# Agent Runtime 端口

## 功能意图

向运行引擎提供单次执行接口。引擎传入角色、执行器、任务上下文与执行环境，按返回结果推进节点。ACP 会话、网络连接和 CLI 生命周期由端口实现处理。

## 关键功能与验收

### 执行输入与结果

`Runner` 接收带有 run/node 标识的输入，返回文本、产物声明及用量，或返回分类错误。执行中的遥测通过 `EventSink` 上报。

#### 验收

- 注入测试执行器时，调用方可检查收到的输入、事件和最终结果，不需要连接模型或启动 CLI。
- 连接中断且无法确认任务是否结束时，执行器可以返回 `OutcomeUnknown`，与明确执行失败区分。

### 取消与替身

调用方可以通过 `run_cancellable` 传递取消意图。未实现中断的执行器沿用 `run`，等待执行返回；取消意图本身不是停止回执。

#### 验收

- 接受取消意图的实现只有在核实结果后才能报告终态；引擎可识别未知结果。
- `MockRunner` 仅在测试或启用 `test-support` 时可用，生产装配不以其替代远端执行器。
