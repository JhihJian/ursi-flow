# sandboxes

## 功能意图

向运行域及沙箱页面提供资源准备、关联查询和释放。保存运行与 Gateway 沙箱标识的关联及平台操作结果，Gateway 拥有沙箱实际生命周期；连接与传输由 `sandbox-access` 实现并通过本模块端口接入。

## 关键功能与验收

### 准备与关联

依据运行冻结的沙箱配置请求 Gateway 准备资源，记录请求标识、运行关联和就绪结果。网络结果未知时通过查询核实，重试使用相同操作身份。

#### 验收

- 给定运行标识和配置，准备成功后可查询对应沙箱标识与就绪状态。
- 同一准备操作重复提交时复用已确认关联，不额外分配资源。
- Gateway 尚未就绪或调用失败时返回可区分状态，运行不能将其当作可执行环境。
- 模拟响应丢失并重开本域存储，查询核实后能够恢复正确关联。

### 状态查询与释放

查询 Gateway 的资源状态并结合本地关联返回平台视图。释放操作保存请求结果，未确认完成时保留可查询、可重试的关联。

#### 验收

- 查询关联可得到运行标识、沙箱标识及 Gateway 返回的资源状态，未知关联返回不存在。
- 释放失败或响应超时不会报告资源已释放，后续查询与重试可确认最终结果。
- 已完成的释放再次请求具有幂等结果。
- 平台侧查询失败不会覆盖先前记录为虚假的资源终态。

### 文件与连接接入

通过 Channel 提供输入文件传输、脚本命令执行和获准端点访问。agent 会话控制由 Agent Runtime 完成。对接 terminal、IDE 或预览时使用相应原生协议和端点授权。

#### 验收

- 文件通道替身收到指定目标、路径与原始内容，回读保持完整；命令返回输出与退出状态。
- 不存在或未就绪的沙箱拒绝访问，错误身份与不可达端点返回可区分错误。
- 连接中断返回连接故障，不自动重放 agent prompt。
- 释放与连接关闭能够回收本地句柄，连接关闭不被当作远端任务已经取消。

## 交付与验收边界

独立交付使用本域临时数据库、Gateway 和 Channel 接口替身，验收请求、关联、就绪、释放失败、未知结果核实和连接请求参数。接口替身支持记录调用与注入超时，无需真实容器。

联合验收连接真实 Gateway 和 Channel，验证资源创建、文件往返、命令执行、连接关闭和释放。与 runs 联调时验证任务前就绪、任务后产物回收及结束释放。Gateway 生命周期实现以其契约为准，server 不维护第二套资源恢复状态机。
